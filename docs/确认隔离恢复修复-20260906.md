# 确认隔离恢复修复

版本：1.20260906.1118

- 确认隔离或移入垃圾邮件时，优先使用当前文件夹和 UID 定向移动。
- UID 失效后，使用 Message-ID 在原文件夹重新定位，并以新 UID 完成处置。
- 如果其他客户端或上一次操作已经完成移动，则在目标文件夹定位邮件并校准本地状态，不重复复制。
- 如果服务器源文件夹和目标文件夹都已找不到该邮件，保留本地证据与审计记录，但从工作列表隐藏失效记录并提示用户。
- 处置按钮增加持续加载状态与防重复点击。
- 前端错误提示不再重复出现两次“确认处置失败”，服务端邮件缺失时自动刷新列表。

验证：50 项离线检查通过，覆盖正常移动、UID 重定位、已移动恢复、服务器邮件确实不存在及前端语法检查。未对真实邮箱执行移动操作。
