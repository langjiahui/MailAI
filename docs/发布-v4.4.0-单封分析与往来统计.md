# MailAI v4.4.0

- 基准版本：v4.3.2
- 变更类型：MINOR
- 目标版本：v4.4.0
- 判断依据：新增向后兼容的单封手动分析能力，包含开始分析、重新分析、处理进度和失败重试。其他变更为显示和统计修复。无需迁移原有账号、邮件或偏好。

## 邮件分析

在未分析邮件标题旁点击“开始分析”，或从安全明细选择“重新分析”。后台读取本地原件，执行安全规则、链接和附件检查，并按当前模型配置生成可用的安全复核与摘要。结果完成后更新界面，缺少原件或分析失败时给出提示并可重试。未分析邮件不显示风险分数。

分析只更新本地检测结果及可用摘要，保留原件、已读与星标、位置及人工反馈。任务按账号隔离，同邮箱重复点击复用正在执行的任务，分析失败保留上次完整结果。原件不可用时需先补下载，单封原件分析上限为 50 MB。

## 往来邮件

通讯录展示当前邮箱可查看的往来邮件数量，和详情采用相同的精确地址匹配、可见性及垃圾箱排除口径。一封邮件中同一地址重复出现只计一次。详情显示已加载数量及总数，每批 50 封，支持继续加载。

## 签名和历史邮件头

隐藏缺失来源且无替代文字的微型装饰图片占位，兼容已知 Wingdings 电话与邮件符号。完整历史邮件头可展开查看，保留历史正文、地址与链接。

## 验证

新增离线回归覆盖分析原子更新、失败保留、重复点击、账号隔离、原件缺失和 100 封以上往来分页。Chromium、WebKit 覆盖分析启动、进度、结果和重试、108 封往来加载及中英文显示。发布执行完整 full、凭据扫描、平台安装包、签名及镜像校验。
