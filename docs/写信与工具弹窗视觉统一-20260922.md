# 写信与工具弹窗视觉统一

写信窗口、助手以及常用工具弹窗共用阅读工作区的浅色/暗色表面、边界、字体颜色与强调色。减少输入栏、格式工具和次要按钮的装饰，突出发送等主要操作。

正文格式工具改为原生 details 按需展开，沿用原有命令和翻译。附件、预览、签名及草稿状态保留原有入口。小屏底部操作允许换行，正文编辑区使用统一内边距和行高。

验证：离线检查 153/153；前端产物与差异空白检查通过。隔离测试邮箱内检查深浅色写信、390px 写信布局、格式展开/折叠、助手稳定状态以及浅色附件中心。没有向真实邮箱发信或调用模型。本轮未逐一验证所有弹窗和完整富文本命令组合。

## 克制精修

提高正文和辅助文字对比，调整已读/未读发件人字重与工具栏对齐。编辑区保留清晰但较轻的键盘焦点线；格式工具组改用分隔线。“小邮帮写”保留小图标并常显文字，检查了 390px 下与主题输入区域的间隔。没有新增业务模块或额外折叠入口。深浅色浏览器检查及离线检查 153/153 通过。
