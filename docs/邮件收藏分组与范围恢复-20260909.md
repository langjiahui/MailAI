# 邮件收藏、通讯录分组与按日期恢复

本次更新提供以下操作：

- 在邮件阅读区点击“收藏邮件”；每个邮箱侧栏的“我的收藏”可集中查看，点击“已收藏”可取消。收藏为当前账号的本地标记，随数据库备份保存，不随服务器星标变化。
- 选中分组后点击“添加人员”，可搜索、多选已有联系人加入；支持跨搜索保留选择、识别已入组人员。空分组中央也提供入口。组内可“移出分组”，不会删除联系人。当前每人归属一个分组，跨组添加会移动归属，弹窗内有说明。
- 在通讯录新增、修改或删除分组。新建或编辑联系人时选择分组并维护姓名、邮箱、公司和备注。删除分组保留联系人，移至“未分组”。
- 写信时从收件人、抄送人或密送人的通讯录按钮进入，按组筛选并选择人员；支持全选当前列表和自动去重。每次查询最多显示 300 位联系人，可使用搜索进一步定位；分组筛选先于数量限制执行。
- 设置 → 数据与维护 → 备份 → 恢复，选择开始和结束日期（包含两端当天，按邮件记录日期）。范围恢复合并邮件正文、原文附件与备份中的收藏状态，保留范围外邮件、通讯录、设置和发件任务。也可选择完整恢复，替换全部备份数据。
- 恢复前自动创建安全备份；数据库、原文路径或身份冲突时停止，替换失败自动回滚。相同备份重复范围恢复不重复插入邮件。旧版 v1 备份继续支持完整恢复；日期恢复使用 v2 备份。
