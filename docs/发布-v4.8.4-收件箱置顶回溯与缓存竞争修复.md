# MailAI v4.8.4 发布说明

- 基准版本：v4.8.3
- 变更类型：PATCH
- 目标版本：v4.8.4
- 判断依据：本版为收件箱点击回顶、后台新邮件锚定与缓存分页并发守卫的交互与稳定性修复，未引入破坏兼容性变更或独立新功能模块，现有账号、邮件、数据库与接口完全兼容。

## 收件箱回顶与缓存稳定性优化

- 为侧栏收件箱入口（`#folder-nav`）、账号收件箱（`[data-account-action="inbox"]`）与「所有收件箱」（`[data-account-action="unified"]`）引入 `fromStart` 加载选项：显式点击收件箱时立即回到第 1 页顶部展示新邮件；从其他视图切回且非点击回顶时仍保留既有阅读位置与滚动恢复。
- 后台增量刷新（`refreshWindow`）仅在列表已滚动、不在首页或处于历史锚点定位时锚定当前可见行，避免浏览历史时被新到达邮件顶走；点击「返回列表开头」时仅在首页重新拉取成功后重置 `anchor`，避免请求失败时状态不一致。
- 在 `fetchPage`、异步滚动恢复 `requestAnimationFrame` 与 `refreshAfterPage` 中补充 `live(key, nav)` / `navigationRevision` 校验，丢弃快速切换账号或文件夹期间的过期分页响应与滚动恢复。
- 在 `tests/test_mailbox_store_browser.cjs` 补充新邮件到达锚定、点击账号/紧凑/统一收件箱回顶及返回列表开头回归用例。
