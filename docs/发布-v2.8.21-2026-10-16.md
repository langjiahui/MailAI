# MailAI v2.8.21

基于 v2.8.20 合并近期品牌、模型输出、连接提示与节能调度改动。

- 原始折叠 M 路径保持不变，原生图标统一为主题绿、宝武蓝折光的冰白玻璃样式，更新 Dock、通知、任务栏、组合 logo 及相关资源。标题栏、启动页与 favicon 适配默认绿、黑白、宝武蓝的明暗模式；macOS 菜单栏使用系统着色的单色模板。
- 自部署 Qwen3 默认关闭思考，过滤普通 JSON 与 SSE 中的思考标签、独立思考字段及分段 reasoning 内容。修复思考过程被显示为邮件草稿的问题，保留主题、正文与落款分离及用户确认后填入正文的流程；截断返回不当作完成草稿。
- 模型验证失败使用当前主题表面色与柔和红色混合的细边框卡片，明确错误原因与重试建议，自动聚焦并滚动到提示；保留输入和语言切换后的错误状态。
- 小邮改为按需播放短动作，空闲、失焦、原生窗口隐藏和视口外暂停；保留执行中 AI 请求的工作状态。同步优化后台队列与空闲调度，保留收信、定时发送和提醒服务。
- 保留初次读取小邮状态失败时的自动重试节奏，正常加载后才启用空闲降频，防止网络短暂中断导致恢复延后。

发布检查：整合版本离线门禁 241/241 项通过。图标、明暗配色、连接引导的 Chromium 与 WebKit 检查及写信侧栏回归通过。合成通知内容已通过用户提供的模型验证，未将密钥或内部服务地址写入本次提交。

应用包仍沿用现有固定签名和通知身份。macOS 通知和电池菜单由系统缓存应用图标，安装后实际刷新仍需实机检查；不能将资源核对结果替代系统通知验收。

构建和质量检查由版本标签触发，三平台产物、SHA-256 与更新清单随 GitHub Release 一并发布。
