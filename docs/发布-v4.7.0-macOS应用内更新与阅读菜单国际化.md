# MailAI v4.7.0 发布说明

- 基准版本：v4.6.1
- 变更类型：MINOR
- 目标版本：v4.7.0
- 判断依据：新增兼容现有数据和配置的 macOS 应用内自动下载、重启替换与启动确认能力，并修复阅读菜单的语言切换问题。

## macOS 应用内更新

- 在支持自动替换的安装位置，应用会后台下载更新并校验，完成后显示「重启并更新」，由用户确认重启。
- 更新前保存编辑中的草稿并检查邮件处理状态。草稿未保存或邮件仍在处理时暂缓更新。
- 校验更新清单签名、安装包 SHA-256、目标版本及应用签名身份后替换应用，重新打开后确认启动结果。启动确认失败时尝试恢复上一版本并重新打开。
- 退出检测识别已经结束、等待父进程回收的进程，避免误判为仍在运行而导致更新超时。
- 更新包沿用 GitHub 与 AtomGit 官方双源下载，新增供应用内更新使用的签名应用 ZIP。安装位置不支持自动替换时提供现有 PKG 安装方式。
- v4.6.1 及更早版本的用户需先安装 v4.7.0，之后可通过新的应用内流程升级。

## 阅读菜单国际化

- 修复切换语言后响应式布局放回旧按钮，导致「总结邮件」入口重复及残留中文的问题。
- 阅读操作按钮直接更新文案和无障碍名称，调整窗口大小时继续使用同一个按钮。
- 收藏、加入待办、稍后提醒、识别图片和问小邮的操作文案随当前语言更新。

## 验证

- 本地完整离线门禁通过，290 项检查全部成功。
- Chromium 与 WebKit 回归覆盖语言切换、响应式阅读菜单、入口唯一性、按钮提示和现有打印分享操作。
- 隔离的完整 macOS 测试包从 0.0.1 升级至 0.0.2，通过 HTTPS 下载、清单验签、包校验、重启替换、启动结果确认及未保存草稿保留检查。该实测使用测试签名与本地更新源。
- 正式发布流程继续执行完整 full 验证、凭据扫描、原生启动、固定签名及双源发布校验。
