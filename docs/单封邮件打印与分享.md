# 单封邮件打印与分享

## 使用入口

- Web／桌面：打开邮件，在阅读区「更多」中选择「打印邮件」或「分享邮件」。已发送邮件的详情工具栏也提供这两个入口。
- Android：打开邮件，点击右上角详情按钮，在面板中选择「打印」或「分享」。

输出预览包含主题、发件人、收件人、抄送、时间、完整正文及附件名称和大小。历史引用完整保留。AI 分析、个人笔记、操作按钮和密送信息不加入阅读版输出。

## 打印和 PDF

- 「打印邮件」打开系统打印窗口，供用户选择打印机。打印附件内容需要分别打开附件操作。
- macOS／Windows 桌面可在分享面板直接保存 PDF。macOS 也可从该面板打开原生系统分享。
- Android 在分享面板直接生成当前邮件的 PDF，可分享给其他应用或保存到本地。Web 浏览器支持文件分享时可打开系统分享，其他浏览器提供直接下载。Web 版由运行 MailAI 的设备使用 Chrome、Edge 或 Chromium 生成 PDF。
- 屏幕预览跟随主题，打印和 PDF 使用浅色排版。桌面和 Web 保留表格排版，Android PDF 保留正文、附件清单及基础文字样式。macOS 使用 WebKit 分段生成矢量 PDF，分页尽量避开文字行和普通表格行；超高图片或表格行仍可能跨页。
- 本地内嵌图片会随正文输出；外部图片和不可用图片会省略并显示说明。生成过程不会额外联网下载图片。

## 分享文本和原始邮件

- 「邮件文本」会预览实际复制或分享的纯文本，包含主题、邮件头、正文及附件清单。
- 「原始邮件 EML」包含完整邮件头、正文及全部 MIME 附件，也可能包含阅读版不展示的信息。接收方需要支持 EML 的应用。
- Web／桌面仅导出现存原始文件。缺失时禁用 EML，仍可使用缓存正文打印、生成 PDF 或复制文本。本地发送记录如果没有原始 MIME，同样禁用 EML；不会拼装一个文件冒充原信。
- Android 首次导出 EML 会按账号、文件夹、UIDVALIDITY 和 UID 从服务器读取原始 MIME，校验身份后缓存；之后可离线导出。原信已移动或删除、服务器索引发生变化时会报错，不会导出其他邮件。单次原始邮件上限 100 MB。

## 实现与验证

`app/mail_output.py` 统一生成邮件快照、文本和不依赖外部资源的 HTML。输出经过标签、属性、链接、CSS 和图片格式过滤。HTTP 请求沿用账号上下文和本机来源校验；原始文件下载响应禁止缓存。分享面板会携带原始文件的版本指纹，文件在预览后发生变化时拒绝继续导出，要求重新打开邮件。

桌面输出能力由 `app/desktop_mail_output.py` 管理。打开面板时固定账号与邮件来源，通过短期令牌引用同一份快照；PDF 生成使用独立 WebView，不打印工作台。关闭面板后释放快照，已交给系统分享的独立私有副本保留至进程退出，供接收应用延迟读取。

Android 的 `MailOutput` 生成自包含文档，输出 WebView 禁用脚本、文件访问和联网。系统打印适配器负责分页及打印生命周期。分享通过 `FileProvider` 和临时只读权限传递文件，保存使用系统文件选择器。

测试覆盖完整正文及历史引用、内嵌资源与主动内容过滤、账号与邮件来源隔离、原始文件字节、缺失原信、取消和异步关闭、浏览器双引擎与明暗／窄屏布局。Android 另验证原始 MIME 导出及离线复用；原生桌面能力还需在对应系统验收。
