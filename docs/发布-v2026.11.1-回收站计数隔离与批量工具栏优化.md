# MailAI v2026.11.1 发布说明

- 基准版本：v2026.11.0
- 变更类型：PATCH
- 目标版本：v2026.11.1
- 判断依据：本版统一将垃圾箱邮件从「全部邮件」、常规列表、侧栏计数及默认搜索结果中隔离，并优化批量操作工具栏的图标区分度、中英文悬浮/焦点提示、悬浮对比度与窄屏布局，属于兼容性修复与体验优化，不涉及数据结构或配置破坏性变更，变更类型为 PATCH；历史正式标签与发布记录保持不变。

## 更新内容

- **垃圾箱可见性与「全部邮件」计数隔离**：新增共享可见性规则 [mailbox_visibility](app/db/emails.py)，在 `list_emails`、`search_emails`、[app/mail_list.py](app/mail_list.py) 与 [api_mailbox_counts](app/web/routes/mail_read.py) 中统一把已移入垃圾箱的邮件从常规列表、默认搜索与「全部邮件」计数中排除（仅垃圾箱视图、`in:trash` 查询与指定服务器文件夹保留展示），前端 `serverMailboxCounts` 与 `updateSidebar` 同步扣减服务端和本地垃圾箱计数。
- **批量操作工具栏与窄窗布局优化**：在 [index.html](app/web/static/index.html) 与 [control-theme.css](app/web/static/control-theme.css) 中区分已读/未读图标，为批量按钮与完成按钮提供基于 CSS `data-tooltip` 的多语言悬浮/键盘焦点提示（避免「星标」重复原生提示），提升 `--bulk-hover` 悬浮态对比度、调整窄列表容器响应断点并在 `<= 820px` 视口激活批量选择时自动隐藏右侧预览区以保证操作栏完整可用；同步更新前端产物 [bundle.js](app/web/static/bundle.js)。
- **回归测试补充**：在 [tests/test_bulk_trash.py](tests/test_bulk_trash.py) 中补充乐观删除、撤销与真实删信后的全部邮件/搜索/计数隔离断言；在 [tests/test_bulk_toolbar_browser.cjs](tests/test_bulk_toolbar_browser.cjs) 中补充中英文提示气泡、键盘焦点、`移动到…` 文案宽裕度、窄屏隐藏预览区与批量标记已读/未读回归测试。
