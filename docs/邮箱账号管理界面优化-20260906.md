# 邮箱账号管理界面优化

设置中的“邮箱账号”页采用账号目录与详情维护分栏，明确区分两类操作：

- 邮件列表左侧用于日常选择账号、查看收件箱和收发邮件。
- 设置页只用于添加邮箱、查看连接状态、更新授权和移除邮箱，不再提供账号切换。

进入页面时默认选中当前账号；没有当前账号时选中第一个已连接账号。切换维护对象会先关闭尚未提交的上一账号授权表单，避免误保存。删除入口收纳在“移除此邮箱”区域，降低误触风险。

宽窗口使用左侧账号目录、右侧详情的双栏结构；窄窗口自动改为单栏。新增和更新登录信息共用右侧编辑区域，服务器参数仍收纳在高级设置中。

账号详情中的身份区域使用独立身份卡，头像、账号角色、邮箱地址与授权状态保持固定对齐。角色会根据账号状态显示“当前发件账号”或“已连接邮箱”，避免“当前管理”等含义不清的界面文案。
