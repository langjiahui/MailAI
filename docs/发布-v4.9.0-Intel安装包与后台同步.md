# MailAI v4.9.0 · Intel 安装包与后台同步

- 基准版本：v4.8.4。
- 变更类型：MINOR。
- 目标版本：v4.9.0。
- 判断依据：新增 macOS Intel 官方安装包与设备匹配更新，扩展兼容设备。历史同步入口和提示调整保持本地邮件与账号数据兼容。

## macOS Intel

- 新增 Intel x86_64 的 PKG 安装包及 DMG 镜像，沿用 macOS 签名和安装包校验。Apple Silicon 继续使用 arm64 安装包。
- 官方 Intel 版的更新会匹配 Intel PKG。使用自行编译旧版本的用户，可以从正式发布页下载安装首个官方 Intel 版。
- Intel 构建和原生启动检查使用 macOS 15 Intel 环境。更早 macOS 版本的兼容性以对应系统的安装实测为准。

## 后台同步

- 首次接入可以边同步边阅读已下载邮件，就绪提示提供进度入口。日常同步完成后入口状态自动消失。
- 「任务与发件箱」按邮箱展示历史同步进度和当前文件夹，支持暂停、继续和处理失败。主动暂停保留已下载内容。

## 发布验证

执行与候选提交及 Git 树绑定的完整 full 验证。Windows x64、Apple Silicon、Intel Mac 和 Linux x64 候选构建并行。发布前核验包内架构、原生启动、macOS 签名和安装包校验值。发行后核对 GitHub 公开附件、签名更新清单与 AtomGit 镜像。
