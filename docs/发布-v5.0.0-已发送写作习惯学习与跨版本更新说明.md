# MailAI v5.0.0 发布说明

- 基准版本：v4.9.4
- 变更类型：MINOR
- 目标版本：v5.0.0
- 判断依据：本版新增小邮「从已发送邮件学习」写作习惯记忆与跨版本升级更新说明汇总两项向后兼容的新功能，同时修复「已发送」邮件删除后的缓存失效与多阶段去重问题；先按兼容新功能由 v4.9.4 升级次版本得到 v4.10.0，再按次版本达到 10 的产品编号上限规则进位为 v5.0.0。此次编号进位仅调整产品编号，不表示存在破坏兼容性变更；本机 SQLite 新增表与字段自动迁移，旧配置、账号与邮件数据完全兼容。Android 与 iOS 独立维护版本号，本次不调整。

## 更新内容

- **小邮「从已发送邮件学习」写作习惯记忆**：在「设置 → 小邮 → 管理记忆」新增可选的账号级已发送邮件后台学习（首次可选最近 30、90 或 180 天），仅在本机从已确认发出的本地及服务器发件中提取称呼、语气、篇幅、结论先行、分点结构、行动主题与常用语言，自动跳过转发、自动回复、引用、签名与密送邮件；将小邮建议填入草稿并修改发出后可识别跨至少三条独立往来的重复人工修订（忽略单纯日期或数值改动），稳定习惯按联系人、角色或当前邮箱及新写／回复场景自动应用于小邮帮写，并支持在管理弹窗中查看来源邮件、对比修改前后摘录、编辑、停用、删除或清空重学。后台扫描采用有界批次、前台写锁让渡与自适应批次调节，不阻塞日常收发与草稿保存。
- **跨版本升级更新清单汇总**：发布清单生成脚本（`scripts/create_release_manifest.py`）自动提取并签名随附最近版本摘要历史（`latest.json` / `latest.signed.json`）；客户端跨多个版本升级时，在更新弹窗与「设置 → 关于」页按版本倒序展示 `(当前版本, 最新版本]` 区间内各版本的更新要点、标注 `Latest`/`最新` 徽章并提供完整版本历史跳转入口，适配默认、单色、宝武主题的明暗模式与中英文切换。
- **「已发送」邮件删除缓存失效与幂等修复**：将 `/api/mail/sent` 与 `/api/trash/purge/execute` 纳入前端 `mailaiMailboxStore` 自动缓存失效范围，删除「已发送」邮件后立即清除列表与搜索旧缓存并强制拉取最新分页，避免旧缓存回写导致已删邮件回显及二次点击报「邮件已在处理或本地记录不可用」；统一 `trash*` 全阶段去重过滤、排除已隐藏历史重复副本，并将撤销提示准确识别为「移入已删除」。
