# MailAI v4.5.2 发布说明

- 基准版本：v4.5.1
- 变更类型：PATCH
- 目标版本：v4.5.2
- 判断依据：修复订阅降噪批处理在收件箱超 1,200 封时越出扫描候选集合、日程时间线跨午夜会议漏报冲突以及 `/api/productivity/triage/sender-batch` 对非法 `days` 返回 HTTP 500 的兼容缺陷；无新增功能或破坏兼容性改动。

## 修复内容

- **对齐订阅扫描与批处理 `1,200` 封候选上限**：`triage_sender_batch` 改用与 `scan_subscriptions` 一致的按时间降序截断 `LIMIT 1200` 候选集合（CTE）后再按发件人过滤，确保批处理仅更新界面卡片列表内包含的邮件。
- **跨午夜日程时段冲突检测**：`_assign_conflicts` 改用基于完整 `start_at` / `end_at` 解析出的 `datetime` 区间全局重叠比较，消除按开始日期分桶和当日分钟截断导致跨午夜会议（如 `23:45–次日 01:15` 与次日 `00:15–00:45`）漏报冲突的问题。
- **批处理 `days` 参数校验收敛**：将 `/api/productivity/triage/sender-batch` 的 `days` 参数直接交由 `checked(...)` 与 `_subscription_window` 校验转换（显式拒绝布尔值与非整数），非法参数稳定返回 HTTP `400`。

## 验证

- `tests/test_triage_rules.py` 新增 1,202 封邮件候选集边界验证与非法 `days` 返回 `400` 校验并全部通过。
- `tests/test_calendar_timeline.py` 新增跨午夜跨时区 `.ics` 会议与次日凌晨会议冲突检测用例并通过。
- `scripts/check_release.py` 全量离线发布门禁通过，PR 完整 CI 验证通过。
