# MailAI v3.9.3 发布记录

- 基准版本：Web／桌面最近正式版 v3.9.2（北京时间 2026-10-31 20:11:17 已公开）。
- 变更类型：PATCH。
- 目标版本：v3.9.3，修订号由 2 升至 3，未达到编号上限。
- 判断依据：本次完整变更修复既有邮件实时监听在连接断开后的异常恢复和 CPU 空转，补充回归测试与离线测量工具；没有增加独立用户功能、接口或数据结构，邮箱、邮件、凭据与配置保持兼容，属于兼容性修复与性能优化。
- 各端独立：只发布 Web／桌面；Android 与 iOS 的产品版本和内部构建序号不变。

## 交付内容

- 修复 IMAP 连接关闭后，监听检查立即返回空结果、持续轮询套接字并读取账号配置的问题。连续三次快速空响应后关闭旧连接，转入重连等待；允许短暂的空响应恢复。
- 服务器主动断开通知和读取错误会关闭连接，避免在失效连接上继续等待退出监听。正常来信仍可及时触发同步，保留账号隔离、暂停监听与定时收信回退。
- 将快速监听循环限制为每秒最多四次，等待可被退出信号打断。连续失败按 5、10、20 秒逐步退避，最长 300 秒；仅在连接稳定运行后重置失败次数。
- 新增真实本地套接字关闭、断开通知、读取错误、正常超时、短暂空响应恢复、来信触发、退避递增及退出中断的回归测试，并提供可复跑的离线 CPU 对比工具。
- 修复浏览器形态矩阵测试在多次异步读取间被正常后台刷新覆盖临时测试状态的问题；动作和外观在同一个浏览器任务中采样，保留两条路线、七个阶段及 Chromium／WebKit 的全部原有断言，并增加动作成功启动的检查。
- 免费互动测试在观察区间暂存正常活动心跳，经验与邮票不变的断言完成后放行全部请求，区分互动成本和正常活动奖励；标签浏览器测试等待邮箱切换完成后再创建标签，保留保存成功及失败重试检查。

## 本机验证

- 完整离线门禁 263/263 通过，凭据扫描通过；固定签名身份、升级身份兼容、隔离安装包启动和原生凭据查询检查通过。
- 同一台 Apple Silicon Mac 上，以真实签名安装包连接隔离的合成 IMAP 服务，在进入实时监听后关闭 TCP 连接：v3.9.2 主进程 10 秒平均 CPU 为 102.04%，v3.9.3 主进程 20 秒平均 CPU 为 0.66%；新版重连间隔约 5.51 秒、10.52 秒。
- 上述断线场景中，macOS 进程能量计数换算的主进程估算功耗由约 6.68 W 降至 0.019 W。这是主进程 CPU 能量估算，不含全部 WebKit 辅助进程，也不代表整机功耗或电池续航增幅。
- 安装修复版后，两个现有邮箱在观察期间成功同步；主进程 60 秒平均 CPU 为 0.98%，中位数 0.17%，活动监视器当前“对能耗的影响”为 1.6。该系统相对指标不以瓦特计量。
