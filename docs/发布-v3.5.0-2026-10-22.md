# MailAI v3.5.0 发布记录

- 基准版本：最近 Web／桌面正式版 v3.4.0（2026-10-22T08:28:11Z 已公开），提交 86df0237d8e6ffde51af9345f20e4bdc3b3b697a。
- 变更类型：MINOR。整合新增的事项分组、整组提醒及完成能力，兼容已有 API、任务、邮箱和配置；同时包含界面、提取质量与更新修复。
- 目标版本：v3.5.0，不触发编号上限进位。
- 判断依据：本次完整变更新增可直接使用的待办管理能力，按影响最高的一类升次版本；不能仅按国内更新 403 修复选择修订号。原拟 v3.4.1 仅为未发布准备方案，已并入本版。
- 各端独立：Android 1.4.0、iOS 1.0.0 测试版本保持各自版本线；Android wrapper 仅换行差异不纳入本次代码整合。

## 交付内容

- 按事项归集同一邮件的待办；跨邮件仅关联明确线程或同发件人七天内的明确更正通知，不仅凭常规重复主题合并。截止日期、阶段、任务类型不同仍独立分组；保留各项 ID、来源、编辑与完成状态。
- 支持逐项／分组切换、子事项展开、整组完成及统一提醒。提醒路由在账号库内原子校验开放任务；到期沿用合并通知，保存失败可重试，切换邮箱不串入前一账号。
- 提取同一交付结果时合并准备步骤，普通注意事项放入摘要；更正通知不重复提取引用旧安排。规范化去重保留任务 ID，用户确认、编辑、完成、提醒或等待中的事项不被模型重提取覆盖。工作分析缓存版本随提示词更新。
- 筛选面板更紧凑、即时应用，保留组合条件与移除标签；显示已选数量和结果，补齐待分析风险、优先级、键盘焦点、窄窗口及中英文深浅主题。
- 国内静态更新入口 403 或网络失败时读取固定仓库 updates 分支的官方文件 API。内置 Ed25519 公钥、官方资产 URL、大小、SHA-256 与网络边界校验保留；无效内容／签名直接停止。发布端共用读取及验签规则。
- 待办分段渲染按子项而非组数限制，单个大组也不一次创建大量 DOM；计数与操作范围仍依据完整组。补充千项大组的继续加载回归。
- 列宽恢复回归等待实际布局，装扮回执核对成交响应余额并保留精确扣款断言。CI 的 APT 下载采用 15 秒连接／空闲超时与最多两次重试，保留软件源、包验证与完整浏览器矩阵。

## 验证与发布

- 整合后重新构建前端，执行完整离线门禁、待办分组／账号隔离／并发去重、筛选面板与全量云端浏览器矩阵。发送、移动和删除相关验证仅使用模拟邮件，功能测试使用合成任务和邮箱。
