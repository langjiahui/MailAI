# MailAI v4.5.0

- 基准版本：v4.4.2
- 变更类型：MINOR
- 目标版本：v4.5.0
- 判断依据：新增向后兼容的待办全流程闭环（已发送跟进整合与 AI 一键催办、手动快速新建、快捷推迟与周／月重复周期）、本地日程时间线与 macOS 系统日历直写、周期工作自动简报（周报／月报聚合与 Markdown 表格渲染）、联系人沟通画像与分角色写作签名预设、订阅降噪与自动分流规则中心、发信前多维自检就地标亮与悬停脉冲定位，以及附件全文与历史会话语义检索；既有账号、邮件、待办与配置自动兼容迁移，无需手动转换。

## 待办与发信跟进闭环

- **已发送跟进融入待办中心**：在待办中心新增「发信跟进」视图与逾期跟进汇总，自动追踪等待对方回复的已发邮件，收到回信后自动完成闭环；支持按自动、礼貌、直接、正式四种语气一键由 AI 生成温和催办草稿并填入回信窗口。
- **快速新建、推迟与周期重复**：支持在待办中心顶部直接新建无需关联邮件的手头待办；为单条或整组待办提供「推迟到明天 / +3 天 / 下周一」快捷操作（同步顺延提醒时间）；支持设置每周或每月重复周期，完成当前周期任务后自动生成下一周期新待办。
- **无边框卡片与双语主题适配**：优化待办中心卡片层次、内联标题自动伸缩与勾选动效，适配全部亮暗模式、小邮兑换主题、减弱动态效果（`prefers-reduced-motion`）与低功耗性能模式。

## 日程时间线与系统日历协同

- **多源日程时间线**：在「待办 → 更多 → 日程时间线」与 `Cmd+K` 命令面板中聚合待办截止时间、发信跟进提醒、邮件 `.ics` 会议邀请及自建日程，自动检测重叠时段冲突并按逾期、今日与未来分组展示。
- **批量 `.ics` 导出与 macOS 日历直写**：支持多选日程一键导出标准 `.ics` 文件；在 macOS 端支持读取本机「日历」列表并按稳定 UID 幂等写入所选日程（自动跳过重复项并给出系统权限指引）。

## 周期工作自动简报（周报／月报）

- **多维工作数据聚合**：在「今日日报」弹窗新增「周期工作简报」标签页，自动汇总本周、本月、上月或自定义周期内的收发邮件、已完成与推进中待办、发信跟进及高频协作联系人。
- **流式生成、表格渲染与一键转草稿**：支持结合个人长期工作记忆流式生成汇报提纲（未配置模型时自动使用本地快速汇总），支持 Markdown 表格渲染、在线编辑保存、历史版本管理、复制纯文本或一键转为写信草稿。

## 联系人画像、角色签名预设与订阅分流

- **联系人沟通画像与分角色预设**：结合工作记忆与往来特征识别「汇报对象／领导」「客户／重要外部」「内部同事／协作」「合作方／供应商」四类角色；支持配置各角色的默认语气、称呼习惯、写作要点与专属签名，写信填写收件人时自动匹配套用。
- **订阅降噪与自动分流规则中心**：自动扫描含 `List-Unsubscribe` 或高频通知特征的聚合邮件源，支持一键批量设为已处理、标为已读或移入垃圾箱（自动豁免星标、收藏与安全高危邮件）；支持可视化创建多条件自动分流规则并在新邮件入库时自动执行。

## 发信前多维自检、检索增强与工程模块化

- **非阻断就地标亮与悬停脉冲定位**：扩展发信前本地毫秒级自检，覆盖正文中身份证号、银行卡号、密钥口令等敏感信息外发、正文提及相对日期与当前星期冲突、遗漏附件及跨域名群发回复；以行内下划线标亮风险片段，悬停提示泡时在正文对应位置触发脉冲聚光提示，不阻断正常写信与发送。
- **附件全文切片与历史脉络检索**：将 PDF、Word、Excel 与文本附件切片纳入本地向量语义索引（`fastembed`）及小邮助手检索范围，并在问答与写作上下文中补充同线程历史往来脉络；修复 macOS 打包环境下模型连接 SSL 证书校验问题。
- **前端渐进模块化与状态收敛**：新增 `mailai-state.js` 共享状态与模块注册层，将分享链接、签名管理、备份迁移与三栏宽度拖拽拆分为独立模块，精简样式覆盖并补齐全部新增服务端文案的中英双语映射。

## 验证

- 新增离线测试覆盖待办新建／推迟／周月重复、日程时间线聚合与冲突检测、周期工作简报、联系人画像与角色预设、订阅扫描与分流规则、发信前多维自检、附件语义检索、v4.1.1 历史库增量迁移及前端模块化契约，完整离线门禁 287 项检查全部通过。
- Chromium 与 WebKit 覆盖新增模块交互、全套主题（亮色／暗色／兑换主题）、中英双语切换、键盘与 `Cmd+K` 快捷流、减弱动态效果及低功耗模式。
