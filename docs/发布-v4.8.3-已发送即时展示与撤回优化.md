# MailAI v4.8.3 发布说明

- 基准版本：v4.8.2
- 变更类型：PATCH
- 目标版本：v4.8.3
- 判断依据：本版为 Web 端发送队列在「已发送」中的即时可见性与撤回体验优化，包括在「已发送」接口与分页查询中合并待发送／发送中任务并去重、支持列表行内及详情页直接撤回／编辑、修复发送回调变量遮蔽错误与列表缓存失效时序，以及完善亮暗与收集主题和中英文切换样式；未引入破坏兼容性变更或独立主次新模块，现有账号、邮件、数据库与接口保持兼容。

## 发送体验与一致性优化

- `GET /api/mail/sent`、`GET /api/mailbox/list`（`special='sent'`）与 `/api/mailbox/counts` 合并展示 `outbox` 中 `queued` / `sending` 状态的待发邮件并按 `sent_record_id` 自动去重；为 `outbox` 表补充列表修订序号触发器。
- 新增 `GET /api/mail/outbox/{token}` 供阅读区预览待发邮件正文与安全附件元数据；点击发送后立刻置顶出现在「已发送」列表，卡片与经典表格视图均支持行内「撤销发送」，详情页同步提供「撤销发送」与「编辑邮件」。
- 修复 `app.js` 发信回调中 `const [sent, drafts]` 遮蔽外层状态变量导致刷新中断的问题，缩短发信后状态轮询步长至 1 秒并优先刷新「已发送」视图。
- 为 `.sent-inline-undo` 接入主题变量（`--desk-line`、`--desk-surface`、`--desk-accent`、`--desk-hover`）并补充 `data-i18n` 标记，确保浅色、深色、黑白、宝武等主题与中英文实时切换正常显示。
