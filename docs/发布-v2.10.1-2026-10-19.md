## 修复内容

2026-10-19 实测匿名发行版 API 返回 HTTP 429，正文指出共用账号 p_repoRobot 达到每小时 10 万次阈值；维护者自己的授权 API 正常。客户端改为读取普通公开仓库 updates 分支的 latest.signed.json，经内置公钥验签后使用公开发行版下载入口，避开匿名 API 的可用性依赖。两个官方源仍按较新版本、当前可达性和小范围下载速度选择；已有部分文件继续按固定大小和 SHA-256 续传。

更新通道由镜像脚本在全部附件匿名整包回读校验、国内正式版本确认后推进。采用非强制 Git 推送并保留历史，拒绝较旧版本回写、同版本不同内容；静态文件采用 no-cache 请求并等待 CDN 刷新。主分支、正式标签与安装包不因更新通道推进而重写。维护脚本可以同步历史已发布版本，源码按发行标签推送，历史版本不覆盖较新主分支。

GitHub 云构建上传可使用维护者配置的 ATOMGIT_UPLOAD_EDGE_IP；该值只用于发布任务的 file.gitcode.com 上传，连接保持原域名、SNI 和完整证书验证，并拒绝私网或保留地址。边缘线路失败时重试默认 DNS，不进入客户端默认网络配置。该方式参考 Agentero 官方项目发布经验，当前候选地址已实测通过 file.gitcode.com 的 TLS 主机名与证书校验；值保存在 GitHub 仓库变量，未硬编码到客户端。

## 验证与维护

离线覆盖静态签名读取、无需匿名 API、通道首次创建/推进/幂等、旧版本不回退、同版本冲突与签名篡改拒绝，以及上传线路保留 TLS 主机名、私网地址拒绝、失败回到默认 DNS。实际账号已创建静态通道并完成匿名清单验签及安装包范围请求。最终正式发布须通过完整门禁、精确提交 CI、三平台构建及真实镜像校验。

客户端无维护者令牌或私钥。ATOMGIT_TOKEN 与 UPDATE_SIGNING_KEY 沿用 Actions Secret，令牌仍按维护者要求长期有效；不新增付费域名或云资源。平台匿名 API 限流不通过轮换账号或客户端嵌入令牌处理。
