# MailAI v4.5.1 发布说明

- 基准版本：v4.5.0
- 变更类型：PATCH
- 目标版本：v4.5.1
- 判断依据：修复订阅降噪批处理越界、`.ics` 跨时区日程与多日全天日程截断等现有功能缺陷，并补齐新增功能浏览器端到端 CI 覆盖与文档参数；不新增破坏兼容性的变更或独立主次功能。

## 主要修复与改进

- **订阅降噪批处理范围对齐与提醒保护**：`triage_sender_batch` 严格对齐列表扫描的时间窗口（默认 `45` 天，支持前端透传当前扫描周期 `days`），仅处理时间窗内的同源低噪推送；自动豁免并保留已加星标、收藏以及带有有效跟进（`followup_at`）或稍后提醒（`snoozed_until`）的邮件，不再越界误改历史存档或清除既有提醒。
- **跨时区 `.ics` 日程与多日全天日程保留**：`app/mail_calendar.py` 解析 `.ics` 时区参数（兼容标准 IANA `TZID`、带引号时区、常见 Windows 时区名如 `Eastern Standard Time` 与固定偏移），正确换算为本地时间展示；多日全天 `VALUE=DATE` 事件按 RFC 5545 排他 `DTEND` 准确计算起止区间，日程时间线与批量 `.ics` 导出均完整保留多日跨度。
- **新功能 CI 全端覆盖与文档更新**：将日程时间线、订阅降噪与自动分流、周期工作简报、联系人画像、待办交互、发信前自检 6 项端到端浏览器测试正式接入 `productivity-flows` 套件并在 Chromium 与 WebKit 双内核执行；同步更新 `CONTRIBUTING.md` 中的并发分片默认/上限与矩阵组数说明。

## 验证

- `tests/test_triage_rules.py` 与 `tests/test_calendar_timeline.py` 新增超期邮件/星标收藏/跟进稍后提醒保护、跨时区 `TZID` 换算、多日全天 `.ics` 导出回归用例并全部通过。
- `scripts/ci_browser.py productivity-flows` 在 Chromium 与 WebKit 均全部通过（共 12 次浏览器测试），`tests/test_ci_pipeline.py`、`tests/test_i18n_coverage.cjs` 与 `scripts/check_release.py` 全量离线门禁通过。
