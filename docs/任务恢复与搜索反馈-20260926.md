# 任务恢复与搜索反馈

本轮以本地可恢复任务、真实状态反馈为目标，不引入新的付费服务，不实际调用 COS 或发送真实邮件。

## 大附件

- 文件先保存到邮箱数据库旁独立的 `.share-uploads` 目录，并关联本地草稿，再发起 COS 上传。文件大小上限仍为 2 GB，写入前检查剩余空间；目录和文件仅当前系统用户可访问。
- 本机保存完成后，即使云端上传失败也可以保存并关闭草稿。重新打开同一草稿可恢复任务并手动重试。尚未完整保存到本机的文件不能保证恢复，界面会阻止静默关闭。
- 重试使用稳定的云端对象键，完整结果也保存在本地。响应丢失时重试可复用成功结果；只有下载链接保存到草稿后才清除本地任务和文件。
- 客户端取消等待不会提前删除后台线程仍在使用的文件。进程重启后中断任务转换为可重试状态。
- 删除草稿同时清理其暂存文件；访问任务列表时清理已无关联草稿的任务及超过一天的未完成接收目录。后台正在上传的任务不能删除。
- 浏览器通过 HTTP 向本机保存的百分比与云端上传状态分开展示。这里实现的是任务恢复与重试，不是跨重启的字节级断点续传。
- 存储仍使用已有腾讯云 COS 配置，未新增托管存储或收费认证。

## 删除与移动

“任务与发件箱”展示当前邮箱待同步删除的主题、阶段和错误。失败任务可手动提前重试；保持现有 COPY/DELETE 阶段，不重做已确认的复制步骤，也不绕过未失败任务的撤销窗口。已成功的服务器移动提示明确说明本地状态已更新。移动失败继续使用现有失败项重试入口。

## 搜索

显示搜索中、完成或未完成状态；输入框提供忙碌状态。请求尚未完成时不把空列表当成无结果。搜索失败可原地重试，过期响应不会覆盖新搜索；完成说明搜索范围与“仅已同步邮件”。语义命中继续沿用已有的匹配来源标记。

## 验证范围

新增离线测试覆盖文件完整性、账户隔离、任务重启恢复、取消等待后保留后台结果、稳定对象键及清理；同步重试测试验证阶段和目标 UID 不变。浏览器测试覆盖搜索失败重试、AI 保留及撤销、上传失败关闭并重开草稿后恢复链接，不使用真实 COS/SMTP/IMAP。

最终结果：离线发布检查 164/164 通过；完整浏览器回归及新增任务恢复/搜索重试测试通过；前端产物已重新构建，未发版。
