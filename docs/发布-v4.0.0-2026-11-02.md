# MailAI v4.0.0（Web／桌面）

- 基准版本：v3.9.3（最近已发布的桌面正式版本）。
- 变更类型：MINOR，兼容新功能及界面交互优化。
- 目标版本：v4.0.0。
- 判断依据：完整变更新增礼物工具按套系发放、整套预览与套系命令行入口，先按兼容新功能得到 v3.10.0，再按次版本达到 10 的产品编号上限进位到 v4.0.0。此次编号进位不表示破坏兼容性变更。
- Android 与 iOS 独立维护版本，本次不调整。

## 更新内容

- 礼物工具与小邮共用商品名称、装备部位、套系成员、角色图稿和领取路径。晨光邮局、云间远航、星海巡邮可整套加入、补齐或移除，保留单件与主题搭配；支持小邮雀／小邮鱼预览、整套参考和实际发放清单。超过每券 8 件时提示容量，不丢弃已有选择；新增 `--collections` 发放入口。
- 陪伴设置改为形象与偏好两组，声音、偶尔说话和成长状态更直观。已选形象仍可聚焦，重复选择不发送请求。补齐小邮空间按钮的悬停、按下与键盘焦点反馈，禁用状态和减少动态效果保持正确。
- 陪伴首页将目标和收藏进度放在对应操作旁；单件衣橱使用完整浏览宽度，试穿时展示完整角色，保留筛选、分页和返回焦点；套系试穿明确显示部件名称。
- 今日目标显示各自真实进度，成长旅程增加阶段名称及当前／待解锁状态；成长与兑换记录分组，空状态提供下一步入口。主题、礼物输入及辅助说明区分主次，领取编号不再挡在领取券前。
- 短页面按内容收紧，长页面只在内容区滚动，顶部导航位置保持一致。修复窄窗口下底部入口可能超出可视区域的问题。
- 覆盖中英文、三种主题的明暗配色、窄窗口、两倍字号和键盘操作。原有成长、邮票、库存、穿戴、礼包、领取编号、原密钥和签名协议保持兼容；领取不扣邮票，无成长门槛，并计入套系进度。

## 验证与发布

本地完整离线检查 263/263 通过；Chromium／WebKit 合计 864 个页面、语言、主题、窗口与字号场景通过，包含底部入口边界与文字对比度。真实兑换、穿戴、保存与重启、声音清理、礼物签发／领取、断线恢复、主题切换与多邮箱共享回归通过，凭据扫描无泄漏。

正式发布以定稿候选的原始 full 门禁为凭证，并通过 `scripts/release_desktop.py` 执行同树验证、候选安装包、合并、不可覆盖标签、签名清单、三平台附件和国内镜像核验；本地检查不替代正式 full。
