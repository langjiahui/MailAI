# MailAI v4.7.3 发布说明

- 基准版本：v4.7.2
- 变更类型：PATCH
- 目标版本：v4.7.3
- 判断依据：修复旧版 macOS 更新器选择安装包的兼容性问题，以及批量邮件标签保存后列表刷新可能停在旧状态的问题。现有功能与数据兼容。

## macOS 旧版升级

- GitHub 和国内镜像的本版更新清单向 macOS 提供 PKG。系统安装器处理授权，安装完成后尝试自动打开 MailAI。
- 已安装 4.7.0 或 4.7.1 的用户，可在「设置 → 关于」重新检查更新。即使先前已下载 ZIP，也可在发现 4.7.3 后重新下载匹配的 PKG，按系统提示完成安装。
- 如果应用内更新仍无法进行，可从本版发布页下载 PKG 覆盖安装。已有邮件和配置会保留。

## 邮件标签

- 批量保存时，如果后台邮件变更使分页位置失效，列表会从本次刷新起点重新加载，避免已保存的标签仍显示为旧状态。
