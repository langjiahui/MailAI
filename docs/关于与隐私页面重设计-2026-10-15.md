# 关于与隐私页面重设计

已随 [v2.8.16](https://github.com/langjiahui/MailAI/releases/tag/v2.8.16) 正式发布。

顶部左侧集中展示当前版本、真实更新状态、应用定位和设备/来源/最新发布日期，四个操作分别为检查更新、发布页、项目主页、分享。版本说明保持原生键盘可展开，刷新信息保留展开状态。发布日期来自远程更新清单的 `published_at`，明确标为“最新发布”；缺失或无效则隐藏，不把它当作已安装版本的构建时间。源码模式或不支持的设备显示实际状态，不标记“最新版”。

右侧作者卡使用主题衍生的柔和渐变与弧面，LJH 标识、姓名、身份、简介与联系入口集中排列。联系作者链接到已启用的 GitHub Issues，保留使用帮助入口。保留本地三维标识、拖动旋转、播放暂停、降动效偏好和不可见停绘。

下方统一隐私区域以三个轻边框图标卡片区分本机存储、邮箱连接和模型处理，再以主题底色的确认提示收尾。完整保留原有联网、自动分析、数据保存与人工确认说明。

所有表面、边框、弧面、图标、状态和按钮使用现有语义配色，适配绿色、黑白、宝武蓝及各自深浅模式。中英文切换同步刷新实际设备、更新状态和日期。宽屏双栏且保留阅读宽度；窄屏自动顺排、操作双列；低高度窗口把更新操作提前到元信息之前，保持首屏可达。保留已选定的无边框柔和选中导航和滚动条自动隐藏。

验证使用临时邮箱 fixture 与模拟更新数据，不执行下载安装。Chromium/WebKit 各 84 组关于页检查，涵盖六种配色、中英文、390–3440 像素及 125% 缩放；检查无横向溢出、更新入口首屏可达、隐私说明完整、版本说明展开状态、实际设备和日期显示、新版本弹框、分享及帮助入口，以及日期缺失/无效、源码模式、不支持设备等状态。七个设置页双浏览器回归各 672 组。作者标识实际动画、旋转、暂停、上下文失败回退、不可见停绘及宽窄屏检查通过。

更新设备选择、版本门禁与校验单元测试、国际化框架及覆盖、前端产物一致性和差异空白检查通过。页面专项和作者标识验收已接入 CI。
