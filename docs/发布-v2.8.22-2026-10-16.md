# MailAI v2.8.22 发布记录

新增邮件多标签：支持单封和多封邮件手动添加、移除标签，按发件人、主题和正文自动打标，规则可先测试匹配再保存，并可应用到历史邮件和导入邮件。标签筛选可与 AI 分类、搜索和风险条件叠加；按邮箱隔离数据，修复并发修改覆盖、保存后刷新失败及批量部分失败重试问题，完善中英文、深浅色、长名称和窄窗口交互。

基于已发布 v2.8.21（d0ddba189332efbb33372862a8503bfc214ca3ae）整合邮件标签功能。

本地完整离线发布门禁 242/242 项通过。标准标签流程及 325 封批量、并发修改、部分失败重试、规则预览、中英文、缩放、长名称和跨邮箱相同邮件 ID 的 Chromium / WebKit 检查均通过。

新增标签浏览器检查接入 CI，并为各组检查启动独立合成邮箱。三平台构建、固定 macOS 签名、SHA-256 与更新清单沿用既有发布流程，最终完成状态以 GitHub Release 和产物核验为准。
