# 便携备份与跨平台迁移

MailAI 现在保留两种不同用途的备份：

- **本地备份**用于当前设备快速回滚，仍使用原有 ZIP v2 格式。
- **便携迁移包**用于更换设备以及 macOS、Windows 之间迁移，使用 `.mailai-backup` v3 格式。

## 操作流程

源设备进入“设置 → 数据与维护”，选择“导出到新设备”。默认设置至少 12 位迁移密码并要求再次输入；只有明确勾选确认后才允许生成未加密文件。桌面应用会打开系统“另存为”窗口，可选择目录和文件名；取消选择时，迁移包仍会保留在应用的备份记录中。浏览器模式会使用浏览器下载功能，并提示从下载列表查看位置。

目标设备先安装同版本或更新版本的 MailAI，并登录迁移包所属的同一邮箱。随后在“数据与维护”选择“从旧设备导入”。系统自动识别文件是否加密，只有加密文件才询问密码；随后检查格式、逐文件 SHA-256、数据库完整性、文件数量、展开大小、目标账号和可用磁盘空间，并显示来源系统、导出时间、邮件数量及原文完整性。确认后自动创建当前数据的安全副本并原子安装迁移数据。完成时可以直接开始重新同步。

邮箱授权码和模型 API Key 不会写入迁移包，目标设备需要重新配置这些凭据。

## v3 格式与安全边界

邮件原文按 SHA-256 保存到 `objects/<前两位>/<完整哈希>`，不使用原操作系统中的文件夹名或绝对路径。导入时按目标系统数据目录重建路径，因此不受 POSIX/Windows 路径分隔符、保留文件名、大小写和 Unicode 文件名差异影响。

清单记录 UTC 创建时间、来源平台、邮箱标识、数据统计和格式版本。`checksums.json` 覆盖数据库、清单以及每个邮件对象；未列入校验清单的内容会被拒绝。可选加密使用 scrypt 派生密钥及 AES-256-GCM，采用流式读写，迁移密码不落盘。

导出会清空同步游标和同步任务，冻结待发送、待删除、移动和已读操作。导入邮件先作为本地归档保留，服务器 UID 全部作废。首次同步根据文件夹与 Message-ID 将邮件绑定到目标服务器的新 UID；任何旧设备上的待执行操作都不会重放。

## 故障处理

导入在目标数据目录所在文件系统中完成暂存。安装前自动生成本地安全备份；数据库或邮件目录替换失败时，两者都会回滚。成功导入后需要执行一次邮箱同步，以重新建立服务器 UID 和 UIDVALIDITY 状态。
