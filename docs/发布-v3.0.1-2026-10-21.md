# MailAI v3.0.1 发布记录

- 基准版本：最近 Web／桌面正式版 v3.0.0，发布提交 139afe13f2136919c6da2a4b3d7e2617c15764ad。
- 变更类型：PATCH，兼容的显示、阅读、交互细节与发布性能优化。
- 目标版本：v3.0.1。Android、iOS 使用各自独立版本，本次仅发布 Web／桌面。
- 判断依据：优化现有主题与 HTML 邮件阅读，未新增独立用户能力，也未改变数据格式或配置兼容性；发布流程优化属于内部性能和可靠性改进。从 v3.0.0 递增修订号，不触发编号上限进位。

## 用户可见改进

- 默认深浅主题统一采用中性底色、清晰主文字和辅助文字，已读状态通过字重和未读标记区分，不再压低标题亮度。
- 标题、发件人、地址、预览和计数更易辨认；选中项减弱泛白高光，并省去默认不透明选中背景的模糊采样。
- HTML 正文与阅读区共用主题底色，使用系统字体及 15px／1.8 行高，切换深浅主题时同步更新已挂载的邮件框架。
- 保留邮件图片、签名、引用、顺序、链接安全隔离及浅色发送方原始背景；兑换主题继续独立适配。

## UI 与交互审查范围

- Chromium／WebKit，中英文，默认与兑换主题深浅配色。
- 主文字与正文对比度至少 7:1，受检辅助文字至少 4.5:1；HTML 与阅读区底色一致。
- 浏览器、macOS、Windows 布局，390／760／1024／1512px，系统主题切换和字号缩放。
- 邮件列表选中、键盘切换、“更多”菜单、抽屉、正文选择与安全链接处理；不操作真实邮箱。
- 完整离线门禁及精确发布源码的 CI 检查，平台安装包构建、校验值和签名更新清单。

## 发布流程

测试按功能并行，主分支与标签只复用完全一致源码的有效完整验证；新提交自动取消旧质量任务。历史凭据重新扫描，构建、签名和完整文件校验继续执行。国内镜像由正式发布后的独立工作流同步，可单独重试；既有静态入口的 HTTP 403 独立报告，不使正式发布等待或重新构建。已发布历史标签与安装包不覆盖。

本次从已发布主分支整合上述主题改动；本地尚未合并的邮件导入增强和 iOS 开发保持独立，不进入本次桌面发布。
