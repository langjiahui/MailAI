## 交付内容

- 设置 → 常用设置 → 邮件列表显示方式新增“显示邮件列表头像”，默认开启；关闭后隐藏摘要列表头像并回收左侧文字留白，适配舒适／紧凑密度，经典表格沿用原有显示方式。
- 头像偏好保存在本机，切换列表视图、重载页面、应用重启或本地服务端口变化后继续恢复；偏好键不包含邮箱凭据。
- 设置导航采用完整圆角选中块，统一图标、行高和点击区域，使用帮助／关于与隐私以留白分组；窄窗口使用可横向滚动的分类导航。
- 浅色下使用主题强调色与反色文字；深色下使用柔和主题底色、浅色文字及完整细描边，不添加左侧竖线或箭头。移除分类导航的大底框，覆盖旧主题按页面恢复底色的问题。
- 保留七个设置分类的原有入口、方向键／Home／End 导航及清晰焦点；对默认绿、宝武蓝、黑白的浅深色、中英文、窄屏与放大字号验证。
- 合入主分支已有 CI 分层与完整发布验证优化。根 VERSION 变化触发 full，正式发布仅复用同仓库、完全相同 Git 树的有效 full 记录。
