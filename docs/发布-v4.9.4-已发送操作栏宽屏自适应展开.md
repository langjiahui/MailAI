# MailAI v4.9.4 发布说明

- 基准版本：v4.9.3
- 变更类型：PATCH
- 目标版本：v4.9.4
- 判断依据：本版为「已发送」详情页操作栏宽窄屏自适应切换、弹窗关闭焦点恢复与悬停动效细节修复，未新增独立功能模块，不引入破坏兼容性变更，现有账号、邮件、数据库与接口保持兼容。

## 已发送详情操作栏自适应优化

- **宽窄屏自适应展开与收纳**：`app/web/static/app.js`、`app/web/static/experience-polish.js` 与 `app/web/static/special-reading.css` 为「已发送」详情页补充 `.special-mail-direct-actions` 容器及 `ResizeObserver` / 语言切换测量：窗口宽度充足时直接平铺打印、分享及仅图标形式的删除按钮（含多语言 `aria-label` / `title` 与悬停危险高亮），窄窗口自动收纳进「更多」折叠菜单并同步迁移焦点。
- **弹窗关闭焦点适配窗口变化**：`app/web/static/mail-output.js` 改用触发按钮 `trigger` 动态解析关闭后的焦点落点，窗口在打开弹窗期间发生窄宽切换时仍能准确回落到当前可见的按钮或「更多」入口。
- **直出按钮悬停图标微动效**：`app/web/static/motion.css` 将直出按钮及删除按钮图标纳入 `toolbarIconNudge` 悬停微动效规则。
- **回归测试覆盖**：`tests/test_mail_output_browser.cjs` 补充窄屏收纳、宽屏展开平铺、打开弹窗后缩回窄屏再关闭时的焦点恢复验证。
