# MailAI v4.9.3 发布说明

- 基准版本：v4.9.2
- 变更类型：PATCH
- 目标版本：v4.9.3
- 判断依据：本版为「已发送」详情页主操作按钮补齐悬停图标微动效与减少动态效果适配，未新增独立功能模块，不引入破坏兼容性变更，现有账号、邮件、数据库与接口保持兼容。

## 交互细节与动效一致性优化

- **主操作按钮悬停微动效**：`app/web/static/app.js` 与 `app/web/static/motion.css` 将「已发送」详情页主操作栏的「再次编辑」（`#btn-edit-special`）、「AI 催办」（`#btn-sent-ai-followup`）和「安排跟进」（`#btn-sent-schedule-followup`）接入既有的 `toolbarIconNudge` 悬停图标微动效（对应铅笔、气泡及表盘指针旋转），在 `prefers-reduced-motion: reduce` 下自动禁用。
- **回归测试覆盖**：`tests/test_mail_output_browser.cjs` 增加 `no-preference` 与 `reduce` 两种动态效果偏好下的动画名称断言。

## 验证

- 通过 `scripts/ci_browser.py workspace`（Chromium 与 WebKit 含 `tests/test_mail_output_browser.cjs`）及 `scripts/check_release.py` 完整离线门禁。
- 正式发布继续执行绑定候选提交和 Git 树的完整 `full` 验证，Windows x64、macOS Apple Silicon、macOS Intel 与 Linux x64 完整打包校验及 AtomGit 镜像核验。
