# 小邮 · 邮件信使

悬浮入口、聊天头像和写作助手统一为薄荷色小信使：嫩芽头饰、圆润身体、小脚与信封挎包。采用可缩放的 SVG，不依赖图片生成服务或在线素材。

待机轻呼吸和眨眼；指针靠近时招手、目光轻跟随；分析时显示思考圆点；成功完成分析后短暂微笑。失败或停止生成不显示成功表情。风险状态保留文字、标识和数量角标。

第二版动作：身体与双脚拆分，待机交替换重心、抬脚，手臂跟随身体摆动；嫩芽和信封包延迟摆动。靠近时探身招手，思考时歪头抬手，成功后小跳并带有落地压缩和阴影变化。真实浏览器验证身体、脚、手臂、嫩芽、挎包的变换均随时间变化，动效开关和系统减少动态效果仍覆盖所有部位。

第三版改为统一的短动作编排：查看周围、交替挪步、伸懒腰轮流出现，每段后休息 4–6.5 秒。招手与完成动作具有预备、加速、缓冲和回稳，头部先动、身体跟随，饰物延迟回摆。状态切换从当前姿态过渡；思考和完成优先于指针招手。隐藏入口及后台页面停止动作，减少不必要的渲染。浏览器验证有限动作结束后的静止、工作优先级、成功动作、隐藏入口停止以及两种减少动效方式。

设置 → 常用设置 → 显示与阅读 → 小邮的轻动效，可关闭动画，选择保存在当前设备。系统减少动态效果设置优先，页面进入后台时停止角色动画。

验证包括真实浏览器页面、三处统一头像、成功状态切换、动效关闭及刷新持久化、系统减少动态效果和窄屏布局。使用隔离测试邮箱，不触发真实收发或模型调用。
