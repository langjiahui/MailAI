# 已删除邮件：本地优先

- 打开“已删除”先读本地记录。服务器目录读取、同步失败不会阻止本地查看。
- “彻底删除”作用于所选本地邮件；“清空已删除”作用于当前账号全部本地已删除记录，不受搜索或列表分页限制，不处理仅存在于服务器的邮件。
- 确认后，本地记录删除和后台任务在同一数据库事务中提交。原文文件独立清理；文件占用或权限错误会记录并重试，不回滚为可见邮件。
- 两阶段移动中或同步失败的邮件也可以本地彻底删除；旧任务返回时不会恢复本地邮件。仅受其他清理任务保护的邮件暂时保留，确认窗口说明跳过数量。
- 不保存正文到删除任务中，只保留账号、服务器文件夹、UID/UIDVALIDITY 和内容摘要等校验数据。删除标记长期保留，防止重新同步导入。
- 远端任务在独立、有并发上限的后台线程池中执行，不占用发件队列或前台删除的锁。断网退避重试，任务可跨重启恢复。
- 远端仅删除能确认身份的垃圾箱邮件，要求 UIDPLUS、原 UIDVALIDITY 和原文摘要一致；不执行整个文件夹 EXPUNGE，不搜索其他文件夹扩大删除范围。
- 不支持安全删除、身份变化、或原位置并非服务器垃圾箱时，仅本地完成。用户可在“任务与发件箱”查看远端待同步/仅本地完成/原文待清理状态，并在网页邮箱核对。

删除不可撤销。此功能不清理用户另存的附件、导出文件或历史备份。

“仅本地完成”结果可点击“已知晓”归档，跨重启保留且按邮箱隔离。归档仅隐藏已展示的远端无法确认结果，不移除防回流标记，不停止待同步或原文清理重试；新结果仍会提醒。

回归：`tests/test_trash_purge.py` 验证断网、重启、重试、账号隔离、编号变化、防回流、事务回滚、文件权限和后台阻塞；`tests/trash_purge_browser.cjs` 与 `tests/trash_navigation_browser.cjs` 验证交互与本地回退。
