# MailAI v4.8.0 发布说明

- 基准版本：v4.7.5
- 变更类型：MINOR
- 目标版本：v4.8.0
- 判断依据：本版新增左侧边栏邮箱显示顺序调整与本地持久化能力，属于向后兼容的用户能力；现有账号、邮件、界面偏好、数据库与接口保持兼容。

## 左侧邮箱顺序调整

- 在左侧边栏多账号列表的「邮箱选项（⋯）」菜单中新增「上移邮箱 / 下移邮箱」（英文：Move mailbox up / Move mailbox down）。
- 第一位邮箱不显示「上移邮箱」，最后一位邮箱不显示「下移邮箱」，「所有收件箱」始终固定在列表首位。
- 调整顺序后立即刷新列表并将焦点保持在原邮箱选项按钮上，方便连续移动和键盘操作；新增账号时仍按既定规则追加在末尾。
- 顺序通过独立本地偏好键 `mailai.sidebar.accountOrder.v1` 保存至 `ui-preferences.sqlite3`，跨窗口端口变化、应用重启与页面刷新持久保留；更新静态偏好脚本缓存标识以确保客户端及时加载。

## 验证

- 本地完整离线门禁及浏览器/重启持久化回归验证通过。
- 正式发布继续执行绑定候选提交和 Git 树的完整 `full` 验证、三平台安装包构建及签名、更新清单与国内镜像校验。
