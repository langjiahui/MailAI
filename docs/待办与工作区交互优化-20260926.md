# 待办与工作区交互优化

本轮基于 v2.2.17 修改源码，纳入 v2.2.18 发布。

## 待办中心

- 按全部、今天、已逾期、以后、未安排分类；提醒记录放在同一面板中。
- 卡片按任务标题、截止与提醒状态、来源邮件组织；标题可直接编辑，失败时保留修改并允许重试。
- 主操作为完成，安排入口统一设置截止时间、跟进与提醒；完成后取消提醒，保留记录。
- 批量管理按需展开；全选和完成当前视图只作用于当前分类，切换分类清除不在当前视图中的选择。
- 保留键盘焦点及文本选择，适配深色、窄窗口和减少动态效果偏好。列表按内容高度排版，避免卡片压缩导致操作溢出。

## 同步失败处理

删除同步增加暂停和恢复入口；失败原因默认折叠，已暂停记录默认收起。暂停只改变后台重试时间，不清除失败详情、尝试次数、服务器 COPY/DELETE 阶段或目标 UID；暂停前与后台操作共用互斥锁。恢复仍从原阶段核对，不重复从 COPY 开始。

暂停不表示远端删除成功。原本不确定的服务器状态仍然保留，用户可以核对网页邮箱并恢复同步。本轮没有操作真实邮箱里的失败任务。

## 其他交互

- 附件中心提供卡片和紧凑列表，默认紧凑列表；选择可跨重启保存，预览和下载行为保留。
- 阅读工具栏保留主要操作及文字标签，根据宽度把次要操作移入更多；原有事件处理不变。
- 小邮结果分别呈现主题、正文和落款，主题旁直接填入主题，正文旁替换正文；仍沿用原有签名去重与撤销逻辑，生成中禁用应用按钮。
- 工作面板统一按钮、表单、键盘焦点和禁用状态，不影响邮件原文的排版。

## 验证

- 168/168 离线发布检查通过。
- 隔离测试邮箱验证暂停/恢复、不同删除阶段保持、账号隔离与操作并发冲突。
- 浏览器验证 148 个附件的卡片/列表布局、预览后返回、390–1512 像素窗口、深色布局、待办筛选与批量范围、提醒设置/完成、编辑保存失败恢复、小邮分区及流式生成期间按钮状态。
- 14 项界面偏好通过新浏览器、服务器重启和端口变化后的持久化测试。
- 当前实际执行环境为 macOS 上的 Chromium；Windows 原生窗口和系统通知未在 Windows 机器上实测。本轮未修改系统通知底层实现。

## 视觉复审

待办面板收窄至 900px，并随内容高度调整，长列表在面板内滚动；分类改为下划线页签及独立数量标记，提醒记录与任务筛选区分。列表移除重复卡片外框，采用轻分隔线；日期与来源字号增大，当前年份日期缩短显示，完整日期保留在提示中。安排提醒与完成并排，区分次要与主要操作。空分类给出明确说明和返回全部待办入口。

附件紧凑列表增加文件名称、来源邮件、大小、邮件时间列标题，卡片/列表切换合并成分段控件。继续沿用应用色彩和字体，不增加装饰动画。

视觉复审后的验证：168 项离线检查通过；浏览器验证 60 项待办、150% 界面缩放、空分类返回、深色及窄窗口、编辑重试、提醒操作和附件滚动。预览图片使用隔离的示例任务，不包含真实邮箱数据。

## 其他页面复审

- 设置页在宽窗口采用左侧导航，缩短顶部区域；窄窗口恢复横向导航，内容独立滚动。选中导航提供可访问状态，引导提示不再遮挡设置内容。
- 通讯录按内容调整高度，联系人采用轻分隔线；只有选中分组后才显示对应管理操作。写邮件、编辑和移除区分层次，窄窗口仍可访问全部操作。
- 写信与小邮面板在宽窗口上下对齐，宽度分配考虑界面缩放；小邮较窄时生成按钮独占一行。补足深色模式下标签对比度。
- 浏览器检查 390、760、1200、1440 像素窗口及 150% 实际界面缩放，五个设置子页无横向内容溢出。通讯录浅色/深色分组管理、收件人选择、备份恢复及小邮生成应用回归通过；168 项离线检查通过。
