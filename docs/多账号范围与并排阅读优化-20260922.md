# 多账号范围与并排阅读优化

## 已完成

- 任务与发件箱增加邮箱选择。切换只改变面板查看范围，不改变当前阅读邮箱；重试同步、撤销发送、打开草稿、提醒处置继续使用各自所属账号。旧账号请求的成功或失败结果不会覆盖新范围。
- 列表工具区显示联系人、附件、待办、日报当前所属邮箱，入口的提示和无障碍名称同步带上邮箱。联系人、日报保留已有的账号隔离机制。
- 待办中心使用独立数据和打开时的账号。编辑、完成、批量完成、安排提醒、来源邮件跳转均绑定该账号；后台邮箱刷新不会替换面板数据。加载和批量操作期间禁用批量入口，失败提供重试。附件中心同样绑定账号，下载链接明确携带账号，并忽略过期请求。
- 自动布局下，按字号折算的有效窗口宽度在 1024–1599 时，临时收起邮件列表，正文与小邮并排；更窄的并排窗口也临时收起文件夹栏。关闭助手恢复原列表滚动位置，不改变用户保存的栏宽。1600 及以上保留列表并排布局；1024 以下提供全窗口小邮和明确的“返回邮件”。手动浮动窗口保留原行为。
- 修正任务面板暗色标题、分隔线和健康状态的对比度。
