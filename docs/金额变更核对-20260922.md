# 金额变更核对

会话进展卡中的“变化线索”支持正文明确写出的“总价从100元改为120元”等金额调整，并保留原文、来源邮件和提议/原文表示已确认/待核实标记。

只有明确总金额、两端币种相同且未发现税费、单位、折扣、约数等歧义时，才使用十进制精确运算展示差额。支持人民币、美元、港币、欧元，数字支持千分位、小数和万元；裸“元”按人民币处理。币种缺失或不同、单价及口径含糊的表述仅提示核对。共同含税说明不会覆盖单位、运费等其他歧义。

这是有限规则的证据提示：暂不覆盖所有币种符号、金额写法或插入复杂限定词的句式，不做跨邮件金额推断，不把建议认定为最终报价。未出现提示不代表没有变更。不会修改待办、代替确认或发送邮件。

验证覆盖：小数精度、千分位、万元、较大金额、币种差异、税费和单位歧义、否定、引用隔离、多条变更及前端展示。
