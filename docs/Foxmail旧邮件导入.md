# 将 Foxmail 旧邮件导入 MailAI

入口在 **设置 → 数据与维护 → 从 Foxmail 导入**。也可在 **设置 → 邮箱账号** 中选中邮箱，点击 **导入旧邮件**。

1. 在 Foxmail 中下载完整邮件及附件，再使用导出功能保存为 **EML 或 MBOX**。如需保留文件夹名称，把收件箱、已发送等邮件分别放在总目录下的子目录中。
2. 打开 MailAI 的导入窗口，核对目标邮箱，选择邮件文件或整个导出目录。目录中的非邮件文件会自动跳过。
3. 点击 **扫描并去重**。查看待新增、重复跳过和无法导入的数量；扫描时会显示当前文件和实时统计；完成后可展开邮件预览、各文件夹预计新增数量及问题文件列表。扫描不会添加邮件。
4. 点击 **导入缺少的邮件**，完成后点击 **查看导入邮件**，或从左侧目标邮箱进入 **本地归档**。

原始邮件、正文、附件和邮件日期会保留。导入邮件默认已读，仅保存在 MailAI 本机，不上传邮箱服务器，也不会修改 Foxmail。可阅读、回复、转发、收藏和下载附件；服务端星标及移动功能不可用于本地归档。

## 中断及异常

| 界面提示 | 如何处理 |
| --- | --- |
| 没有需要新增的邮件 | 邮件已在 MailAI 中，无需重复导入。 |
| 无法识别或格式不完整 | 展开问题文件列表，在 Foxmail 中重新导出对应邮件；下载完整问题清单可查看全部原因（窗口最多显示前 30 项）。其他正常邮件仍可导入。 |
| 文件添加未完成 | 点击「重新选择」，再次添加整批文件。不会自动导入只有一部分的文件。 |
| 已暂停 | 点击「继续」。扫描会重新核对整批文件；导入会跳过已成功保存的邮件。 |
| 磁盘空间不足或写入失败 | 清理磁盘后点击「继续」。已成功的邮件会保留。 |
| 关闭窗口或重启应用后想继续 | 再次打开导入窗口，展开「最近导入记录」，选中相应任务。 |

单封邮件最多 64 MB；单个 MBOX 文件最多 1 GB；每批最多 10 GB、20,000 个文件和 200,000 封邮件。超出时请在 Foxmail 中分批导出。

本版读取导出的 EML/MBOX 文件，不直接读取 Foxmail 的 Storage、.fox 等内部数据库。首次导入建议先选少量邮件，确认正文和附件完整，再导入其余历史邮件。导入后的邮件和附件可通过 MailAI 的本机备份或迁移包保存。
