# MailAI v4.1.0（Web／桌面）

- 基准版本：v4.0.2，最近已发布的桌面正式版本。
- 变更类型：MINOR，新增兼容的撤销换装能力。
- 目标版本：v4.1.0，次版本由 0 升至 1，修订号归零，未达到编号上限。
- 判断依据：本次完整变更新增原子撤销上次穿戴的独立用户能力，并重整既有衣橱、试穿、兑换确认、套系及礼物操作；原有接口、配置与本机数据继续兼容，不涉及破坏性变更或用户手动迁移。
- Android 与 iOS 独立维护版本，本次不调整。

## 更新内容

- 衣橱采用背包式布局：人物和六个实际穿戴部位与物品货架同屏，物品使用自身缩略图；按全部、已拥有、可兑换及部位筛选和分页，日常换装不再进入独立试穿详情页或选择预览模式。
- 点选已拥有的物品立即穿戴；点选同一件不会误卸下，卸下在物品详情明确操作。穿戴、卸下后的大图显示实际保存结果，并与悬浮小邮、聊天及写信助手保持一致。
- 未拥有的物品可先试穿，不扣邮票、不改实际穿戴；兑换前展示物品、本次花费和兑换后余额，确认后才兑换并穿戴。未解锁、邮票不足和每日使用上限沿用既有校验。
- 新增撤销上次穿戴，一次恢复头饰、颈饰、身体／邮包、背饰、配色与光效；保持库存、成长、邮票、兑换记录及工作区主题。服务端校验库存与部位，在单一事务内恢复；另一窗口已改变装扮时不覆盖其结果，已提交但响应丢失的恢复请求可安全重试。
- 套系、礼物、成长与衣橱入口衔接；整套穿戴后显示实际结果，首页返回后保留套装动作。领取的高阶礼物仍可跨成长等级免费穿戴，旧领取券和原密钥兼容。
- 衣橱导航随内容正常滚动，避免窄窗口和大字号时盖住物品点击；桌面人物区保留侧栏跟随，窄屏按内容堆叠。
- 保留筛选、分页、所选套系及键盘焦点；取消兑换返回价格操作，结束试穿返回原物品，提交期间禁用冲突操作并显示等待反馈。
- 保留七阶段形态和动作体验、暂停和后台清理、减少动态效果；适配中英文、默认／黑白／宝武主题的明暗外观、窄窗口及大字号。

## 验证与发布

功能定稿的本地完整离线门禁 264/264 通过，凭据扫描无泄漏。Chromium／WebKit 衣橱回归覆盖各 432 个语言、主题、页面、窗口和字号组合，并补查选中物品及新控件的对比度。两种浏览器分别验证 72 个未拥有物品／兑换确认布局、72 个大字号背包布局、16 件真实兑换、两条形象路线的直接穿戴／卸下／撤销、实际造型一致、重复提交保护、失败重试、键盘操作、重载持久化及悬浮／聊天／写信头像动作。成长与响应丢失恢复、礼物领取与发放工具、共享主题及页面回归通过；服务端覆盖原子恢复、旧别名兼容、库存与部位校验、并发更改保护和重试。

VERSION、README 和本记录定稿后，以 `scripts/release_desktop.py --execute --head <候选提交>` 并行启动私有三平台候选包和原始 full。正式发布只接受绑定定稿候选相同 Git 树与测试提交的原始 full，再执行同树合并、不可覆盖标签、三平台安装包、签名更新清单及国内镜像校验。本地结果不替代正式 full。
