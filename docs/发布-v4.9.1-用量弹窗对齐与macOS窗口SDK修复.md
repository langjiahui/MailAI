# MailAI v4.9.1 发布说明

- 基准版本：v4.9.0
- 变更类型：PATCH
- 目标版本：v4.9.1
- 判断依据：本版为「模型用量统计」弹窗界面与主题样式对齐修复，以及 macOS 安装包可执行文件保留引导程序 SDK 26+ 版本头的打包修复；未新增独立主次功能，不引入破坏兼容性变更，现有账号、邮件、数据库与接口保持兼容。

## 界面与打包修复

- **模型用量统计弹窗对齐设置面板风格**：`app/web/static/model-usage.js` 与 `app/web/static/style.css` 接入 `.productivity-dialog` / `.productivity-body` 结构及 `--desk-*` 主题令牌，指标栏改用语义化 `<dl>` 与可聚焦滚动表格 `<th scope>`；仅在内容变化时重绘以保持横向滚动与焦点位置，并响应语言切换实时刷新。
- **macOS 安装包保留原生窗口控制 SDK 版本**：`MailAI.spec` 在 `EXE(...)` 后校验并恢复 PyInstaller 引导程序的 macOS SDK（要求 `>= 26.0`），避免 PyInstaller 按 Python 运行时 SDK 封顶导致封装后应用丢失系统原生窗口控件。

## 验证

- 通过 `scripts/ci_browser.py responsive-dialogs`（Chromium 与 WebKit 覆盖亮暗/主题配色、窄屏与弹窗交互）及 `scripts/check_release.py` 完整离线发布门禁。
- 正式发布继续执行绑定候选提交和 Git 树的完整 `full` 验证，Windows x64、macOS Apple Silicon、macOS Intel 与 Linux x64 完整打包校验及 AtomGit 镜像核验。
