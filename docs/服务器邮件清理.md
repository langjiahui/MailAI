# 清理服务器邮件

入口：设置 → 数据与维护 → 清理服务器邮件。支持手动执行，以及默认关闭、按邮箱独立保存的自动清理。

## 自动清理

1. 点击“自动清理设置”，勾选“启用此邮箱的自动清理”。
2. 选择一个服务器文件夹、保留最近 30 / 60 / 90 / 180 / 365 天，以及每天或每周执行。默认保留 90 天、每天执行；早于截止日期的邮件才会入选。
3. 阅读说明，勾选授权并输入当前邮箱地址，点击“保存设置”。规则修改后需重新确认。关闭自动清理无需再次授权，也不需要连接邮件服务器。
4. 首次在保存后的一个周期结束时执行；以后从实际完成时间计算下一次。应用运行时每 5 分钟检查，邮箱有其他操作时延后；关闭应用期间不会执行，下次启动后补执行一次，不累计补跑。卡片显示启用状态和下次执行时间。

自动清理始终排除本地收藏、星标及服务器星标邮件，跳过未同步、原文不完整、正在移动、已保留本地或结果不明的邮件。每次最多清理一批 50 封、100 MB，单封不超过 50 MB。每轮最多扫描 500 封，扫描进度在下个周期继续，避免受保护的旧邮件一直挡住后面的邮件。每批先逐封校验原文、保留本地完整副本并创建安全备份，再使用 UIDPLUS 精确删除；不会清除文件夹中其他邮件。

备份失败、连接异常、校验失败或应用中断后自动暂停。卡片显示原因，最近清理记录标记“自动执行”。核对服务器及清理记录后，可在设置中重新授权启用；结果不明的邮件仍被保护，不会重新删除。应用退出时正在执行的任务不能保证完成，重启后不会继续上次删除。关闭开关并保存即可停止后续周期。

## 手动清理

入口：设置 → 数据与维护 → 清理服务器邮件 → 选择清理范围。

1. 选择服务器文件夹及 30 / 60 / 90 / 180 天以前，或自定义截止日期。不包含截止当天，依据本地记录的邮件日期。
2. 默认排除收藏和星标；只有主动勾选才包含。
3. 点击预览。仅处理本机已同步、具有完整原文，并经服务器逐封校验内容一致的邮件。每批最多 50 封、100 MB，单封不超过 50 MB；可查看下一批，跳过未满足条件的邮件。
4. 核对主题、发件人、日期和大小，勾选风险确认并输入当前邮箱地址。
5. 点击“备份并清理服务器”。先完整保存本地原文及创建安全备份，再删除已确认的服务器副本。此操作只执行当前批次，不会自动重试失败的删除；自动清理由独立开关控制。

服务器副本删除后，网页版及其他设备可能无法再查看；本地备份恢复不会重新上传邮件到服务器。本机邮件仍在原来的收件箱、已发送等文件夹中，保留原文、附件、收藏和已读状态，无需进入单独的归档目录。后台标记服务器副本已清理，后续同步不会隐藏本地邮件；这些邮件不再参加服务器移动或删除操作。

服务器必须支持 UIDPLUS 精确清除，否则会拒绝操作。预览有效期为 10 分钟；执行前再次验证当前账号、文件夹 UIDVALIDITY、原文及收藏状态。预览单次使用，不能重放。修改范围会清除之前的确认。

备份失败或校验失败时不会开始删除。连接中断时保留本地邮件，清理记录显示“服务器结果需要核对”；未确认的邮件不会自动重试。应用意外退出留下的运行记录也不会在重启后继续删除。可在入口的最近清理记录中查看结果及安全备份文件名。执行过程中不应退出应用。

## 验证

`tests/test_server_cleanup.py` 使用独立临时数据库和模拟 IMAP，覆盖确认校验、收藏保护、账号/过期预览、UIDVALIDITY、原文变化、UIDPLUS 限制、备份失败、断线、重复提交、附件及本地邮件原位保留、分页和精确删除，以及自动清理默认关闭、规则授权、到期执行、周期保存、失败暂停、中断不重放、账号隔离和忙碌延后。

`tests/test_server_cleanup_browser.cjs` 配合 `MAILAI_CLEANUP_FIXTURE=1 tests/workspace_preview.py`，验证浅色与深色主题、自动规则启停和持久化、修改规则清除授权、加载失败保护、离线关闭，以及手动预览、确认、清理记录和原位阅读。全部测试使用模拟服务器，未对真实邮箱执行清理。
