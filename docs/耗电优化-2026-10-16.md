# MailAI 按需动效与后台调度优化

保留轻动效开关及小邮外观。前台空闲时每隔 8～15 秒播放一次轻微呼吸、眨眼或歪头，动作结束后重新随机等待；较大动作在 40～70 秒后具备触发条件，在下一次空闲动作时播放。输入和滚动后的 15 秒内推迟较大动作，写信小邮仅保留微动作。同一时刻只安排一个小邮播放日常动作，期间装扮特效保持暂停。成功打开另一封邮件、打开助手或悬停小邮时播放短动作，约 3.5 秒后暂停。刷新同一封邮件不会重复触发。AI 请求进行期间保留工作动作，结束或取消后停止。

自然信使使用轻呼吸、歪头、伸懒腰与招手；星际先锋使用点头、观察、巡视、整理姿态与抬手致意。工作与完成状态也有各自的动作片段。皮肤切换时正在进行的工作或完成反馈会从当前姿势衔接到新皮肤动作，空闲动作则停止并重新等待；未知皮肤安全回退到自然信使。颜色主题沿用角色动作，服装、翅膀、面罩继续跟随所属身体部位。

窗口失焦、隐藏、组件离开可视范围，以及助手打开后被透明隐藏的悬浮入口，同时停止 JavaScript 和 CSS 动画。恢复前台不会补播已经过去的短动作，仍在进行的 AI 请求可以恢复工作动作。装扮商店保留明确的预览播放与暂停操作。

其他优化：

- 切回窗口时保留刷新截止时间，仅处理到期任务或明确积压的更新，避免反复切换窗口触发整批请求。
- 养成计时在前台操作期间维持 10 秒采样；停止操作 90 秒后改为 60 秒检查，重新操作后恢复，并丢弃空闲时间。
- 首次养成状态尚未成功读取时保留 10 秒重试节奏，避免临时连接失败也被空闲降频延后；成功加载后的正常空闲才降低频率。
- 发件箱遍历和截止时间计算跳过已隐藏账号，清理对应内存重试记录，解决保留本地历史的已登出账号反复报“邮箱账号不存在”。
- 关于页面的 WebGL 标识在失焦和原生窗口隐藏时停止绘制。
- macOS 原生应用激活、失活、隐藏及窗口最小化/恢复事件直接通知节能调度器，避免 WKWebView 保留 DOM 焦点时继续运行。页面加载完成后重发状态，重复原生通知不重复触发刷新。
- 后台收信、定时发送及到期待办提醒继续使用原有后台服务。

## 验证

随机日常动作调整后，Chromium 与 WebKit 均通过空闲调度、微动作不连续重复、长时间空闲的大动作、持续输入推迟大动作、工作状态打断、失焦不补播、减少动态效果停止、装扮保持暂停，以及眨眼结束恢复睁眼的检查。两种皮肤分别验证日常动作、招呼、工作和完成反馈，并覆盖工作中切换皮肤与未知皮肤回退。另通过 Chromium 的 90 组装扮运动兼容检查。前端构建及新鲜度校验通过。

使用临时邮箱、模拟邮件服务与独立浏览器，无真实邮件发送。原节能方案的 Chromium 与 WebKit 验证覆盖默认静止、打开邮件触发、短动作停止、同邮件刷新、失焦与恢复、视口移出、原生隐藏、正在执行的模型请求、写信小邮及减少动态效果。既有模型生命周期、90 组装扮运动、商店预览、翅膀裁切与关于页面测试通过。后台测试覆盖隐藏账号、空队列休眠、发送/提醒截止时间与写入唤醒。
