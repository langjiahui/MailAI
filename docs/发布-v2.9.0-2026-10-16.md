# 发布 v2.9.0 · 2026-10-16

- 基准版本：GitHub 最新正式版 `v2.8.22`（`670e137424e1ed926aba388a99e82195cf7795af`）。
- 变更类型：MINOR。
- 目标版本：`v2.9.0`。
- 判断依据：新增向后兼容的 macOS 原生菜单栏与快捷键能力，同时包含通知和界面修复。旧邮箱、配置和邮件数据继续使用，数据库扩展自动迁移；按本次影响最高的新增功能升级次版本，修订号归零。

## 发布内容

1. macOS 原生菜单栏：应用、编辑、显示、窗口、帮助菜单；设置、字号、全屏等快捷键；语言即时切换、页面加载排队和草稿保护。
2. macOS 通知：统一现代接口，修复系统拒绝旧通知请求；后台提交确认、持久化领取租约和失败重试；正确区分邮件与任务的点击目标，已读邮件不补弹。
3. 邮件标签：入口并入现有操作栏；无标签邮件取消独立占行，有标签时在元信息区紧凑展示，完整标签仍可查看和编辑。
4. 主题细节：发件箱数量徽标使用当前主题的强调色和配对文字色，覆盖默认绿、黑白和宝武蓝的深浅模式。
5. 维护规范：新增项目总要求及版本分级规则，恢复已有引导检查并将原生菜单浏览器检查纳入 CI。

## 发布验证

发布前执行整合分支的完整离线门禁，并在隔离邮箱验证菜单、标签及主题界面。发布产物由 Windows、macOS、Linux 工作流构建，校验安装包、SHA-256 与自动更新清单。

本地验证：完整离线门禁 **244/244** 通过；原生菜单和邮件标签的 Chromium / WebKit 检查通过，14 项偏好重启持久化检查通过。发件箱徽标已在三套主题的深浅色、悬停与展开状态核对，字色对比度均不低于 4.5:1。CI 将针对同一发布提交复核。

云端首轮发现原生菜单英文测试遗留共享语言偏好，已补齐测试状态清理，并让邮箱切换检查显式设置断言语言；正式发布前重新执行门禁。
