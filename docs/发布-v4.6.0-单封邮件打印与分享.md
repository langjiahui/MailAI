# MailAI v4.6.0 发布说明

- 基准版本：v4.5.3
- 变更类型：MINOR
- 目标版本：v4.6.0
- 判断依据：新增单封邮件打印、PDF 分享和原始邮件导出，现有邮件、配置及工作流程保持兼容。

## 单封邮件打印与分享

- 打开邮件后，从阅读区「更多」进入「打印邮件」或「分享邮件」。已发送邮件的详情也提供这两个入口。
- 「打印邮件」将主题、邮件头、正文和附件清单交给系统打印服务。
- 分享面板可从当前邮件直接生成 PDF、复制完整正文，或导出现存的原始 EML。支持系统文件分享的环境可直接选择接收应用，其他环境可保存 PDF。Web 版使用运行 MailAI 的设备上已安装的 Chrome、Edge 或 Chromium 生成 PDF。
- 大幅预览面板适配明暗主题和窗口尺寸。长邮件可在正文区滚动，底部操作保持可见。打印和 PDF 使用浅色纸张版式。
- 原始 EML 可用时保留完整邮件头和附件。输出过程使用本机数据，远程图片省略并提示。

完整操作见 [单封邮件打印与分享](单封邮件打印与分享.md)。
