# MailAI v4.4.1

- 基准版本：v4.4.0
- 变更类型：PATCH
- 目标版本：v4.4.1
- 判断依据：修复现有单封分析状态不同步和交互闭环，调整已有界面并按需求结束重复分析入口，保留账号和邮件数据兼容。

## 更新内容

- 融合安全状态和开始分析入口，在原位呈现检查、模型复核、保存及同步进度。
- 分析完成后同步邮件详情、列表徽标和侧栏风险统计，切换邮件或重新进入时可恢复任务状态。
- 已分析邮件保留结论和依据，不再提供重复分析入口；失败可重试，结果同步失败可单独刷新，不重复运行分析。
- 升级保留账号、邮件、原件和人工反馈。Android 与 iOS 版本独立。

## 验证

完整离线门禁、凭据扫描、Chromium 和 WebKit 回归、平台安装包、签名与镜像校验。
