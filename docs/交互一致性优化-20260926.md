# 交互一致性优化（2026-09-26）

本轮集中处理待办编辑、列表刷新、常用确认弹窗和连接恢复，未发版。

- 待办标题/日期在行内显示未保存、保存中、已保存和失败原因；失败可重试，同一页面关闭后重开仍保留未保存输入。刷新/离开页面存在未保存修改时使用浏览器原生离开提示。连续编辑按任务串行保存，安排或完成前先保存该任务的修改。
- 待办和提醒列表按项目标识更新，保留未变化的节点、滚动位置及键盘焦点。后台刷新失败保留已有数据。提醒动作处理期间不刷新或重复提交。
- 舍弃草稿、移除联系人、全部完成待办、新建邮箱文件夹、修改邮箱显示名改用主题一致的弹窗。危险操作显示红色按钮、默认焦点在取消，Esc 只关闭确认层。尚未替换迁移/备份等低频系统确认框。
- 本地服务连接失败使用有超时的只读健康检查。已知邮箱/模型接口失败显示各自的设置入口。恢复连接不自动重放发送、移动、删除等操作。

验证：167 项离线检查通过；隔离邮箱浏览器验证涵盖失败保留/重试、连续编辑、焦点恢复、草稿舍弃、深色窄屏、提醒刷新、连接分类和不重复提交。浏览器回归加入 PR 检查。未操作真实邮件、调用真实模型或发出系统通知。

界面使用 Windows/Mac 共用的前端实现；本轮浏览器验证运行在 macOS Chromium，不能替代 Windows 安装版和 macOS WebView 实机验收。
