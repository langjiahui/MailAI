# MailAI v3.8.0 发布记录

- 基准版本：最近 Web／桌面正式版 v3.7.0（北京时间 2026-10-26 16:03:57 已公开），提交 09319f4877cdc6a661d7870e3cc7b1da4f5057e5。
- 变更类型：MINOR。
- 目标版本：v3.8.0，不触发编号上限进位。
- 判断依据：本次完整交付将原先需要手动补下载的 50–256 MB 邮件扩展为自动分段收取，补查旧版本仅留数量的历史大邮件；最高影响为向后兼容新能力 MINOR，次版本加一、修订号归零。标题栏、连接兼容性和状态恢复同时按修复交付，既有邮箱、邮件、配置和偏好继续使用。
- 各端独立：仅发布 Web／桌面；Android 与 iOS 版本、安装序号及各自开发改动不纳入本次发布。

## 交付内容

- 大邮件自动按有界分段保存到磁盘，支持至 256 MB，复用大邮件投影解析保留原件及附件；只保存本机副本，不标记服务器已读、不移动或删除服务器邮件。未经完整安全复核的大邮件保留未复核状态，不误标安全，也不自动执行安全移动。
- 增量收信和历史完整同步接入自动下载；成功后移除问题记录并更新数量，失败保留精确文件夹、UID、大小及重试记录。历史大邮件不重复发送新邮件通知，保留服务器已读和星标。
- 补查旧版本只记录数量的未下载邮件，升级原先 24 小时跳过的可处理大邮件记录；超过 256 MB 留下准确问题记录，提供原邮箱下载说明，不宣称支持无限大小。
- 首次 IMAP 连接遇到临时网络错误最多尝试三次；授权失效和证书错误保留明确处理入口，沿用后续后台调度。补齐登录后、选择文件夹前的 RFC 2971 IMAP ID，覆盖普通授权码和 OAuth 登录、连接检查及 IDLE 使用的统一登录入口；仅发送产品身份，不发送账号或凭据。
- 区分自动重连、重新登录和证书检查，问题窗口以最新同步结果清除旧失败，完成后刷新邮箱状态与邮件列表。
- macOS 标题栏拖动与双击区域仅在原生桥成功回应后缓存，失败有界重试并重测最新几何；桥就绪时独立同步，字体与标题栏内容变化时更新，保留控件及顶部小邮排除区域。

- 修复 WebKit 大组待办翻页时移除正在激活的按钮而导致点击超时；行更新保留稳定操作按钮，增加真实指针点击及 DOM 连续性断言。翻页使用独立任务完成渲染，避免无绘制帧时延迟；大组标题高度测量批量读写，减少逐项强制布局。
