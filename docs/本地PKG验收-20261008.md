# MailAI 2.3.15 本地 PKG 验收

安装包为本地验收版，未上传到 Releases。文件为 `dist/MailAI-local-2.3.15-20261008-ui3.pkg`，约 74.6 MB。适用于 Apple Silicon Mac。安装前保存草稿并退出旧版 MailAI，再双击 PKG 按安装器步骤完成安装；安装完成后重新打开应用。已有本机账号、邮件和草稿由新版本继续读取。

## 建议验收流程

| 项目 | 操作 | 应看到的结果 |
|---|---|---|
| 搜索与筛选 | 点击搜索框右侧筛选图标，组合发件人、日期、附件名；搜索所有账号 | 条件同时生效，结果标明所属账号；搜索完成后可直接浏览结果 |
| 简洁列表 | 打开全部邮件，再展开筛选 | 默认顶部仅有标题、数量、排序和筛选；重点/已有处理标记在筛选中；阅读区没有额外的处理工具行 |
| 模板和短语 | 写信保存模板，选中正文位置插入短语，再撤销 | 模板可复用；短语只改变选中位置，不覆盖其他正文、附件或签名 |
| 发送安排 | 在写信底部设置定时发送和未回复提醒，保存草稿后重新打开 | 时间与跟进选项恢复；点击发送后任务进入发件箱，可取消尚未开始的任务 |
| 条件跟进 | 发送测试邮件后安排提醒，再同步关联回复 | 正常关联回复会取消跟进；同主题的无关邮件不会取消；没有回复时只提醒，不自动催办；发送结果不确定时先核对，人工确认送达后跟进安排恢复 |
| 阅读与引用 | 打开有历史引用或明确签名标记的邮件 | 正文优先展示，历史引用和签名可展开，原文内容保留 |
| 发件箱管理 | 对一封尚未发送的定时邮件修改时间，再点击编辑 | 列表显示计划时间；编辑前暂停原任务，草稿保留修改后的时间；已经开始发送的任务拒绝编辑或取消 |
| 附件 | 在附件中心“查找文件内容”选择文件并搜索内容，比较两个同名附件 | 展示提取文字和差异；超时或格式不支持时保留原文件并给出说明 |
| 展开写信与局部润色 | 展开写信，打开帮写；选中正文一段文字，润色、应用、撤销 | 帮写位于右侧，不遮挡编辑区；选区以外正文和签名保留，撤销恢复原文；没有独立窗口入口 |
| 通讯录与分享 | 预览导入联系人；已有 COS 配置时上传测试文件并重新生成分享链接 | 默认保留已有联系人；链接可查看到期时间，新链接不修改旧邮件 |
| 运行诊断 | 在数据与维护点击开始检查 | 立即展开全部检查项；等待、检查中、通过、注意或失败逐项更新，显示总进度与耗时；中断保留已完成结果 |
| 外观 | 切换浅色和暗色，调整字号、窗口宽度 | 筛选图标与页面风格一致，主要操作可访问 |

## 服务配置与验证范围

Google 和 Microsoft 官方登录需要注册的客户端 ID 和用户在官方页面授权；Google 桌面应用在需要时还须填写客户端密钥。可从邮箱设置进入官方登录。真实收发取决于邮箱是否启用 IMAP/SMTP 及组织权限。

AI 写信与摘要复用已有模型配置；COS 功能复用已有存储桶配置。没有相应配置时，应用应明确提示并保留当前内容。

201 项离线门禁、示例邮箱浏览器操作、安装包内容核对和解包应用启动体检已通过。真实邮箱授权、投递、后台系统通知和原生多窗口的实际操作以本次验收结果为准；Windows 安装包不在本次交付范围内。


本次 UI 验收补充：通讯录导入与导出分为两个标签页，导入需预览确认；附件内容搜索直接读取选定文件，比较结果按第一份/第二份分色展示；已分享文件说明创建、到期与重新生成的步骤；局部润色先关闭建议弹窗再写入正文，并支持撤销。三个邮箱图标改为信封、收件托盘、向外箭头托盘，减少装饰线条。
