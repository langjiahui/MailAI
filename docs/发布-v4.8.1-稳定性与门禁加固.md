# MailAI v4.8.1 发布说明

- 基准版本：v4.8.0
- 变更类型：PATCH
- 目标版本：v4.8.1
- 判断依据：本版为兼容性稳定性修复与内部模块化整理，包含 WebKit 缓存列表滚动位置恢复时序修正、SQLite 级联清理触发器加固、侧边栏邮箱排序异常 ID 清理与词典补全，以及安全看板图表模块拆出与离线测试隔离；未新增破坏兼容性变更或独立主次功能，现有账号、邮件、界面偏好、数据库与接口保持兼容。

## 稳定性与交互修复

- 修复 WebKit 下从缓存切换回邮件列表时，右侧阅读区渲染导致列表 `scrollTop` 被重置的偶发抖动，并保证后台静默刷新分页时保持原有滚动位置。
- 左侧边栏邮箱顺序偏好（`mailai.sidebar.accountOrder.v1`）自动清理已删除账号残留 ID，并补齐 `i18n-catalog.js` 中 `side.moveAccountUp` 与 `side.moveAccountDown` 中文条目。
- 在数据库初始化阶段清理既有孤儿外键记录，并为 `emails` 与助手会话／消息子表补齐 `AFTER DELETE` 级联清理触发器。

## 内部质量与构建门禁

- 将安全看板 KPI 动画与 SVG 图表拆出为独立前端模块 `dashboard-charts.js`，缓解 `app.js` 体积压力并重新打包 `bundle.js`。
- 为离线发布门禁 `scripts/check_release.py` 及助手离线测试屏蔽本地 `.env` 模型凭据，消除本地开发环境下测试超时隐患。

## 验证

- 本地完整离线门禁 `scripts/check_release.py` 291/291 通过，WebKit `mail-navigation` 与前端模块化、国际化覆盖回归通过。
- 正式发布继续执行绑定候选提交和 Git 树的完整 `full` 验证、三平台安装包构建及签名、更新清单与国内镜像校验。
