# 操作、逻辑与设计修复（2026-09-08）

本轮修复源码，未更新安装包，未操作真实邮箱或模型。

## 完成项

- 附件读取绑定草稿会话和发件账号；关闭或切换草稿后不提交旧结果。正文图片也采用同样保护。
- 在途附件计入 25 MB 总量；批次读取完成后整体提交，读取失败释放额度。读取期间不能发送或切换发件账号。
- 发件箱保留所有 queued/sending/failed/unknown 记录；200 条限制仅适用于已完成历史。前端不会用同草稿其他记录隐藏 unknown。
- 普通列表和搜索不再静默截断为 1000 条，按每批 1000 条获取列表元数据；DOM 仍按现有分段方式显示。计数、分面与筛选基于已完成加载的完整元数据。
- 底部按钮改为“同步更早邮件”“同步全部历史”，在已发送、草稿及搜索视图中隐藏，避免与本地结果展开混淆。
- 当前已发送、草稿搜索保留所在列表，搜索本地记录内容；时间排序、时间筛选、附件筛选在这些列表生效。不适用的风险排序、优先级和发件人域名筛选不作为有效操作展示。
- 服务器文件夹搜索保留 folder 参数；统一收件箱共用单账号的搜索字段、关键词逻辑和索引策略。
- 900 像素等窄窗口保留整行搜索；紧凑列表保留所属账号、附件、隔离/垃圾等重要状态。
- 账号页区分授权码可用与最近同步结果，不再因有授权码而显示“连接正常”。
- 写信发件账号移到收件人上方；抄送/密送按需展开，已有抄送/密送的草稿自动展开；格式工具换行显示，不再将末尾按钮裁到横向区域外。

## 验证

- 同时选择两份 20 MB 附件只接受一份；读取失败不遗留预留量。
- 换草稿后旧附件与正文图片不进入新草稿。
- 1500 条结果可完整读取；原分页测试现验证 2505 条及失效请求不覆盖当前列表。
- 已发送按时间正序排序且主题搜索有效。
- 统一收件箱与单账号摘要关键词、多关键词查询一致，指定文件夹不会返回其他文件夹的邮件。
- 201 条新成功发件记录不能隐藏旧待确认记录。

浏览器隔离验收：已发送主题搜索保留 1 条正确结果且未离开文件夹；紧凑视图展示所属账号；写信发件账号前置、抄送密送折叠；900×640 搜索可见。测试窗口设置已恢复。

## 实现边界

完整列表元数据在前端保留，因此内存仍随邮件数量增长；正文不随普通列表加载，页面保持分段渲染。原来对“只保留 1000 条”的测试已改为验证完整分页，不代表进行了十万封界面内存实测。后续如需严格固定客户端内存，应把全部分面统计和组合筛选迁至后端，并引入按需分页；本轮没有把该架构重构混入修复。

已发送/草稿的搜索当前针对已加载的特殊列表记录；已发送接口原有的默认历史条数限制仍存在。本轮修复的是在列表中可见的本地发送记录搜索不到的问题，未声称完成全邮箱跨所有类型的历史搜索引擎。

安装包与真实弱网收发尚需独立验收。
