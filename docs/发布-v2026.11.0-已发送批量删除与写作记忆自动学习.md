# MailAI v2026.11.0 发布说明

- 基准版本：v5.0.0
- 变更类型：MINOR
- 目标版本：v2026.11.0
- 判断依据：本版新增「已发送」多选、批量移入已删除、堆叠卡片预览，以及小邮「从已发送邮件学习」在连接可用模型后自动启动等兼容新功能与体验增强，变更性质为 MINOR；同时自 `v5.0.0` 之后起将 Web／桌面产品版本号规则调整为日历版本号 CalVer（`YYYY.M.N`），本版作为 2026 年 11 月首次正式发布定为 `v2026.11.0`。旧数据库表结构自动平滑迁移，配置与历史邮件数据完全兼容；历史正式标签 `v5.0.0` 及更早版本保持不变，Android 与 iOS 仍各自独立维护 SemVer 版本线。

## 更新内容

- **「已发送」多选、批量移入已删除与堆叠预览**：在「已发送」列表开放 `Ctrl/Cmd` 点选、`Shift` 连选、空格键选择与 `Ctrl/Cmd+A` 全选（自动跳过仍在排队的发件箱条目），右侧展示堆叠预览卡片与按收件人方向标签（`GET /api/mail/sent/{id}/preview`），通过统一事务接口 `POST /api/mail/sent/bulk-trash`（复用于单封删除）原子提交入队、审计与撤销记录，部分未同步项保留勾选供重试并支持 `Ctrl/Cmd+Z` 撤销及右键打开／取消选择。
- **前端批量选择模块抽离**：将 `syncBulkSelectionVisuals`、`syncReadingSelectionStack` 与 `loadReadingSelectionPreview` 抽离至 [app/web/static/mail-list-view.js](app/web/static/mail-list-view.js)，进一步降低 `app.js` 体积。
- **小邮「从已发送邮件学习」连接模型后自动启动**：当邮箱账号存在可用 AI 模型且「小邮长期记忆」总开关开启时，默认自动按最近 90 天启动本机后台写作习惯学习，可在「设置 → 小邮 → 管理记忆」随时切换 30 / 90 / 180 天学习范围、手动暂停（暂停后不再自动重开）或清空重学。
- **桌面端日历版本号规则切换（CalVer）**：更新 [AGENTS.md](AGENTS.md)、[CONTRIBUTING.md](CONTRIBUTING.md) 与 [scripts/release_desktop.py](scripts/release_desktop.py) 至 `YYYY.M.N` 规范（按当月 0 起连续递增，月度切换归零），解决频繁小步迭代导致主版本号过快跳代的问题。
