# 邮件确认与界面降噪

## 操作语义

- 正常邮件：`确认无风险`只确认当前安全结论；`报告风险`用于反馈漏判。
- 可疑或钓鱼邮件：只显示`标记为正常`，通过误报反馈流程改判，不再调用“确认当前结论”接口。
- 待处置邮件：显示`执行隔离/移入垃圾邮件`与`标记为正常`，两者互斥且含义明确。
- 已隔离邮件：显示`恢复到收件箱`、未审核时的`保留隔离`以及`标记为正常`。
- 人工纠错默认只影响当前邮件，不再静默改判同发件人、同主题的其他邮件；弹窗会按当前文件夹说明是原地保留还是恢复到收件箱。

## 视觉层级

阅读页头、操作区、邮件分组标题和正文卡片取消重复分隔线。区域关系主要依靠留白、浅色操作底和轻量表面层级表达，保留必要的窗格边界与选中态。
