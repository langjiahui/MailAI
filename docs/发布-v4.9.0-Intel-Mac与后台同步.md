# MailAI v4.9.0 发布说明

- 基准版本：v4.8.4
- 变更类型：MINOR
- 目标版本：v4.9.0
- 判断依据：新增 Intel Mac 原生安装和按架构更新，扩大桌面端兼容范围。同步数据的结构扩展可自动迁移，现有账号和已下载邮件可继续使用。

## Intel Mac 支持

- 提供 Intel（x64）原生 PKG 安装程序和 DMG 镜像，配套同架构的系统钥匙串助手。
- 桌面自动更新按 Mac 架构选择安装包。GitHub 与 AtomGit 同步提供经过校验的 Intel 安装包。

## 大量邮件在后台同步

- 首次接入后，已下载的邮件可先打开。收件箱首次有邮件可读时提示一次，历史邮件继续在后台同步。
- 「任务与发件箱」按邮箱显示同步阶段、总进度和当前文件夹，支持暂停、继续和失败重试。暂停的历史同步可在日常收信后继续，已下载的邮件保留在本地。
- 正常同步时，顶栏任务图标用主题色小圆点显示状态。进度和控制集中在任务面板，需处理的失败显示角标。中英文界面及浅色、深色、宝武和黑白主题均使用同一入口。

## 发布验证

- 使用绑定候选提交和 Git 树的完整质量门禁，以及 Windows x64、macOS Apple Silicon、macOS Intel 和 Linux x64 构建校验。
- 核对平台附件校验和、签名更新清单与 AtomGit 镜像。
