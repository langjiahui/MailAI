# 首批优化与验证（2026-09-08）

本轮修改源码，未重新生成或替换安装包；未操作真实邮箱、未调用模型。

## 授权码保存

- 系统凭据库保存失败时，授权码仅保留在进程内，不再回退写入配置文件。
- 登录和更新账号返回保存提示，设置页持续显示“仅本次运行有效”。退出软件后需要重新登录。
- 后台同步和账号切换共用凭据读取逻辑。本次输入优先于旧凭据；保存失败标记随账号元数据保留，重启后不会重新使用凭据库里的旧授权码。
- 退出账号清除会话凭据。旧配置中的 IMAP 授权码在启动迁移时清空；本次审查没有直接修改用户现有配置文件。

## 附件预览

- 预览放入一次性的 spawn 子进程，最多同时运行两个预览。
- 等待预览结果的超时为 20 秒；超时后终止子进程并回收资源。进程启动、输入传输和退出清理另有少量开销，不承诺整个 HTTP 请求精确在 20 秒结束。
- 解析异常、进程崩溃、超时和并发满载都有可读提示。
- 入口提前调用 multiprocessing.freeze_support，以支持冻结应用的子进程分派。打包后的 macOS/Windows 版本仍需实包验收。
- 这是故障隔离，不是操作系统权限沙箱。

## 邮件搜索

- 使用 SQLite FTS5 trigram 索引加速至少三个字符的子串查询，支持中文长词。
- 一至两个字符、含 LIKE 通配符的查询以及缺少 trigram 支持的旧运行环境，沿用原查询方式，保持结果语义。
- 首次初始化为旧数据建立索引，插入、删除和正文等搜索字段更新时同步维护。已读状态更新不会重建正文索引。
- 索引增加磁盘占用；首次构建时间随邮箱大小变化。

## 验证

- 离线发布门禁 96/96 检查命令通过。最终清理调整后再次通过进程/搜索回归、凭据回归和 JS 语法检查。
- 新增测试覆盖：预览超时、异常退出、恢复、无遗留子进程；搜索旧库迁移、重复初始化、更新、删除、中文短词、通配符、多条件、分页和无索引回退。
- 凭据测试覆盖：保存失败不写明文、会话使用新授权码、重启后不取旧授权码、账号隔离。
