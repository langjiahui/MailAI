# MailAI v4.2.1：柔和邮件阅读界面

- 基准版本：v4.2.0
- 变更类型：PATCH
- 目标版本：v4.2.1
- 判断依据：本次完整变更是兼容的界面排版、主题配色与交互细节优化，未新增独立功能、未改变接口及数据结构。修订号由 0 升至 1，未触发次版本或修订号达到 10 的主版本进位规则。

## 本次更新

统一收件箱、已发送、草稿箱和已删除的柔和阅读风格：去掉明显分隔线和附件描边，用留白与主题轻底色区分邮件头、附件和正文。收件箱与已删除中的附件前置到正文上方，短正文不再保留多余的固定空白；已发送和草稿的标题、收件人、抄送／密送、时间分层排列，编辑与删除操作集中放在顶部。

附件卡片显示统一的文件图标、文件名及大小，保留用默认应用打开、独立预览和下载的入口。编辑操作使用主题浅底色，删除与舍弃草稿保留警示色；悬停和键盘焦点提供清晰反馈。适配默认、黑白简约、宝武蓝三套主题的浅色／深色模式、中英文、窄窗口与触屏按钮尺寸。

## 兼容与验证

从 v4.2.0 主线整合，仅带入本次确认的 UI 改动，保留已发布版本的邮箱切换保护、空主题处理、小邮对话及记忆体验。正文仍使用原有隔离渲染，不改变 HTML 安全沙箱、邮件内容、附件字节、发送／删除／恢复请求或数据库。原有邮箱、凭据、草稿、已发送、联系人、待办及个人偏好继续使用。Android 与 iOS 版本独立维护，本次不改号。

发布执行完整离线门禁、凭据扫描、绑定同一候选提交与 Git 树的原始 full，保留 Chromium／WebKit、主题、语言、窗口、字号与原生平台完整覆盖。三平台候选包与 full 验证并行，全部成功后才允许合并、标签、正式安装包发布与国内镜像核验；旧标签和安装包保持不变。
