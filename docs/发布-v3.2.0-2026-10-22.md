# MailAI v3.2.0 发布记录

- 基准版本：最近 Web／桌面正式版 v3.1.0，提交 6e181d1352e225ba0897647a414a15b3eef4f0ef。
- 变更类型：MINOR，新增用户主动单封补下载能力，支持自动下载上限以外的 50–256 MB 邮件；同时修复已有导入、计数、编码、更新和同步交互。新增能力向后兼容。
- 目标版本：v3.2.0，不触发编号上限进位。
- 数据兼容：已有邮件、账号、凭据、配置、成长、装扮和偏好继续使用，无需手动迁移。Android 1.4.0 与 iOS 1.0.0 测试版本保持独立，本次不改号或重复发布。

## 整合内容

- 下载与安装分成两个明确步骤。“后台下载”只收起更新窗口；下载完成后保持待安装，由用户点击“立即安装”才打开系统安装器。
- 小邮旁新增当前下载／待安装状态入口，保留小邮本身打开邮件助手的操作；设置 → 关于始终可以继续更新。重开弹窗不重置进度，客户端与服务端共同防止重复任务。
- 记录已完成下载，界面重载或应用重启后可以恢复；安装前重新确认最新清单、目标版本和文件 SHA-256，拒绝错误版本、缺失或损坏文件。取消 macOS 安装器后可以再次打开，不误报安装完成。
- 进度动效仅用于活跃下载，隐藏、后台、停用轻动效及系统减少动态时暂停；更新弹窗采用清晰实底，并适配中英文、深浅配色、窄屏、大字号与键盘操作。
- 整合尚未提交的系统代理／Windows PAC、VPN Fake-IP、可信证书与多地址连接修复。仅官方 GET 下载地址可使用受限的代理／合成 DNS 路径，其余地址仍要求公开 IP；保留 HTTPS、固定公钥验签和 SHA-256 校验，不泄露代理凭据或 CDN 参数。
- 更新源全部不可达时显示逐源的安全原因，中英文均能说明网络、证书或代理问题。

## 验证与发布

使用临时合成邮箱和模拟安装器测试关闭后读信、点击小邮恢复、进度保留、仅在确认后安装、安装取消重试、重启恢复、旧版本包、损坏文件及网络失败。真实邮箱和系统安装不参与交互回归。

执行完整离线门禁和并行 CI，覆盖 Chromium／WebKit、默认／黑白／宝武的深浅主题、中英文、窄屏及字号缩放。正式标签仅在完整源码质量门禁通过后创建；安装包执行现有平台构建、签名与完整性检查，公开发布后回读更新清单和附件校验值。国内镜像由独立工作流同步，不阻塞正式发布。

## 发布前 UI 复核

更新弹窗以完整长发布说明及下载中／待安装／失败三种状态，在 Chromium、WebKit 各验证 72 组组合，共 144 组：默认、黑白、宝武配色的深浅模式，中英文，390px 大字号与 1360px 窗口。底部稍后／安装操作始终可见，说明区支持键盘滚动；英文签名提示、分源网络错误均使用完整英文。补齐对应持续回归检查。

补充并发回归：在 Esc／关闭操作时同步保存“稍后”的选择，不等待异步 close 事件；模拟关闭通知延迟后立即自动检查，确认弹窗不会重新弹出。


## 问题定位与补下载闭环

- 邮箱同步提醒可点击，菜单及数据维护保留固定入口。按邮箱显示待下载文件夹、邮件编号、大小及原因；仅按用户要求读取受限邮件头，展示标题、发件人与日期。
- 50 MB 自动下载上限保持不变。手动单封补下载最多 256 MB，使用 BODY.PEEK 分段落盘，核对 UIDVALIDITY，保留未读状态、不移动或删除服务器邮件；原件保留，不自动运行模型或将未审查邮件判为安全。
- 补下载完成后移除问题记录并提供打开邮件；失败保留问题与重试入口，超过上限提供原邮箱下载及较小副本导入建议。关闭弹窗后台继续、停止界面轮询；重新打开可查看任务结果。
- 同步失败可重试指定邮箱、完整同步文件夹或直接管理该账号；每个操作固定账号，防止切换误操作。
- 导入失败卡片可定位清单，每项显示文件名、原因、建议及重试操作；超过预览范围可继续查看；历史批次重开或页面重载后仍可选择原问题文件补导。
- 新批次明确导入位置，按收件箱／已发送目录归属，未知目录仍归档；旧批次可明确执行按源文件夹归位，保留用户已移动或删除的状态。侧栏计数不依赖当前页或日期筛选，合并服务器与本地邮件数量。
- HTML 阅读与导入统一严格字符集回退，兼容 GBK 扩展字误标 GB2312；历史单字符异常优先从本地 MIME 原件恢复。无法从原件恢复的字符提示核对原件，不猜测或改写原始邮件。
