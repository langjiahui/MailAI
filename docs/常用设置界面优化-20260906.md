# 常用设置界面优化

版本：1.20260906.1054

- 常用设置采用居中双列布局，950px 以下改为单列，避免卡片贴在一起和右侧大片空白。
- 「显示与阅读」统一承载本机偏好：密度使用可键盘操作的单选预览卡片，服务端文件夹保留开关。
- 「邮件提醒」展示当前邮箱与四个直接可选的提醒级别，不再依赖原生下拉框。
- 设置读取、保存期间禁用提醒控件，失败时明确提示并提供重新读取入口。
- 请求固定邮箱上下文，晚到的旧邮箱结果不会覆盖新邮箱界面。
- 设置自动保存；阅读密度按设备保留，通知策略按邮箱分别保存。
- 窄屏导航将旧称「系统中心」统一为「设置」。

验证：48 项离线检查通过；隔离界面验证密度/通知修改、刷新持久化、双邮箱独立通知及 1440px 双列与 760px 单列布局。未连接真实邮箱，未发送真实邮件。安装包资源与源码核对一致。
