# 蓝绿玻璃品牌图标

已完成源码、打包资源与前端产物更新，保留原始折叠 M 的四条矢量路径、比例与折叠顺序。尚未构建或安装新的完整应用包，也未验证本机系统通知横幅实际刷新。

## 使用位置

- macOS Dock、Finder 与通知的应用包图标，以及 Windows 窗口、任务栏、托盘和通知、Linux 桌面图标，共用冰白玻璃、主题绿与宝武蓝折光的原生图标资源。
- 应用内标题栏、启动动画、引导页和 favicon 使用相同 M 的渐变标识，随默认绿、黑白、宝武蓝主题的浅色与深色模式适配。黑白主题的应用内标识保持灰阶；深色模式提高前层亮度。
- macOS 菜单栏保留同一 M 的黑色 alpha 模板，由系统在明暗菜单栏上着色。
- 一并重建打包目录中仍包含旧盾牌标识的组合 logo，提供 SVG 与 PNG；作者的个人 LJH 标识不属于应用品牌图标。

## 资源来源与生成

`app/web/static/brand.js` 是 M 路径的唯一来源，实例之间使用独立渐变 ID。`scripts/brand-app-icon.svg` 保存批准的玻璃底板、光效和原生材质模板，不复制 M 路径。`scripts/prepare_brand_assets.cjs` 组合两者，生成所有品牌 SVG、PNG 和菜单栏模板。

再运行 `scripts/prepare_app_icon.py` 生成多尺寸 Windows ICO，运行 `scripts/prepare_macos_icon.command` 生成按内容哈希命名的 ICNS。当前为 `build/mailai-a61c4d47b5f5.icns`，现有 `MailAI.spec` 会自动选择该文件。前端 bundle、CSS 和 fallback favicon 的缓存版本已更新。

玻璃边缘高光收在底板内，1024px 图标的不透明主体边界保持 `(100,100)–(924,924)`，避免 Dock 中比相邻图标偏大。M 的四条路径与改动前逐字一致。
