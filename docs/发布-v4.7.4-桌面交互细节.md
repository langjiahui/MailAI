# MailAI v4.7.4 发布说明

- 基准版本：v4.7.3
- 变更类型：PATCH
- 目标版本：v4.7.4
- 判断依据：本版调整已有控件的悬停反馈、图标和发送按钮样式，属于界面与交互细节。现有功能、接口和数据兼容。

## 图标与按钮反馈

- 顶部工具栏、邮箱文件夹、邮件列表筛选、空白阅读区、邮件阅读工具栏及「更多」菜单均加入悬停动效。
- 小邮面板的顶部操作、推荐卡片和设置页分类导航均加入悬停反馈。
- 动效随鼠标移入播放一次。开启系统「减少动态效果」时保持图标静态。

## 小邮发送按钮

- 发送按钮采用透明背景。输入框空白时纸飞机使用淡色；输入文字或选好图片、附件后，飞机加深并略微加粗。
- 鼠标移入发送按钮的点击区域时显示手形指针。生成期间可用「停止生成」终止当前请求。

## macOS 升级

- 正式发布提供签名的 Apple Silicon 安装包。仍在使用 4.7.0 或 4.7.1 的用户可从发布页下载 PKG，通过系统安装器覆盖升级。
