# 小邮长期养成

入口：小邮聊天窗口顶部「小邮养成」，或者设置 → 常用设置 →「养成手账」。

进度保存在当前邮箱的本机 SQLite 数据库。各邮箱分别养成，刷新、重启和普通数据库备份保留进度。第一次启动自动建表，旧数据库自动补充形象路线字段。

## 两条形象路线

两条路线同时保留，各有完整的七阶段进化：

- 「可爱 · 自然信使」：柔和圆润的形象，嫩芽、小花、星章、小翅膀与极光特效。
- 「帅气 · 星际先锋」：偏男性、硬朗的形象，从初始阶段就有利落的侧分短发，成长后增加先锋耳机、能量发饰、护目镜、战术外套、装甲、机甲翼与电光特效。

在养成手账的「形象路线」随时免费切换，共享成长度、邮票和已拥有的装扮，切换不会重置进度。

| --- | ---: | --- | --- |
| I | 0 | 初见嫩芽 | 初见先锋：侧分短发、硬朗眉眼、战术领口 |
| II | 240 | 萌芽信使：新叶片 | 见习信使：先锋耳机、能量发饰 |
| III | 1,200 | 花苞伙伴：小花 | 战术伙伴：能量徽章 |
| IV | 3,600 | 星章邮差：星章 | 电光邮差：护目镜 |

外观同步到悬浮小邮、聊天头像、写信助手与手账预览。沿用现有 SVG 动作骨骼，成长特效遵循轻动效开关和系统减少动态效果设置。

## 日常积累

成长度累计不扣减；邮票积分可消费。以下为每日奖励上限，达到上限后仍继续统计活跃使用、阅读和点击的次数或时间。

| 来源 | 单位奖励（成长度 / 邮票） | 每日奖励范围 |
| --- | --- | --- |
| 前台活跃使用 | 每 60 秒 +2 / +1 | 前 30 分钟 |
| 阅读时间 | 每 30 秒 +2 / +1 | 前 20 分钟 |
| 日常点击 | 每 5 次 +1 / +1 | 前 40 次 |
| 认真阅读邮件 | 每封 +5 / +3 | 前 20 封 |
| 收到正常新邮件 | 每封 +2 / +1 | 前 20 封 |
| 成功发送邮件 | 每封 +10 / +5 | 前 10 封 |
| 工具、小邮协作 | 每次 +6 / +3 | 前 10 次 |
| 帮助学习 | 每主题 +5 / +3 | 前 5 个主题 |

- 邮件前台阅读至少 8 秒，同一封每天奖励一次；帮助主题展开并前台阅读 8 秒，同一主题每天奖励一次。
- 前台活跃计时超过 90 秒未操作即暂停；后台、失焦、原生窗口隐藏均停止。恢复窗口不补记后台时间。前端使用现有统一节能调度器，每 10 秒提交一次；服务端以真实经过时间限制多窗口重复计时。
- 只给实际新到的正常收件邮件奖励，不给历史导入、隔离和垃圾邮件奖励；收件 Message-ID 与成功发件记录分别去重。发送失败、AI 中断不给对应奖励。
- 工具包括高级检索、工作流、模板保存、通讯录导入、日历工具、证据比对及附件分析等已接入成功结果的操作。普通工具同类每天首次使用奖励，小邮问答和 AI 写作按成功完成次数奖励。
- 点击限速，养成面板自身点击不参与点击奖励。成长请求支持 token 去重；断网仅在 30 秒内重试原批次，不补记离线时长。

每日自动奖励：读 3 封（+15 / +8）、活跃 10 分钟（+15 / +8）、工具协作 2 次（+15 / +8）、帮助学习 1 主题（+10 / +5）。

每天首个有效主动活动额外 +10 / +5；连续陪伴每满 7 天再 +30 / +20。被动收到邮件不触发签到；中断只重置连续天数，不损失已获得的成长、积分或装扮。

## 兑换与装扮

18 种奖励，包括两套工作区主题，以及围巾、信使帽、邮包、晴空/蜜桃/深空配色、战术外套、护目镜、先锋装甲、普通/机甲翼、星光、星环、极光、电光脉冲以及成长莓。

永久道具只扣一次积分，兑换后自动穿戴；配色、配饰和特效各有一个位置，可重新穿戴或卸下。成长莓每次消耗 120 邮票、立即增加 80 成长度，每天最多 3 次。兑换不降低成长度，形象路线切换免费。

所有购买、资格、余额、归属和每日使用限制由服务端校验并在 SQLite 写事务中提交。并发重复兑换不会重复扣分。可暂停养成，暂停后停止新增行为记录，已有形象和道具保留；手动兑换仍可使用已有积分。

只保存计数、时长、奖励、装扮以及行为去重键，不采集邮件正文或输入内容。最近 14 个有记录日期可在手账查看。可选成长记录失败不阻止核心收发邮件。

## 第二版闭环与稳定性改进

- 分段阅读累计满 8 秒即可获得当天单封阅读奖励，短暂切换窗口不丢失已经记录的阅读片段。
- 兑换请求有持久化编号，成长莓在网络超时、响应丢失、页面刷新和跨天重试时均核对同一笔兑换，不再次扣分。未确认的兑换会显示「核对兑换结果」；确认前暂停其他购买，装扮与暂停操作仍可用。
- 初始加载失败自动重试；养成请求 12 秒超时释放界面状态，心跳按原 token 重试。暂停及闲置时每 30 秒读取状态，多窗口操作会同步；后台仍不轮询、不补计时长。
- 新阶段及新道具解锁、每日目标完成、即时获得奖励均有反馈。「成长记录」增加最近 20 笔兑换记录，可以核对积分去向。
- 手账只在当前页面实际可见的数据变化时重建，减少商店与角色动画重复渲染。服务端快照在单个读取事务内取得，余额、外观与库存保持一致；短期计时去重数据每天清理一次并建立日期索引。
- 便携备份实际往返测试覆盖成长、装扮、兑换记录和重试编号。奖励钩子允许没有函数名的可调用工具，记录故障不影响原工具结果。

## 两条路线的边界复查

- 修复帅气路线第五至第七阶段默认色覆盖已兑换配色的问题。浏览器逐一检查两条路线、七个阶段与三种兑换配色，共 42 个组合。
- 可爱、帅气往返切换会恢复各自外观细节，保留成长、积分和当前装扮。商店中的帽子、邮包预览不再受正在穿戴的其他装扮影响。
- 暂停期间不缓存点击和学习行为；同步其他窗口的暂停/恢复状态时清空旧计时与待提交行为，防止恢复后补算。
- 未确认兑换遇到权限错误或请求限流时保留原请求编号，只有业务或参数明确拒绝才清除，继续核对时仍使用同一编号。

稳定性验收以离线发布检查及隔离浏览器测试为依据。真实邮箱、第三方模型服务和多日实际使用情况需要持续使用验证；离线测试不等同于这些外部服务的运行状态。

## 积分主题与全界面适配

- 黑白简约 300 邮票，宝武蓝 480 邮票，均从第一阶段即可兑换，永久拥有。入口为「小邮养成 → 商店」或「设置 → 常用设置 → 小邮主题」。兑换立即启用，不影响成长度；已拥有的主题可免费切换、恢复默认。
- 主题沿用现有亮色、暗色与跟随系统模式。随邮箱保存，切换账号即时切换主题，库存和积分独立；备份恢复包含主题及原兑换编号。
- 配色覆盖导航、搜索、邮件列表及选中态、阅读区、写信、通讯录、附件、待办、设置、帮助、小邮面板与手账。历史样式中的固定颜色通过受主题范围限制的 CSS 层映射到统一色板，默认界面保持原来的外观。选中态玻璃、桌面窗口色板和脚本隔离的 HTML 正文同步适配；原邮件图片不做色彩变换。
- 两套主题各有配套矢量 Logo、浏览器标签图标、文字标识、导航和工具图标底座。深浅切换时同步更新；恢复默认时恢复原标识和图标。关于页面的 LJH 标识也采用对应配色。风险、警告、成功状态保留表达含义的颜色。
- 小邮的默认身体、手脚和叶片随主题配色，可爱与帅气两条路线均保留。单独兑换的小邮配色仍优先，主题不会覆盖原有装备和成长。主题预览独立展示自己的配色。
- 兑换沿用幂等购买机制，响应丢失后可刷新并核对同一笔交易，不重复扣分。
