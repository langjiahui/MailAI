# MailAI v3.4.0 发布记录

- 基准版本：最近 Web／桌面正式版 v3.3.0（2026-10-22 已公开），提交 51b222a；核对本次全部变更后定级。
- 变更类型：MINOR。增加向后兼容的自然语言组合筛选和邮件对话连续衔接能力；同时交付界面、装扮、语言与回复质量优化。
- 目标版本：v3.4.0，不触发编号上限进位。
- 判断依据：新增用户可直接使用的筛选表达和连续邮件问答能力，旧 API、配置与邮件继续兼容；会话新增阅读对象字段通过自动迁移保留历史记录，无需手动转换。
- 各端独立：Android 1.4.0 与 iOS 1.0.0 测试版本不改号。

## 交付内容

- 快速搜索支持“查看未读邮件”“查看本周未读且带附件的邮件”及对应英文条件；本机解析明确筛选，不把自然条件当正文关键词。
- 小邮可连续完成查找、总结、负责人／截止追问、待办建议与简短回答，支持多封及“第二封”指代。切换阅读对象后简短追问跟随新邮件，明确指定的邮件组保留；切换话题重新检索，清除旧条件和固定范围。
- 分析历史仅采用账号内服务端保存、来源集合相同的连续对话；旧邮件事实不能补进新来源。知悉通知不擅自分配用户任务，活动时间不当作任务截止；未知信息明确说明，执行操作仍需确认。
- 完善装扮试穿、组合效果、阶段预览、兑换后反馈、装备和卸下、邮票不足及返回补给铺的衔接；兑换与穿戴状态以保存结果为准。
- 邮件列表、选中态、日期分组、加载区和阅读空状态更轻量，停靠小邮后列表仍可拖动／键盘调宽并记忆；分隔线渐变渐隐，减少生硬边框和折角。
- 黑白主题采用中性灰白与石墨层级，完善不同主题的深浅色、中英文、窄窗口和焦点反馈，补齐安全分析部分语言切换。

## 验证与发布要求

- 发布前执行完整离线门禁及对应浏览器矩阵；自然语言、上下文、空状态与分栏新增回归加入 CI。模型审计脚本必须显式 --live 才联网，不加入离线门禁。
- Kimi Code / kimi-for-coding 使用互不相同的合成邮件完成上下文基线及修复后复测；修复后 30 轮实际模型回答与 2 次检索规划成功，另核对能力介绍和无来源澄清。旧人名、日期、金额和引用未串入本次来源范围。
- 发送、移动和删除相关回归仅使用模拟 IMAP／SMTP；模型审计没有发送邮件、创建待办或标记已读。未使用真实邮箱内容作为模型测试材料。
- 合并前必须通过完整源码质量门禁。随后创建新标签，平台工作流生成 Windows x64、macOS arm64、Linux x64 安装包与更新清单，核对版本、签名及 SHA-256；公开后回读附件并等待独立国内镜像验证。
- 历史标签和附件保持不变，失败重试沿用相同源码和版本，不能覆盖已发布内容。
