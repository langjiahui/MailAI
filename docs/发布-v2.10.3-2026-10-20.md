# MailAI v2.10.3 发布记录

- 基准版本：GitHub 最近 Web／桌面正式版 v2.10.2。
- 变更类型：PATCH。
- 目标版本：v2.10.3；Android 独立发布 1.4.0。
- 判断依据：补齐已有自部署 Kimi K2 的推理额度兼容处理，不增加独立桌面能力或改变数据格式。该基准以来另有 Android 1.3.3 编码修复及本次国内更新功能，只按 Android 自身基准分级，不据此抬升桌面次版本。

自部署／通用 API 的 Kimi K2 模型使用 4096 token、90 秒额度，避免模型只返回推理而没有可见正文；模型 ID 原样发送，不附加官方服务专用参数。其他模型及 DeepSeek、官方 Kimi、Kimi Code、Ollama 请求合同保持兼容。没有变更邮箱协议、发送、草稿、附件或数据库逻辑。

验证包括实际合成邮件场景、响应解析回放、各服务商参数回归和完整离线门禁；CI 对精确源码运行既有浏览器、平台及发布检查。Windows／macOS／Linux 安装包和签名更新清单分别构建并校验；国内更新指针与 Android 新通道分开维护，历史标签和安装包保持不变。
