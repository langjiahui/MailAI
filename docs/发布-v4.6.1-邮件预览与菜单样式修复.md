# MailAI v4.6.1 发布说明

- 基准版本：v4.6.0
- 变更类型：PATCH
- 目标版本：v4.6.1
- 判断依据：修复现有打印和分享预览的滚动边缘及菜单悬停样式，兼容现有邮件和配置。

## 修复内容

- 打印和分享的屏幕预览使用与面板相同的底色，并关闭正文在滚动端点的回弹，避免暗色模式下露出白带。
- 「更多」菜单的普通操作统一使用当前主题的悬停及键盘焦点背景。「删除邮件」保留淡红提示。
- 纸张打印和导出 PDF 继续使用浅色排版。

## 验证

- Chromium 和 WebKit 回归覆盖默认、黑白、宝武主题的明暗菜单样式，以及长邮件滚动、预览主题和打印背景。
