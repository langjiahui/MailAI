# 小邮填写附件并准备回复

打开带 `.xls`、`.xlsx`、`.docx` 或可填写 `.pdf` 附件的邮件，在小邮中说“帮我填写附件并回复这封邮件”。小邮会给出“开始填写”卡片。选择附件后，小邮识别待填字段和位置；部门按行排列的登记表会先让用户选择部门行。可以一次描述填写信息，让小邮提取到字段，也可以逐项填写。字段或位置有误时，可补充说明并重新识别。

小邮只向可定位的空白字段写入。生成文件后会重新读取并核对填写值，创建带新附件的回复草稿，并打开写信窗口。原附件不会被覆盖。收件人从原邮件的 `Reply-To` 或发件人推导，不能由模型决定。写信窗口会提示预览附件、核对收件人和正文；只有用户点击“确认发送”才进入现有发送前检查和发送流程。

旧版 `.xls` 使用本地 `xlrd`、`xlutils` 和 `xlwt` 处理简单表格。含宏、公式或绘图对象的旧表格会拒绝自动填写，提示先另存为 `.xlsx`。`.xlsx` 含宏或外部链接时也会拒绝。Word 支持表格空白单元和正文中连续的填写占位符；含宏、嵌入对象或外部链接时拒绝填写。PDF 仅支持原生空白文本表单字段；扫描件、普通扁平 PDF、加密 PDF 和无法可靠显示中文字形的 PDF 会提示改用可编辑模板。

微信单聊先“查看第一封”，再“填写附件”。小邮列出可填写字段；可以发“填写信息：姓名张三，车牌沪A…”或“填写字段1：张三”补充，发“填写预览”核对，发“生成附件回复”创建草稿。发“查看填写结果”获取文件并预览，再用回复预览中的一次性编号确认发送。微信确认前修改了电脑端草稿，原确认编号会失效。
