# 小邮填写表格并准备回复

打开带 `.xls` 或 `.xlsx` 附件的邮件，在小邮中说“帮我填写附件并回复这封邮件”。小邮会给出“开始填写”卡片。选择附件后，小邮识别待填字段及单元格；部门按行排列的登记表会先让用户选择部门行。可以一次描述填写信息，让小邮提取到字段，也可以逐项填写。普通表格的字段或位置有误时，可补充说明并重新识别。

小邮只向空白单元格写入。生成文件后会重新读取并核对填写值，创建带新附件的回复草稿，并打开写信窗口。原附件不会被覆盖。收件人从原邮件的 `Reply-To` 或发件人推导，不能由模型决定。写信窗口会提示预览附件、核对收件人和正文；只有用户点击“确认发送”才进入现有发送前检查和发送流程。

旧版 `.xls` 使用本地 `xlrd`、`xlutils` 和 `xlwt` 处理简单表格。含宏、公式或绘图对象的旧表格会拒绝自动填写，提示先另存为 `.xlsx`。`.xlsx` 含宏或外部链接时也会拒绝。当前仅支持表格附件，其他文档格式仍保留现有只读分析能力。
