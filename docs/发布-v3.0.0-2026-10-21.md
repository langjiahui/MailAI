# MailAI v3.0.0 发布记录

- 基准版本：GitHub 最近 Web／桌面正式版 v2.10.3（1c5de180f66dee9c4c8d00d74ac4ee5cb7d0a717）。
- 变更类型：向后兼容的新功能（MINOR 影响），按用户指定的编号上限进位。
- 目标版本：v3.0.0。Android 与 iOS 保持独立版本，本次不发布移动端。
- 判断依据：本次完整变更新增小邮拖拽随停、本地位置记忆、四边吸附、成长形态与动作试穿、陪伴声音及提示偏好，同时优化外观、补给铺与能耗；最高影响为兼容新能力，同时新增经典列表和导入恢复、本地移动能力；按 2026-10-21 确认的新规则，次版本或修订号达到 10 时提升主版本，本次编号为 v3.0.0；该编号不表示破坏兼容性。原有邮箱、成长、积分、装扮及偏好无需手动迁移。

小邮全面升级：新增拖拽随停、位置记忆和四边吸附，顶部扒边、拖离松手与身体回正更自然；提供小邮雀到青羽凤凰、小邮鱼到星海鲲鹏两条成长路线，优化转向、跑动、游动及手部与信封的协调。补给铺升级装扮、配色与特效预览，可试穿七阶段形态和动作；欢迎页仅展示一个完整形象，打开和悬停时短暂互动，结束后静止。适配默认、极简和宝武主题的深浅配色，保留已兑换配色，并支持本地轻音与陪伴提示偏好。已有成长、邮票、装扮和邮箱数据保持兼容。

验证使用合成邮件和独立客户端覆盖两条路线、七个阶段、拖拽持久化、吸附接触点、装扮试穿、欢迎页单次互动、主题配色、后台暂停及减少动态设置。执行精确发布源码的离线门禁、Chromium/WebKit 与既有 CI 检查；安装包版本由根 VERSION 和发行标签统一注入，Windows、macOS、Linux 构建后生成校验值及签名更新清单，再同步国内镜像。历史正式标签与附件保持不变。

整合邮件导入恢复、单文件跳过、中文失败建议及导出报告；新增本地收件箱与归档互转、撤销及经典列表列宽记忆。移动和撤销使用合成邮件验证并禁止 IMAP 连接，未操作真实邮箱。

macOS 恢复原生正文选择菜单与复制；已使用真实 WKWebView 合成邮件验证右键 Copy、Cmd+C、外部链接和邮件脚本隔离。
