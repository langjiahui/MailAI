# MailAI v4.7.5 发布说明

- 基准版本：v4.7.4
- 变更类型：PATCH
- 目标版本：v4.7.5
- 判断依据：本版修复已有打印与分享预览的鼠标滚轮和滚动条交互，属于兼容性错误修复。未增加独立新能力，现有功能、接口和数据兼容。

## 打印与分享预览

- 修复 macOS WebKit 中鼠标滚轮无法滚动预览、只能拖动滚动条的问题。加载时改用透明度遮住尚未完成主题处理的预览，保留 iframe 的正常滚动处理。
- 明确预览根元素的垂直滚动容器与滚动边界，统一不同 WebKit 实现中的滚轮处理。
- 打印、分享 PDF／EML 和纯文本预览采用可拖动的悬浮滚动条。滚动或移到右侧边缘时显示，停止操作约 0.9 秒后自动隐藏，拖动期间保持可见。
- 滚动条显示和隐藏不再挤压正文，底部打印与分享按钮保持原位。关闭预览时清理滚动观察和拖动状态。
- 更新样式缓存版本，确保已有客户端能加载修复。邮件预览继续使用原有沙箱隔离，打印和导出的邮件内容与排版保持原有规则。

## 验证

- 本地完整离线门禁 290 项及改动凭据扫描通过。
- Chromium／WebKit 工作区回归通过，覆盖打印、PDF／EML 分享、纯文本预览、滚轮双向滚动、滚动条拖动与自动隐藏，以及深浅主题、窄窗口和 125% 字号。
- macOS 原生 WKWebView 的实际滚轮事件检查通过，确认正文宽度和底部按钮位置稳定；原生单页和多页 PDF 检查通过。
- 正式发布继续执行绑定候选提交和 Git 树的完整 full 验证、三平台安装包构建及签名、更新清单与国内镜像校验。
