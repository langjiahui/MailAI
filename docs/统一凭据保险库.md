# macOS 统一凭据保险库

迁移完成后，MailAI 只需解锁一个钥匙串条目，就能恢复已迁移的邮箱密码、OAuth 令牌、模型密钥和其他连接凭据。正常修改密码、更新令牌不再改写多个钥匙串条目。

临时签名包的升级可能仍要求重新授权一次主密钥。相同安装版本选择“始终允许”后，通常无需每次启动重新输入密码；钥匙串锁定或系统策略仍可能要求解锁。跨版本保持授权需要稳定的开发者签名。

旧凭据分别受 macOS 钥匙串保护，不能用一次授权替代所有旧条目的首次授权。MailAI 在读取获得授权后将它迁入保险库；其他旧条目保持等待解锁，不会在后台集中弹窗。迁移失败会保留旧条目供后续重试，迁移不会扩大原有访问权限。

保险库位于用户应用数据目录的 `credentials.v1.enc`，采用 AES-256-GCM，随机主密钥只存于钥匙串 `MailAI / credential-vault-key:v1`。每次更新使用新的随机 nonce，文件仅允许当前用户读写，并以原子替换方式保存。密码、令牌、主密钥及凭据名称不会以明文写入该文件。

邮件备份、便携迁移包和安装包不包含保险库或主密钥。不要单独删除主密钥：失去主密钥后，加密文件无法解密，需要恢复钥匙串备份或重新配置凭据。损坏或缺少主密钥时，程序不会自动覆盖原有加密数据。删除凭据会保存删除标记，防止旧条目在后续迁移中恢复。

建议验收：逐一解锁并迁移旧邮箱后重启应用，确认所有已迁移邮箱一起恢复；更换临时签名预览包时，仅主密钥可能要求授权。迁移阶段与正常使用阶段的授权次数应分开判断。
