# iOS 全面升级（本地验收，不公开发布）

用户已授权全面开发，默认宝武蓝 #005EAA 与白色，随系统深浅色。沿用现有签名和设备安装方式；不创建发布标签，不覆盖历史 beta。

## 交付顺序

1. 邮件基础：兼容旧数据的多草稿、收件人/抄送/密送、附件读写与预览、回复全部/转发、邮件标记/归档/移动/删除、已发送副本。
2. 原生体验：统一蓝白语义配色，收件箱/文件夹/阅读/写信/设置重设计，搜索、联系人、统一收件箱与会话入口，深色/大字号/辅助功能。
3. 小邮：用户配置模型，按需总结/待办/翻译/起草/润色，采用前预览、可撤回；凭据入钥匙串。
4. 同步与认证：前后台同步状态、系统调度刷新及本地提醒；Google/Microsoft OAuth 和 APNs 需要应用注册/签名能力/外部服务，先完成可独立验证的客户端能力，再明确外部依赖。

## 必须保持

- 手机独立收发，TLS 和服务器证书校验不降级；不自动向猜测主机提交密码。
- 发送结果未知不能自动重发；SMTP 成功与已发送存档失败分别处理。
- 旧账号、邮件缓存和草稿兼容迁移；密码、API Key、设备标识不入仓库。
- 所有界面按钮连接真实行为，无虚假数量和无效功能入口。
- 保留完整门禁、协议/持久化测试，补充迁移/附件/密送/批量操作/界面与主题验证。
