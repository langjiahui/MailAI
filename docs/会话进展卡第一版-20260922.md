# 会话进展卡第一版

阅读页新增会话进展卡，工作简报新增直达入口。第一版在本地整理已保存事实，不调用模型，不推断责任人、对外承诺或整件事已经完成。

## 行为

- 使用 Message-ID、In-Reply-To、References 和回复来源关联同一邮箱的往来，不按同名主题归组。
- 补充保存本地发件记录的回复关系。只有成功发送的记录进入时间线，转发不因原邮件来源被当作回复；同步副本按 Message-ID 去重。
- 展示最新往来正文片段、来源邮件或发件记录、关联待办及其来源。保留既有风险判断口径，已核对的风险不重新冒出。
- 状态依据人工保存的待办：待推进、已标记等待反馈、已记录任务完成。自动提取但未经确认的任务不用于断言当前处理状态；待办完成仍提示核对后续事项是否结束。
- 时间线默认折叠，单封且无关联往来时不重复展示正文片段。支持在原有任务安排器中核对和更新任务，更新后刷新进展卡。
- 进展读取独立于正文读取；失败可以重试，切换邮件或账号后的旧请求不覆盖新界面。

## 范围与边界

- 仅使用当前账号本地数据库。查询最多收集 100 条邮件/发件记录、12 轮关联和 256 个关联键；触及上限显示范围不完整。
- 已删除、已移除、垃圾邮件、隔离邮件和草稿不计入往来。
- 旧本地发件记录没有回复关系时可能无法关联，不根据主题补猜；未同步邮件不在范围内。
- 第一版展示的是往来记录和已保存状态，尚未做交期、金额、承诺等内容的自动差异识别，也不自动完成待办或发送邮件。
- 数据迁移只增补发件关系字段和查询索引，可重复执行，不修改旧邮件的归组规则。
