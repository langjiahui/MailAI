# MailAI v3.8.3 发布记录

- 基准版本：最近 Web／桌面正式版 v3.8.2（北京时间 2026-10-29 14:10:01 已公开）。
- 变更类型：PATCH。
- 目标版本：v3.8.3，不触发编号上限进位。
- 判断依据：本次完整交付为既有导入、收信、提醒、数据库初始化、语义索引和退出流程的兼容性与稳定性修复；主分支新增的发布候选构建优化仅调整内部交付流程。未新增独立用户能力，未破坏数据、接口或配置兼容性，按 PATCH 升级修订号。
- 各端独立：仅发布 Web／桌面，Android 与 iOS 产品版本和安装序号保持不变。

## 交付内容

- Foxmail 大批量导入：进度查询短暂超时、服务忙和旧写入请求释放期间有界恢复，沿用同一文件序号与持久回执，避免重复计数或跳过文件。
- 将上传磁盘读写和相关锁操作移出异步服务线程；取消请求时等待当前磁盘操作完成后安全清理，写入启动失败不会遗留占用。
- 同名文件大小或内容变化时返回批次冲突，要求重选原文件；异常 MIME 或头部解析失败按单封记录，其余邮件继续导入。
- 小邮件分段下载遇到服务器长度误报时，独立请求完整正文并核对已收字节；无法确认或大邮件仍保留原有重试与大小边界。
- 串行化同一数据库的初始化，并以事务保护迁移，避免并发重复加列与失败后半迁移；不同邮箱保持独立。
- 提醒调度排除已删除、隔离、垃圾、远端缺失及孤立邮件记录，避免无效提醒每秒唤醒。
- macOS 通知权限不可用时短暂缓存并仅在状态变化时记录日志；主动授权可立即重试，不会将未投递通知标记为成功。
- 语义索引自动更新失败后按邮箱退避五分钟，保留错误状态，手动重建可立即重试；Ctrl+C 正常退出不再误报崩溃。
- 纳入最新主分支的私有候选包与完整验证并行流程；正式发布仍校验完整测试凭证、同树产物、签名与校验和。

## 验证与发布

- 开发阶段完整离线门禁、Chromium／WebKit 导入与相关浏览器分组通过，使用合成邮件和模拟服务验证，不访问真实邮箱。
- 导入回归覆盖 6698 文件回执与去重、439 附近响应丢失、450 文件浏览器恢复、进度查询超时／503、写入占用 409、重复取消及异常 MIME 隔离。
- 补充正文长度误报、并发迁移与回滚、账号隔离、提醒唤醒、通知权限恢复、索引退避及实际进程退出回归。
- macOS 候选构建暴露已有选路测试依赖 40／150 毫秒墙钟的时序波动；改用线程局部时钟核对实际耗时选择、事件同步断言工作源在阻塞源释放前返回，保留双源选择、并发不阻塞及守护线程检查。候选变化后重新执行全量验证与构建。
- 定稿候选执行完整离线门禁、凭据扫描和云端原始 full；由 scripts/release_desktop.py 固定提交，衔接合并、全新标签 v3.8.3、三平台安装包及国内镜像验证。
- 用户日志、账号数据和真实邮件不进入源码或发布附件。既有正式标签与安装包保持原样。
