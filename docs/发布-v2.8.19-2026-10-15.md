# MailAI v2.8.19 整合发布

本版本以主分支 `91c71799e910180daeaa601207fe3158e66bb91a` 为基线，整合当前项目目录中的新增代码。已发布的附件默认应用打开、独立预览、多账号通知及跨平台测试修复继续保留。

## 更新内容

- 快速搜索支持明确的发件人、收件人、主题、附件名、日期及邮件范围条件，展示可移除的条件标签，与高级搜索共用解析规则。
- 高级搜索保留可见条件、已应用条件与结果，支持跨账号、保存条件、错误恢复和旧请求取消；已发送与草稿可以定位完整记录。
- 可将搜索需求交给小邮继续查找，支持排除本轮结果、放宽日期、补充线索、撤销调整、失败重试、返回候选结果及确认找到邮件。搜索状态保存在所属账号与对话内。
- 中文全文及拼音检索使用持久化索引文本，升级时重建旧派生索引；查询时不再逐封计算正文拼音。
- 阅读区滚动条在 90%–130% 字号缩放下保持物理位置、宽度和滑块行程，保留空闲隐藏。
- 原邮件完整展示签名、嵌套引用及文本内容，移除正文格式标记；修正仍调用旧折叠函数的动效回归。
- MacBook Air 顶栏根据实际可用宽度保留文字并避免重叠，覆盖中英文、深浅色与主题组合。
- 原生图标使用石墨灰折叠 M，完善安装后当前 GUI 用户的应用注册，隔离测试副本不注册正式应用身份。系统通知与电池菜单的历史图标缓存仍需实机验证，不宣称此版本已保证刷新。

## 发布验证

发布使用完整离线门禁、Chromium/WebKit 搜索与阅读回归、原生 WKWebView 滚动条检查，以及 GitHub Actions 的跨平台质量门禁和 Windows x64、macOS arm64、Linux x64 构建。最终构建与发布结论由对应 Actions 记录和 Release 资产核验记录确认。

针对新增搜索功能，已完成发件人姓名、日期边界、语法冲突、跨账号打开、搜索条件保存、过时请求取消、AI 检索调整与撤销、来源跳转、历史恢复、失败重试和窄屏布局验证。所有邮箱与模型均使用隔离测试数据。

本地未提交源码已保存为恢复快照 `f31d851c381e604d530e105fefa11de415b7b3b2`，分支 `codex/source-snapshot-2.8.19`。临时构建、私有材料和开发工具状态未纳入发布源码。
