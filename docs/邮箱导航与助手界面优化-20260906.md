# 邮箱导航与助手界面优化

版本：1.20260906.1042

## 邮箱导航

- 将多层账号卡片改成轻量分组，收件箱、已发送和草稿箱纵向排列。
- 折叠入口放在账号标题前，记住每个邮箱的展开状态。
- 同步状态并入账号副标题，运行时显示小型旋转指示；失败和重新登录仍有明确提示。
- 显示名称与邮箱管理收进标题末尾的菜单。管理入口不会改变当前发件账号。
- 账号标题优先显示自定义名称或邮箱用户名，副标题显示域名，悬停可查看完整地址。

## 邮件助手

- 查询范围放在输入框上方，使用紧凑的范围入口。说明、邮箱完整地址和分析数量在展开后查看。
- 单封邮件分析显示主题，可一键清除；从邮件发起的分析会固定对应范围，避免范围文字与实际请求不一致。
- 切换邮箱清除上一账号的指定邮件范围，来源匹配按账号约束。
- 历史会话和浮动显示合并到标题栏更多菜单。
- 桌面未打开邮件时使用空白阅读区；已打开邮件时，1600px 及以上并排停靠，较窄窗口使用覆盖面板，不强行压缩四栏。
- 760px 及以下适配近全屏面板，保留关闭与范围操作。

## 验证

- 离线发布检查 47 项通过，新增范围标签、账号上下文重置、布局分支和导航控件回归检查。
- 使用两个虚构邮箱的隔离界面验证折叠、范围切换/清除、单封分析、管理入口和 760/1440/1800px 布局。
- 测试未连接真实邮箱或发送真实邮件；未调用线上模型。
- 打包后核对 JavaScript、CSS 与工作区源文件一致。
