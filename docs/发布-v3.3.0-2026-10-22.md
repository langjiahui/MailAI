# MailAI v3.3.0 发布记录

- 基准版本：最近 Web／桌面正式版 v3.2.0，提交 04b9f5786e2543d4399ccc5d564a43b81fbddc8c。
- 变更类型：MINOR。新增向后兼容的自动清理服务器邮件能力；同时交付小邮拖拽及特效显示修复，最高影响为新增用户能力。
- 目标版本：v3.3.0，不触发编号上限进位。
- 判断依据：用户可以首次按邮箱保存并授权周期清理规则；旧邮件、账号、凭据、收藏、附件及偏好继续使用，无需手动迁移。
- 各端独立：仅更新 Web／桌面版本。Android 1.4.0 与 iOS 1.0.0 测试版本不改号、不重复发布。

## 交付内容

- 设置 → 数据与维护 → 清理服务器邮件新增“自动清理设置”。默认关闭，按邮箱保存一个服务器文件夹、保留 30／60／90／180／365 天、每天或每周执行。
- 开启或修改规则需要风险授权和邮箱地址确认；关闭无需再次确认或连接邮件服务器。卡片显示状态和下次执行时间。
- 每次先逐封核对完整原文，保存本地完整副本并创建安全备份，再用 UIDPLUS 精确删除服务器副本。每批最多 50 封、100 MB，始终排除收藏、星标、原文不完整及结果不明的邮件。
- 仅在应用运行且邮箱空闲时执行。失败或应用中断后暂停，不重放删除；核对后重新授权可继续处理其他邮件。最近清理记录区分自动执行。
- 修复 macOS 小邮顶部停靠时被原生标题栏截获拖拽的问题，保留相邻空白区域拖动和双击窗口操作。更新排除区域时串行提交最新几何位置。
- 已装备的星光、光环、极光及闪电特效在静止和减少动态模式下仍可辨识；临时拖尾消失，空闲时不持续运行动画。

## 验证与发布要求

- 使用临时合成邮件与模拟 IMAP／SMTP 验证，未对真实邮箱执行移动、发送或删除。自动清理测试覆盖默认关闭、授权校验、定时执行、完整副本、备份失败、断线暂停、中断不重放、账号隔离和忙碌延后。
- 执行完整离线发布门禁；清理设置在 Chromium／WebKit 验证启停、持久化、离线关闭、加载失败保护、中英文、深浅主题、窄窗口及字号缩放。纳入独立 CI 分组，每种浏览器使用独立临时邮箱。
- 小邮修复由原生标题栏命中测试、双浏览器位置回归、装备动效和静止姿态回归覆盖。
- 完整源码质量门禁通过后合并并创建新标签；平台工作流生成 Windows x64、macOS arm64 和 Linux x64 安装包，核对元数据、签名和 SHA-256。公开后回读清单与附件，国内镜像沿用独立同步流程，历史标签及附件不覆盖。
