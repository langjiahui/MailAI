# MailAI 邮件效率与交互迭代

本轮源码扩展了邮件查找、处理安排、写信、附件核对与账号接入。数据继续保存在所属邮箱的本地数据库；已有邮件、草稿、附件和账号配置保留。本地验收 PKG 已构建为 2.3.15，尚未公开发布。

## 功能入口

| 功能 | 入口与行为 |
|---|---|
| 高级搜索 | 搜索框右侧的筛选图标。组合发件人、收件人、主题、日期、附件名、未读、分类、处理状态；可搜索所有可见账号，覆盖已同步邮件、成功发件与本地草稿。 |
| 搜索条件保存 | 高级搜索中“保存本次条件”，随后从已保存搜索列表恢复。搜索结果自动收起条件，保留展开入口。 |
| 附件名搜索 | 附件元数据纳入全局本地索引；高级搜索支持 filename:pdf 等条件。附件正文从附件中心选定文件后直接搜索。 |
| 重点邮件 | 列表“筛选 → 重点邮件”。高优先级、已收藏联系人和人工指定的重要发件人进入重点。 |
| 订阅查看 | 侧栏“AI 分类 → 订阅推送”或高级搜索，按现有“订阅推送”分类集中检索。尚未分类的订阅需先核对分类。 |
| 邮件模板 | 写信工具栏“模板”。保存主题和纯文字正文，支持从当前邮件建立模板；使用前可预览编辑，不复制收件人、附件、签名。 |
| 定时发送 | 写信底部“发送安排”；选定时间后点击发送提交。安排随草稿保存，发件箱中可直接编辑邮件、调整时间或取消尚未开始的任务。编辑前原任务会先暂停，修改后重新确认发送。 |
| 连续写信 | 写信窗口可最小化或展开；移除独立窗口入口。展开时帮写在右侧独立区域，格式工具可换行显示。草稿版本检查阻止旧窗口覆盖或发送其他窗口更新后的内容；原有输入保留供核对。 |
| 收件人检查 | 写信地址框下提供可逐个移除的地址标签，不同发件域的地址单独提示；原有发送前安全检查继续生效。 |
| 局部 AI 润色 | 正文选择文字后点“润色选中文字”。仅发送选中的文字给已配置模型，预览后应用；账号或原文变化时拒绝覆盖。 |
| AI 草稿核对 | AI 草稿中的明确日期和金额标注是否在本次参考内容中出现。字面出现不能证明事实正确或双方已确认，发送前仍需核对。 |
| 附件文字与版本 | 附件中心“查找文件内容”选择文件并搜索；每个文件旁也可直接比较其他邮件里的同名附件，不再要求手动建索引或输入完整文件名。最新邮件中的文件不一定是内容最新版本。 |
| 分享链接管理 | 附件中心“已分享文件”查看最近 200 个新上传分享的到期时间，并为已有 COS 对象重新生成链接；不会修改已发送邮件中的旧链接或提前使旧链接失效。 |
| 会议与日历文件 | 待办中心“日历文件”查看当前邮件的本地 ICS 邀请、导入 ICS 预览、核对时间后导出事件；接受或拒绝会准备带日历回复附件的草稿，需确认发送。 |
| 通讯录互导 | 通讯录“导入 / 导出”支持 UTF-8 CSV 与常用 vCard 字段。导入先预览，默认保留已有联系人；选择更新后才替换姓名、公司和分组。 |
| 快捷操作 | Cmd/Ctrl + K 打开命令面板；非输入、非弹窗、非写信状态下 J/K 切换邮件，R 回复，/ 聚焦搜索。 |

## 账号与同步

Google 和 Microsoft 接入使用官方 OAuth 授权页面、PKCE 和限时本机回调。客户端 ID 可在邮箱设置的官方登录入口中配置；Google 桌面客户端在需要时填写客户端密钥，密钥与授权令牌保存在系统凭据库。Microsoft 使用桌面公共客户端，不填写客户端密钥。

Google 回调使用 `http://127.0.0.1` 的随机端口；Microsoft 使用 `http://localhost` 的随机端口。注册应用需允许相应桌面回调与 IMAP/SMTP 权限，企业账号可能需要管理员许可。授权返回后由用户点击“连接邮箱”，成功验证邮箱身份后保存账号。真实登录验收需要用户提供注册的客户端 ID 并在官方页面授权。

新邮件通过 IMAP IDLE 唤起原有增量同步，监听失败或服务器不支持时保留轮询。默认轮询间隔调整为 60 秒；已有配置显式设置的间隔继续生效。监听最多同时覆盖 8 个账号，其他账号保留轮询；暂停、退出账号和退出应用会停止对应监听。

## 稳定性与处理边界

- 数据迁移只新增列、表和派生索引，不删除原邮件或草稿。邮箱处理状态、模板、附件索引、联系人、发件任务均按账号隔离。
- 定时发送依赖本机开机、联网和 MailAI 运行。退出或休眠期间无法保证准时发送，恢复运行后会处理到期任务；最长安排到一年内。
- 发送队列在实际领取任务时再次核对到期时间，避免修改时间后仍提前发送。发送前持久化邮件标识；结果不确定时保留核对状态，不自动重发，人工确认送达后恢复跟进安排。
- 草稿修改和加入发送队列都在数据库事务中检查版本及已有任务。独立窗口参与退出保存；保存失败时保留窗口和输入。
- 附件文字解析在限时独立进程中执行，最多两个解析进程；单文件最多 10 MB、原始邮件最多 40 MB、文字最多 16000 字符。超时停止解析，原文件保留。扫描图片、图表、格式和截断范围外内容不属于文字差异核对结果。
- 根据用户验收反馈，移除阅读区的安排处理、会话进展与更多工具整排入口；撤掉单封/会话模式切换，默认逐封展示。旧处理记录保留，筛选面板仍可检索既有状态。
- 搜索、模板和导入表单保留失败输入；异步结果绑定账号和当前弹窗，过期响应不覆盖新界面。显示密度和侧栏折叠偏好保存在本机。

## 本地验收补齐

- 写信的发送安排支持成功发送后 1 天、3 天、7 天或指定时间的未回复提醒；安排随草稿保存。同步到关联的正常回复后停止提醒，未同步到的回复不做猜测，提醒不会自动发出催办邮件。
- 常用短语可在正文光标处插入，选中内容时替换该段；通过原生编辑命令保留撤销能力。其他正文、附件、引用和签名不变。
- 阅读页根据明确的邮件引用和签名标记折叠历史内容；原文保留，点“展开原文”即可查看。没有明确标记时保持原文展示。
- 邮件列表头部只保留标题、数量、筛选和排序；移除全部/重点/待回复等快捷按钮、办公工具、高级搜索和紧凑显示重复入口。联系人互导、附件工具、模板和发件任务归入各自板块。
- 本地 PKG 与便携应用的 446 个文件和链接逐项相符，最新界面资源已核对。安装包解包后的应用也通过启动体检，默认配置仅观察，没有内置账号、模型密钥或邮件数据库。


本次 UI 验收补充：通讯录导入与导出分为两个标签页，导入需预览确认；附件内容搜索直接读取选定文件，比较结果按第一份/第二份分色展示；已分享文件说明创建、到期与重新生成的步骤；局部润色先关闭建议弹窗再写入正文，并支持撤销。三个邮箱图标改为信封、收件托盘、向外箭头托盘，减少装饰线条。
