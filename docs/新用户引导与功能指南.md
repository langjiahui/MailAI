# 新用户引导与功能指南

适用于 Web／桌面当前源码；Android 与 iOS 的引导独立维护。本次不变更产品版本号，发布时按完整变更及最近正式版重新判断。

## 首次使用

1. 连接邮箱。邮箱授权码和模型 API Key 分开配置，可以稍后连接、先了解界面。
2. 邮箱连接后先进入阅读流程，不自动弹出模型配置。同步中、同步中断、空邮箱各有对应提示；没有邮件时不阻塞完成基础教程。
3. AI 是可选步骤。可以从使用帮助或小邮中配置，验证通过才保存启用；验证失败保留输入，提示失败原因。
4. 在一封真实邮件上完成阅读，再按需要体验总结与待办。模型不可用不影响正常阅读邮箱。

## 进度与升级

「设置 → 使用帮助」显示邮箱连接、真实打开邮件、小邮成功回答三项进度。连接状态按当前配置更新；打开邮件以成功读取详情为准；成功回答才记录小邮体验完成。配置模型不等于完成一次问答。

保留 `mailai.onboarding.v2` 及原跳过、完成字段。旧用户不因升级强制重走新手流程；已有成功对话记录也可识别为小邮已使用。新增的真实阅读进度没有历史证据时不猜测为完成。重新体验基础教程保留已完成的实际阅读和问答记录。进度不包含邮箱正文、密码或模型密钥。

新功能从帮助页可折叠的「用好这些新能力」进入，按具体任务跳转。无需先重新体验整套教程。功能入口只导航或打开阅读、设置与工具，不会直接发信、清理服务器、兑换物品或调用模型。

## 附件与模型说明

邮件内从「问小邮」默认讨论正文和附件，材料清单可排除文件，跨邮件浏览不会自动替换会话范围；附件中心保留指定文件模式。附件本地内容搜索与小邮模型分析各自说明读取范围，不能把搜索的限制直接当成模型限制。PDF 原文件直传需要验证接口支持；纯文字模式看不到扫描页和图表；图片识别开启并验证后可逐页阅读。Office 主要读取结构化文字，不承诺完整图表与排版。邮件中的“问小邮”默认纳入正文与附件，无需选择或加入材料。打开对话、查看清单与预览不调用模型，发送问题才开始分析；同封邮件持续保留上下文与排除项，每次请求重新读取原附件。附件中心保留指定文件分析。

启用 AI 后，自动邮件分析和空闲记忆整理也可能发送所需内容至所选服务。说明不得暗示只有手动点击小邮才联网，也不得将本地保存等同全部离线。

## 维护与验证

新增用户能力时同步检查首次引导、帮助主题、搜索与 FAQ、界面入口及中英文说明。目录数量从实际主题计算，避免固定数字过期。继续使用三主题的语义颜色与明暗外观，不为引导单独固定绿色或深色背景。

浏览器回归覆盖连接后不强制配置 AI、失败不保存、成功恢复原表单、空邮箱跳过、延后与重启、真实阅读与回答进度、重新体验不丢进度、附件指南跳转与搜索，以及整封邮件材料清单、连续追问与排除项恢复。布局检查覆盖 Chromium／WebKit、三主题明暗、中英文及窄屏到宽屏。
