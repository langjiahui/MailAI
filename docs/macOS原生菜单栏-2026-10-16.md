# macOS 原生菜单栏

为安装版的顶部系统菜单接入现有应用功能，窗口内入口继续保留，其他平台沿用原有界面。

| 菜单 | 项目 |
| --- | --- |
| MailAI | 关于 MailAI、检查更新、设置、服务、隐藏、隐藏其他、全部显示、退出 |
| 编辑 | 撤销、重做、剪切、复制、粘贴、全选 |
| 显示 | 放大、缩小、标准字号、布局与外观、切换全屏 |
| 窗口 | 最小化、缩放窗口、显示主窗口、前置全部窗口，以及系统维护的窗口列表 |
| 帮助 | MailAI 使用帮助、快捷键说明、反馈问题 |

- 设置使用 `⌘,`，退出使用 `⌘Q`，字号使用 `⌘+`、`⌘-`、`⌘0`，全屏使用 `⌃⌘F`，最小化使用 `⌘M`。编辑操作保持 Cocoa 响应链，作用于当前输入框或写信窗口。
- 关于、设置、帮助、字号和检查更新复用已有页面与操作。检查更新不会自动安装，安装仍走已有确认流程；反馈打开公开的问题页面，不附带邮件、日志或账号信息。
- 主窗口隐藏时，页面菜单会先显示主窗口。启动或页面重新加载期间暂存菜单动作；切换独立写信窗口后，pywebview 重建菜单时仍保留应用菜单。
- 中英文沿用保存的应用语言，并可即时切换。帮助菜单注册为系统帮助菜单，支持 macOS 原生菜单搜索；服务、窗口菜单使用系统原生入口。
- 退出继续通过现有 AppDelegate 的草稿保存流程。编辑弹窗尚未完成时，页面跳转给予提示并保留输入；字号调整仍可使用。快捷键说明入口会清除帮助筛选并定位到对应说明。
- `tests/test_macos_menu.py` 覆盖真实 Cocoa 菜单对象、原生 selector、快捷键、语言刷新、启动暂存、页面重新加载和窗口切换后的菜单重建。
- `tests/test_native_menu_browser.cjs` 在隔离邮箱验证页面入口、快捷键说明、字号保存和边界、更新检查去重、弹窗及草稿保护；Chromium 和 WebKit 均通过，不发送真实邮件或安装更新。
- 完整离线门禁 `244/244` 通过；页面重新加载保护的补充检查也已通过。本功能纳入 v2.9.0，旧版本号保持不变。
