# 小邮礼物发放工具

双击项目中的 `scripts/小邮礼物发放.command`，使用原有发放密钥启动。升级此工具不需要重新初始化密钥，也不需要用户更换领取编号。礼券与已发布的新版小邮兼容。

## 发一整套

1. 在「按套系挑选」选择晨光邮局、云间远航或旗舰星海巡邮，右侧显示整套参考造型。查看参考不会自动选择礼物。
2. 点击「加入整套」。所有部件加入待发放清单，预览切换为「所选礼物」。可以再加另一套，或展开「单件搭配与工作区主题」调整。
3. 填写礼包名称、专属或活动礼包及领取期限。专属赠礼需要用户提供「小邮 → 领取礼物 → 我的领取编号 → 客户端领取编号」。活动礼包每个客户端可领取一次。
4. 确认右侧实际发放清单，生成领取券，再复制或导出 `.mailaigift` 文件。收礼人从「小邮 → 领取礼物」粘贴领取券或导入文件，验证、预览并确认领取。

每张礼券最多 8 件。晨光邮局 3 件、云间远航 3 件、星海巡邮 4 件；任意两套可一起发放，三套需分券。达到上限时工具保留当前选择，并提示还需多少空位。部分选择可点击「补齐此套」，已完整选择可点击「移除此套」；其他已选礼物保留。

## 预览与领取后的行为

- 名称、套系成员、装备部位和角色 SVG/CSS 均来自客户端同一份源码；星轨披风沿用旧商品 ID，因此旧券仍有效。
- 「整套参考」展示当前套系的完整造型；「所选礼物」只展示待发放清单里的部件。同部位一次显示一件，多套礼包可在客户端切换搭配，工作区主题在客户端启用。
- 小邮雀／小邮鱼切换只改变预览，不改变礼物。预览使用第五阶段示意，实际随收礼人的成长形态变化。
- 领取免费且无成长等级门槛，进入永久库存并计入套系进度；已有部件只计一次。领取不替换当前穿戴，用户可以随后自由搭配或整套穿戴。
- 生成结果遇到连接中断时，保留原请求并锁定编辑。点击「核对并重试」找回同一领取券；最近发放记录也可找回原券。

## 命令行

`--items` 继续兼容原用法；也可直接按套系生成：

```sh
.venv-build/bin/python scripts/companion_gift_issuer.py issue \
  --collections star --title '星海巡邮见面礼' --campaign \
  --output /tmp/star-courier.mailaigift
```

可传入 `post cloud` 等多个套系，总数仍受 8 件限制。CLI 不覆盖已有输出文件。

## 验证

离线赠礼测试覆盖三套实际签发、领取、一级整套穿戴、零花费及重复领取不重复累计；浏览器测试覆盖整套／单件联动、容量保护、真实签名与导出、断线恢复、中英文、深浅色、两种形象和窗口／字号矩阵。工具继续使用原有本机访问限制、系统凭据库与离线签名验证。
