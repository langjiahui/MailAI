# MailAI 部署推广指南

## 一、部署方式选型

| 方式 | 适用对象 | 优点 | 缺点 |
|---|---|---|---|
| **源码 + 一键安装脚本** | 有 Python 环境的开发/安全人员 | 最灵活、便于更新迭代 | 需要装 Python |
| **PyInstaller 打包成 exe** | 普通业务同事 | 双击即用、零依赖 | 首次打包需调试；更新要重发包 |
| **部门集中部署（1 台机器服务多人）** | 试点阶段 | 只维护一套 | 需要访问他人邮箱授权，合规上要注意 |

推荐路径：**试点期用方式一（脚本安装），规模化推广用方式二（打包 exe）**。

## 二、方式一：源码 + 一键脚本（当前已就绪）

### 给同事的完整步骤

1. 把项目目录（不含 `data/` 和 `.venv/`）打包成 zip 发给同事
2. 同事解压后双击 `scripts\install.bat`
   - 自动检测 Python → 创建虚拟环境 → 安装依赖 → 生成 `.env` 模板
3. 同事用记事本编辑 `.env`，只需填 4 项：
   ```
   IMAP_USER=自己的企业邮箱地址
   IMAP_PASSWORD=邮箱密码或客户端授权码
   LLM_BASE_URL=https://model-gateway.example.com/v1
   LLM_API_KEY=内网网关的 API Key
   ```
4. 双击 `scripts\start.bat`，浏览器自动打开 http://127.0.0.1:8787

### 打包前请清理

```
排除以下目录/文件，避免泄露你自己的数据：
  .venv/        虚拟环境（同事自己装）
  data/         你的邮件数据库和原始邮件！！必须排除
  .env          你的账号密码！！必须排除
  __pycache__/  缓存
```

> 建议加一个 `scripts\pack.bat` 自动产出干净的发布 zip（见文末附录）。

## 三、方式二：PyInstaller 打包成 exe（规模化推广）

在**你自己电脑上**执行一次打包：

```powershell
# 安装打包工具
.\.venv\Scripts\python.exe -m pip install pyinstaller

# 打包（单文件、带静态资源）
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean `
  --name MailAI --onedir `
  --add-data "app/web/static;app/web/static" `
  --add-data ".env.example;." `
  --hidden-import uvicorn.logging --hidden-import uvicorn.loops.auto `
  --hidden-import uvicorn.protocols.http.auto --hidden-import uvicorn.lifespan.on `
  run.py
```

产出 `dist\MailAI\` 目录，压缩发给同事即可，**同事电脑上不需要装 Python**。

同事侧操作：
1. 解压 → 把 `.env.example` 复制为 `.env` 并填写自己的邮箱配置
2. 双击 `MailAI.exe`，浏览器打开 http://127.0.0.1:8787

注意事项：
- FastAPI/uvicorn 打包常缺 hidden-import，上面命令已包含常见项，如启动报 `ModuleNotFoundError` 按提示补 `--hidden-import`
- 数据目录会在 exe 旁生成 `data/`，用户各自独立
- 企业内网杀软可能误报，提前与 IT 安全组报备加白名单

## 六、FAQ 预置

| 问题 | 排查 |
|---|---|
| 启动后拉不到邮件 | 检查 IMAP_HOST/密码；企业邮箱可能需在网页端开启 IMAP 并生成「客户端授权码」 |
| LLM 分析无结果 | 检查 LLM_BASE_URL/API_KEY；内网自签证书设 `LLM_VERIFY_SSL=false` |
| 8787 端口被占用 | 改 `.env` 里 `WEB_PORT` 为其他端口 |
| 误报太多 | 把该发件域加入 `.env` 的 `TRUSTED_DOMAINS`；或在面板点「举报误报」 |

## 附录：发布打包脚本（scripts\pack.bat）

```bat
@echo off
chcp 65001 >nul
cd /d %~dp0..
set OUT=MailAI_release.zip
if exist %OUT% del %OUT%
powershell -Command "Compress-Archive -Path app,run.py,requirements.txt,.env.example,README.md,scripts,tests -DestinationPath %OUT%"
echo 已生成 %OUT%（不含 data/、.venv/、.env）
```
