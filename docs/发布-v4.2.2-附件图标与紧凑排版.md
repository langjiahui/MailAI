# MailAI v4.2.2：附件图标与紧凑排版

- 基准版本：v4.2.1
- 变更类型：PATCH
- 目标版本：v4.2.2
- 判断依据：本次完整变更是已有附件界面的排版、视觉辨识与主题适配修复，未新增独立业务能力、未改变接口及数据结构。修订号由 1 升至 2，未触发次版本或修订号达到 10 的主版本进位规则。Android 与 iOS 版本独立维护，本次不改号。

## 本次更新

收件箱、已发送、草稿箱和已删除中的附件卡片统一收紧：普通附件高度从 76px 调整为约 56px，减少上下留白和卡片间距；长文件名仍允许两行显示，保留文件大小、打开原件、独立预览和下载入口，触屏操作区域继续保持可用。

邮件阅读区与附件中心共用一套文件图标。PDF、Word、Excel、PPT、图片、压缩包、音频、视频、文本和代码使用独立图形，底部显示 PDF、DOCX、XLSX 等格式标记，未知类型使用通用文件图标。图标按已有文件名及媒体类型呈现，不读取或改变附件内容，也不改变附件中心的筛选分类与查询行为。

附件中心的卡片与紧凑列表都保留格式标记，修正列表列标题与文件信息的对齐。默认及宝武蓝主题使用克制的类型色，深色模式调整图标与标记文字对比度；黑白主题统一使用主题墨色，通过图形和格式区分文件。排除旧配色映射对这套文件类型色的覆盖，保留其他界面的原有主题规则。

## 兼容与验证

保留 v4.2.1 的柔和阅读风格及主线功能，邮件正文仍使用原有隔离渲染；邮箱、凭据、附件字节、邮件收发、草稿、删除恢复及个人偏好保持兼容。

本地完成 267 项离线门禁、凭据扫描、附件打开／预览／下载及大批量列表检查；在 Chromium 和 WebKit 中验证默认、黑白简约、宝武蓝的深浅模式、窄窗口、长文件名和中英文，检查文件类型图形、格式文字对比度与布局。发布执行绑定固定候选提交及 Git 树的原始 full，与三平台候选包构建并行；全部通过后才合并、创建新标签、核验正式安装包并同步国内镜像与签名更新通道。旧标签和安装包保持不变。
