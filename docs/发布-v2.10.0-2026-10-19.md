# MailAI v2.10.0 发布记录

- 基准版本：v2.9.6。
- 变更类型：MINOR。
- 目标版本：v2.10.0（Web/桌面）。
- 判断依据：新增官方国内更新源、跨重启下载续传与自动镜像发布能力；现有安装、数据与自定义更新源保持兼容。Android 使用独立版本线，本次不修改。

## 交付内容

默认客户端从 langjiahui2011/MailAI 的 AtomGit 正式发布读取签名清单，使用内置 Ed25519 公钥校验，按同一版本、大小和 SHA-256 下载。国内源不可用时回退 GitHub；下载中断保留固定哈希对应的部分文件，重启后继续，严格校验 Content-Range，遇到忽略 Range 的 200 响应从头覆盖。完整文件哈希不符立即停止并清理残片。自定义企业更新源不切换仓库。

发布工作流使用 GitHub Actions Secret 中的同步令牌和清单签名私钥；客户端不包含这两项凭据。先通过现有门禁并发布 GitHub 正式版，再推送相同源码与标签到普通 AtomGit 仓库；国内附件逐个免登录整包回读校验，清单最后上传，全部成功后才将国内版本标记为正式。重试只接受完全相同的既有附件，不覆盖已发布文件。

## 维护

国内仓库：https://atomgit.com/langjiahui2011/MailAI 。保持普通可推送仓库，不启用禁止写入的只读代码镜像模式。ATOMGIT_TOKEN 已按维护者要求设为平台“长期有效”（2099-12-31）；权限为项目和 Repository 读写。令牌仅保存在仓库外受限文件和 GitHub Actions Secret。UPDATE_SIGNING_KEY 也仅保存在仓库外与 Actions Secret；公钥随客户端发布。令牌失效后替换 Secret 并手动运行 Sync official release to AtomGit；不改号、不重建或覆盖正式包。

旧客户端首次需要从国内发布页手动覆盖安装；平台免费政策、配额或线路可能变化，当前不承诺永久免费或任何网络条件下均可完成更新。
