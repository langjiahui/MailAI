# 图片与邮件一起分析（2200）

在小邮输入框左侧添加图片，也支持粘贴截图、拖入文件。支持静态 PNG/JPEG/WebP，每次最多 3 张，单张 5 MB、合计 12 MB。普通长截图会在发送时自动规范尺寸；单张超过 6400 万像素、边长超过 32768 或本次合计超过 8000 万像素时，会在选择阶段提示裁剪或分批上传。缩略图可查看大图和移除。

## 办公场景

- 截图提炼：项目沟通、会议白板、排期截图，区分事实、待确认事项和建议下一步。
- 表格整理：把能看清的表格整理成文字，金额/日期看不清时明确标注，不能用猜测补齐。
- 邮件对照：先打开邮件，点击“对照当前邮件”，核对截图与邮件约定是否一致；图片用【图片1】标注，邮件保留可点击来源。
- 故障说明：上传报错截图，说明可见问题和核查建议，不宣称操作已经执行。

## 行为与隐私

- 图片只在点击发送时交给系统配置的多模态模型（MULTIMODAL_MODEL，未单独配置则使用主模型）；自动图片安全复核的开关不影响用户主动上传分析。
- 默认单独看图片，不凭截图问题自动检索其他邮件。可手动选择正在阅读的邮件或当前列表一起分析，沿用邮箱账号边界。
- 图片不能按文本规则自动脱敏，应先遮挡身份证号、工资、客户隐私和企业机密。后台校验真实图片、限制单张与合计解码预算、规范方向、去除元数据，并将长边控制到 2560 像素；细小文字建议提供局部图。
- 原图仅当前页面内存中保留，不写入聊天历史；历史保留附图数量和文字回答。后续核对图片细节需要重新上传，恢复历史不会暗中上传原图。更换账号或新开会话清除暂存图片。
- 图片、二维码和图片中的指令都是参考材料；不自动打开链接、不转账、不发送、不审批、不创建待办。
- 模型不支持图片或接口失败时明确报错；重试保留本次图片，不以无关邮件检索结果冒充图片分析。
