# 日期调整线索

会话进展卡增加本地日期调整线索，识别交付、交期、发货、提交、截止、验收、上线相关正文中的明确调整表达。

- 同一句写明前后日期时并列展示；只写新日期时标为“原文未写明”，不从另一事项拼凑旧日期。
- 区分提出调整、原文表示已确认、发现调整表述待核实。标签描述原文措辞，不验证双方实际达成一致。
- 保留日期原词（例如“下周二”），不猜测具体日期，不自动修改任务、提醒或发送回复。
- 每条线索展示原句、发件人、邮件日期、原邮件入口及已有风险提示。
- 排除常见否定句、引用回复、HTML blockquote 和常见引用容器。一句出现多个日期调整时跳过；匹配属于有限规则，不保证理解所有否定、假设和自然语言表达。
- 只分析本地会话中每封邮件截取的正文（纯文本至多 6000 字符、HTML 至多 12000 字符），最多展示 8 条；没有线索不代表不存在变化。不支持附件差异、金额差异、跨句或跨邮件语义推断。
