# 阅读工作区视觉与交互优化

主界面采用统一的浅色/暗色工作区配色，减少容器阴影与重复边框。邮件列表使用连续行，保留选中底色和左侧标识，普通正常邮件不再重复展示“正常 0”。调整主题、发件人及辅助信息字号，小邮入口缩小。

阅读页突出带文字的回复按钮。往来、稍后提醒、图片识别及普通邮件的安全反馈收进“更多”；需核实风险或隔离中的邮件仍直接显示风险操作。菜单支持点击外部关闭、Escape 关闭并返回触发器焦点。

会话进展默认显示往来数量与变化数量，详细证据按需展开。来源风险提示保留在折叠区域外；刷新保留展开状态。预留加载空间，减少异步加载对正文位置的影响。

验证：完整离线检查 153/153 通过；前端产物一致性检查、差异空白检查通过。实际浏览器检查浅色/暗色、1280px、640px、390px 窗口，验证正文可见性、菜单边界、Escape 焦点恢复、风险操作保留、进展刷新。窄屏无页面横向溢出。使用隔离测试邮箱，未连接真实邮箱或发送邮件。

本轮范围为主界面、列表与阅读页，写信、助手内部与其他弹窗沿用原有样式。长邮件标题、较长摘要以及小屏仍可能需要滚动后阅读正文。
