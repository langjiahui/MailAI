# MailAI v4.0.2（Web／桌面）

- 基准版本：v4.0.1，最近已发布的桌面正式版本。
- 变更类型：PATCH，界面细节与交互反馈优化。
- 目标版本：v4.0.2，修订号由 1 升至 2，未达到编号上限。
- 判断依据：本次完整变更优化既有小邮控件的悬停和按下视觉反馈，并修复空主题邮件的列表布局与空白内容回退；未增加独立用户能力，数据结构与协议不变。
- Android 与 iOS 独立维护版本，本次不调整。

## 更新内容

- 修复无主题邮件在卡片列表中标题行塌陷、摘要与头像重叠的问题；空字符串、缺失值及纯空格均显示本地化占位。收件、已发送、草稿、表格、阅读页和摘要侧栏保持清楚的标题层级；空白摘要回退正文预览，原邮件字段不改写。
- 移除小邮空间控件悬停、按下时的统一外框，避免文字导航出现生硬矩形。
- 顶部和底部文字导航使用文字变色、细下划线及轻微按下反馈；当前导航的选中标记保持独立、清楚。
- 操作按钮保留轻微底色变化，不改变按钮或相邻内容的位置；声音、成长和说话开关在轨道内反馈，开关状态保持清楚。
- 保留键盘焦点提示、禁用状态和减少动态效果偏好，沿用主题配色。原有邮箱、成长、邮票、装扮、库存与本机偏好保持兼容。
- 交互回归按可见颜色、下划线、底色和开关轨道验证反馈，保留悬停与按下不同、无布局移动及键盘可见焦点的断言。

## 验证与发布

功能定稿的本地完整离线检查 264/264 通过；Chromium／WebKit 各 432 个语言、主题、窗口、字号与页面场景通过，覆盖文字对比度、内容边界和导航可达性。两种浏览器的实际按钮交互、试穿与成长操作、角色显示与动画清理回归通过。补查两种浏览器各 12 个语言／明暗主题组合下的无框导航与禁用开关状态，凭据扫描无泄漏。新增空主题回归覆盖两种浏览器各 192 组语言、主题、窗口、字号、头像及密度组合，包含空字符串、缺失、纯空格、长标题、转义内容、缺少摘要和搜索高亮；卡片／表格与本地／服务器已发送和草稿详情、普通阅读页及摘要侧栏保持占位和预览，原有摘要 Markdown 格式保留。

VERSION、README 与本记录定稿后，通过 `scripts/release_desktop.py --execute --head <候选提交>` 并行构建私有三平台候选包和运行原始 full。正式发布以定稿候选完全一致的 Git 树和测试提交为凭证，再执行同树合并、不可覆盖标签、三平台安装包、签名更新清单及国内镜像核验。本地结果不替代正式 full。
