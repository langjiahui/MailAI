# MailAI v4.7.2 发布说明

- 基准版本：v4.7.1
- 变更类型：PATCH
- 目标版本：v4.7.2
- 判断依据：修复现有应用更新流程的权限判断、失败恢复和状态提示，保持功能与数据兼容。

## macOS 更新恢复

- 系统管理员拥有的应用及权限受限的安装位置使用 macOS 系统安装器，由系统处理授权与安装，安装完成后尝试自动打开应用。
- 可直接替换的安装位置继续使用重启更新。应用替换失败时自动重新打开旧版，启动确认前显示更新后的窗口。
- 失败原因保存在本地更新状态中，重启后继续显示失败和重试入口。权限拒绝后切换系统安装器，安装方式变化时重新下载匹配的安装包。
- 旧版已卡在应用替换步骤的用户，可从发布页下载本版 PKG 完成一次覆盖安装，保留本地数据。

## 更新提示

- 后台下载完成使用单一更新入口，重启更新与系统安装显示各自对应的操作文案。
- 更新入口采用统一圆角和低干扰配色，下载完成后收起进度条。
- 发布说明中的 Markdown 链接与加粗标记整理为可读文字。

## 验证

- 隔离原生测试覆盖权限拒绝后的旧版重新打开、启动成功、启动失败回退和启动确认。
- 更新状态测试覆盖失败结果消费后仍保留失败状态、受保护安装选择、更新包校验和显式安装。
- 浏览器检查覆盖中英文提示、后台进度、系统安装器重试和响应式布局。
- 正式发布继续执行完整 full 验证、三平台构建、签名、安装包和国内镜像校验。
