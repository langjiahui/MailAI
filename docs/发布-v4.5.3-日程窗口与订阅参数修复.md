# MailAI v4.5.3 发布说明

- 基准版本：v4.5.2
- 变更类型：PATCH
- 目标版本：v4.5.3
- 判断依据：修复已有日程时间线的冲突漏报和订阅批处理的参数校验，保留有效请求和现有数据的兼容性。

## 修复内容

- 日程时间线按起止区间筛选自建日程。从查询窗口之前开始、在窗口内仍进行的日程会显示并参与冲突检测。先筛选再应用查询上限，避免窗口外的历史记录挤掉近期日程。
- 订阅批处理继续接受整数和整数字符串。小数、布尔值及溢出的数值统一返回 HTTP 400，邮件状态保持原样。
- 更新贡献指南中的浏览器预检和依赖缓存说明，使其与当前 CI 一致。

## 验证

- 回归用例覆盖跨窗口重叠、午夜边界、全天日程、超过 300 条历史日程，以及批处理的非法天数和整数字符串。
- 本地离线门禁 287 项通过，Chromium 和 WebKit 的 12 次办公流程浏览器测试通过。
