# iOS 1.0.0 首版测试构建

- 基准版本：无独立 iOS 正式版本；已查询 GitHub 发布记录，不继承 Android / Web 编号。
- 变更类型：首次建立 iOS 原生产品线。
- 目标版本：产品版本 1.0.0，测试发布标签 `ios-v1.0.0-beta.1`；正式标签保留给后续签名与真机验收通过的正式发布。
- 判断依据：从零新增 SwiftUI 原生客户端，手机独立连接 IMAP/SMTP；后续依照 iOS 自身最近正式版分级，不改变其他端版本。

首版包含多账号、服务器文件夹、邮件头分批加载、缓存搜索和未读筛选、按需正文、离线阅读、HTML 隔离阅读、本地草稿、纯文本新邮件与回复。凭据存入本机钥匙串，强制 TLS 1.2+ 或 STARTTLS 并校验证书。发送前确认，提交状态先持久化；确认丢失或应用中断时禁止直接重发。

交付待签名 arm64 IPA、SHA-256、构建元数据及安装说明。明确标注未签名，不能直接安装，不作为 App Store / TestFlight 版本。设备证书由用户在目标 iPhone 上兑换，卡密、密码、私钥与描述文件不进入仓库或发布附件。

验收：根离线门禁、核心状态与存储测试、模拟 IMAP/SMTP TLS 协议测试、模拟器启动与账号表单、真机构建与安装包元数据。构建记录与实际结果在测试发布时补齐；目标 iPhone 的证书签名和安装验收仍需在设备上完成。

范围限制：iOS 18+；每账号一封本地草稿；当前文件夹最多加载 500 封邮件头；正文每个文本类型最多 2 MB；本版不自动保存服务器已发送副本。附件、抄送/密送、OAuth、通讯录、小邮、后台定时收信和推送后续逐步移植。
