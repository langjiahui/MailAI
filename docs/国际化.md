# 国际化（i18n）

MailAI 的界面以中文为源码语言，国际化采用"属性标记 + 字典覆盖"的渐进式方案，
无需模板引擎或构建期处理，离线可用。

## 工作原理

- `app/web/static/i18n.js` 是前端打包清单（`frontend/sources.txt`）中的第一个模块，
  其余所有脚本都可以直接使用它暴露的全局函数。
- **中文（zh-CN）是源码语言**：HTML 中的静态文案就是中文原文，不经过字典。
- 其他语言在 `I18N_MESSAGES` 中以语言代码为键登记字典（目前提供 `en` 首个切片，
  覆盖顶栏导航、安全菜单、看板头部与常用设置页）。
- 语言选择保存在本机 `localStorage`（键 `mailai-language`），与主题、密度一致，
  不上传服务器；切换后立即套用并派发 `mailai:language-changed` 事件。

## 标记静态文案（HTML）

```html
<span data-i18n="nav.compose">写邮件</span>
<input data-i18n-placeholder="search.placeholder" placeholder="搜索主题、发件人..." />
<button data-i18n-title="nav.sync" data-i18n-aria="nav.sync">...</button>
```

- `data-i18n`：替换 `textContent`
- `data-i18n-placeholder`：替换 `placeholder`
- `data-i18n-title` / `data-i18n-aria`：替换 `title` / `aria-label`

启动时与切换语言时 `applyI18n()` 统一套用；新插入的 DOM 片段可调用
`applyI18n(fragment)` 局部套用。**缺失的键一律回落到 HTML 中的中文原文，
界面永远不会出现空白。**

## 动态文案（JS）

```js
const label = mailaiT('dash.refresh') || '刷新';
```

`mailaiT(key)` 在默认中文下返回 `null`，始终用 `|| 中文原文` 兜底。
渲染完成后如需随语言切换刷新，监听 `document` 上的
`mailai:language-changed` 事件重新渲染即可。

## 添加一种新语言

1. 在 `I18N_MESSAGES` 中新增一个语言代码条目（如 `ja: { ... }`），
   键与 `en` 保持一致；未翻译的键会自动回落中文，可以分批补全。
2. 在设置 → 常用设置 → 界面语言（`#interface-language`）中添加对应 `<option>`。
3. 运行 `tests/test_i18n.cjs`：它会校验 `index.html` 中所有 `data-i18n*` 键
   在英文字典中都有翻译（新语言的字典完整性可自行扩展断言）。

## 键命名约定

点分层级：`区域.用途`，如 `nav.compose`、`tabs.account`、`kpi.pending`、
`theme.lightHint`。同一控件的正文与提示用 `Xxx` / `XxxHint` 成对命名。
新增键时先在字典中登记，再在 HTML/JS 中引用；`tests/test_i18n.cjs`
会拦住"HTML 引用了但字典缺失"的情况。
