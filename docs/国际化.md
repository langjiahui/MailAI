# 国际化（i18n）

界面支持简体中文和英文。中文为源码语言；翻译只作用于应用定义的文案，不翻译邮件正文、主题、联系人资料、用户标签、输入内容或模型生成的回答。

## 加载与持久化

`frontend/sources.txt` 依次加载 `i18n.js`、`i18n-catalog.js`、`i18n-runtime.js`，再加载各界面模块。`i18n.js` 保留语义键字典；`i18n-catalog.js` 登记全局界面及服务提示；运行时负责参数格式化、动态 DOM、CSS 文案和已绑定标签的语言切换。

语言使用 `mailai-language` 保存。桌面偏好通过 `preferences.js` 同步到本机偏好文件，跨启动和本地端口保留；不会发送到邮箱或模型服务。

`app/ui_copy.py` 读取同一份文案目录和已保存的语言，用于 macOS 菜单栏、Windows 托盘、独立写信窗口标题，以及新邮件、待办和跟进通知。保存语言时更新已启动的原生菜单；邮件主题、待办标题和账号地址只作为原文参数传入。

## 静态界面

```html
<span data-i18n="nav.compose">写邮件</span>
<input data-i18n-placeholder="search.placeholder" placeholder="搜索主题、发件人..." />
<button data-i18n-title="nav.sync" data-i18n-aria="nav.sync">...</button>
```

支持文本、placeholder、title、aria-label、alt、data-placeholder 和 data-tooltip 对应的 `data-i18n-*` 标记。文本标记应放在文字叶子节点上，避免替换图标、输入框或事件绑定。新增 DOM 会自动处理这些明确标记；邮件和用户数据不会进入自动翻译。

带参数的 HTML 叶子使用字典中的 `{0}`、`{1}` 等编号，运行时保留原有参数并更新静态文案。选择框必须显式设置 `value`，翻译显示文字时保持服务器枚举值不变。

CSS 生成的提示由 `mailaiCSSCopy` 的自定义属性处理，随界面语言切换。新增 CSS `content` 文字也需要登记翻译。

## 动态文案

原有语义键继续使用 `mailaiT('key') || '中文原文'`。新文案可使用源码文字或带参数的模板：

```js
const label = mailaiText('高级搜索');
const result = mailaiTemplate`已处理 ${count} 封邮件`;
mailaiBindUI(statusNode, 'textContent', () => mailaiText('正在搜索…'));
mailaiBindUI(button, '@aria-label', () => mailaiTemplate`关闭${title}`);
```

`mailaiText` 和 `mailaiTemplate` 必须在 `MAILAI_UI_COPY` 登记中英文。新键为 `ui.` 加中文源码 SHA-256 的前 12 位；已有语义键也可继续沿用。模板参数只能通过文本格式化插入，保留用户内容中的花括号和 HTML 字符；插入 HTML 时仍需转义。

`mailaiBindUI` 保存可重算的文案读取函数。语言切换保留表单输入；节点已被移除或由其他渲染器更新时，旧绑定不会覆盖新状态。静态 UI 对象可通过 getter 返回 `mailaiText`，避免启动时固定语言。安全看板使用已加载的数据更新文案；规则中心重新渲染时保留未保存的权重、开关和焦点。

应用定义的服务错误及状态在显示边界使用 `mailaiSystemMessage`，匹配已登记的完整文案或参数模板。API 的原始错误、协议字段和审计记录保持不变。未知的外部错误会保留原始细节。

## 验证

```sh
python3 scripts/build_frontend.py
node tests/test_i18n.cjs
node tests/test_i18n_coverage.cjs
python3 tests/test_i18n_service_copy.py
python3 tests/test_i18n_native.py
```

覆盖检查扫描前端 HTML、JS、CSS、模板参数和服务校验消息。保留中文的协议枚举、匹配值、内部模型指令等需要在 `frontend/i18n-exceptions.json` 说明用途。该清单不能用于绕过未翻译的可见文案。

浏览器回归使用隔离的测试邮箱：先启动 `venv-mac/bin/python tests/workspace_preview.py`，再运行 `node tests/test_i18n_browser.cjs`。测试检查英文启动、筛选值、归档标题与空状态、高级搜索、联系人导入、附件搜索、待办日历、安全看板、规则中心、设置、写信、错误提示及双向语言切换，并确认用户输入、未保存的规则修改和事件绑定被保留。
