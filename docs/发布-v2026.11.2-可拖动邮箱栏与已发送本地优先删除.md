# MailAI v2026.11.2 发布说明

- 基准版本：v2026.11.1
- 变更类型：MINOR
- 目标版本：v2026.11.2
- 判断依据：新增可手动折叠的邮箱图标栏及四栏布局，并将删除扩展至发送失败或服务器副本尚未同步的本地记录。现有邮箱、草稿和设置可以继续使用，数据库新增字段由客户端自动迁移。

## 更新内容

- **可拖动的邮箱图标栏**。拖动邮箱栏和邮件列表之间的分隔线，可缩到图标栏，也可向右拖回任意支持的宽度。应用会记住收起状态和展开宽度，也支持用键盘操作分隔线。图标可直达收件箱、已发送、收藏和小邮，完整的账号与文件夹列表可以从图标栏打开。提示支持简体中文和英文。
- **邮件工作区四栏布局**。收起邮箱栏后，空间充足时，邮箱图标栏、邮件列表、阅读区和小邮可同时显示。窄一些的桌面窗口会把小邮切换为右侧浮层。图标栏的分隔线与小邮分隔线一样在上下两端渐隐，并随浅色和深色主题调整。
- **已发送优先在本地删除**。单封或批量删除后，从已发送列表立即移除成功处理的记录。发送失败和服务器副本尚未同步的本地记录也能删除并撤销。已知的服务器副本由后台移入垃圾箱，之后发现的匹配副本也会进入同步队列。列表、计数和相关搜索同步排除已在本地删除的记录。
