# MailAI v4.9.2 发布说明

- 基准版本：v4.9.1
- 变更类型：PATCH
- 目标版本：v4.9.2
- 判断依据：本版为「已发送」邮件详情页操作栏与元信息实时多语言绑定的界面及交互细节优化，未新增独立功能模块，不引入破坏兼容性变更，现有账号、邮件、数据库与接口保持兼容。

## 已发送详情页操作栏与多语言细节优化

- **操作栏结构统一与菜单收口**：`app/web/static/app.js` 抽取 `renderReadingMoreActions`，将「已发送」详情页中的「打印邮件」「分享邮件」「删除邮件」等次要及破坏性操作收纳至「更多」菜单，主操作栏保留「再次编辑」「AI 催办」「安排跟进」并补充对应图标。
- **分隔线、样式与键盘焦点一致性**：`app/web/static/reading-polish.css` 与 `app/web/static/special-reading.css` 为「已发送」详情页操作栏同步底部分隔线、菜单悬停/红字删除高亮及移动端触控最小高度（`44px`），并约束非面板内控件的焦点样式边界。
- **元信息实时国际化绑定**：收件人、抄送、密送（`compose.to` / `ui.f482cb6fc793` / `compose.cc` / `compose.bcc`）、时间标签与邮件来源/发送状态标签改由 `data-i18n` 与 `mailaiBindUI` 绑定，实时响应语言切换。
- **自动化回归测试**：在 `tests/test_mail_output_browser.cjs` 补充「已发送」详情页（本地与服务器记录）的「更多」菜单键盘导航（`ArrowDown` / `End` / `Escape`）、焦点恢复及中英文元信息切换断言。
