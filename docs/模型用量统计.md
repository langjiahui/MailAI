# 本机 MailAI 模型用量

统计从启用后开始，覆盖统一模型调用层中的邮件分析、摘要、写信、小邮问答及模型连接测试，不读取订阅额度或供应商账单。按服务商、API 地址和模型分组；同一地址及模型更换密钥不新建分组，也不保存密钥。

每次实际请求独立记录，重试也是新的调用。同一次请求仅写入一次。总量优先使用接口返回的 total_tokens，否则在输入、输出均报告时求和；缓存或推理明细不再叠加。失败、断流或接口没有返回用量时列入“未报告”，不能据此推断没有收费。该数字不是账单级对账数据。

流式调用读取结束标记之前的用量事件，包括正文结束后 choices 为空的事件。未知网关默认保持原请求参数，支持时可在模型扩展参数设置 stream_options.include_usage=true；不支持时不强制请求该字段。

用量保存在用户数据目录的 model-usage.sqlite3，独立于邮箱数据库，不会随着删除邮件而减少。仅保存调用时间、邮箱、服务商、API 地址、模型与 token 数，不保存正文、提示词、响应内容或密钥。更换设备不会自动汇总其他设备记录。

设置的模型配置栏展示全部邮箱累计用量；打开明细后可按今日、本月、全部以及邮箱筛选。面板可见时每三秒刷新，调用完成后更新，不逐字估算。历史调用无法补算，未返回用量时以未报告次数提示。
