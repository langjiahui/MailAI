# 设置滚动条原生兼容修复

本轮改动纳入 v2.8.17。实际发布状态以 [GitHub Release](https://github.com/langjiahui/MailAI/releases/tag/v2.8.17) 为准。

在本机已安装的 v2.8.16 客户端复现了设置页右侧滚动条空闲常驻。安装包相关 CSS、JS 与 v2.8.16 源码一致。macOS 原生 WKWebView 中，旧实现移除了 `scrollbar-visible`，两套颜色属性的计算值均透明，但 `scrollbar-width:thin` 仍让系统滚动条保留 13px。本轮原生回归能在 v2.8.16 源码上直接触发对应断言，避免仅以透明计算值和计时类名作为隐藏依据。

空闲时改为 `scrollbar-width:none`，并对旧引擎使用 `::-webkit-scrollbar { display:none }`；滚动或移动至边缘时显示原生滚动条，空闲约 900 毫秒后隐藏，拖动期间保留。显示与隐藏前测量实际原生滚动条宽度，通过内边距补偿保持内容位置与宽度不变；ResizeObserver 同步延迟打开的分页和窗口缩放。拖动释放采用捕获事件，并在原生滚动条吞掉 pointerup 后通过无按键的指针移动恢复自动隐藏。窗口失焦、页面后台与切页清理状态。强制对比度模式保留系统滚动条。

只修改设置页滚动条，不更改系统“显示滚动条”偏好，不修改已安装应用及其签名，不触碰邮箱数据。CSS 与 JS 均更新缓存版本号。

新增 `tests/test_settings_scrollbar_webkit.py`：在本机实际 WKWebView 中加载生产 CSS/JS 的独立 HTML，检查空闲原生滚动条占位为零、显示/隐藏前后内容宽度稳定、滚动与边缘超时、拖动释放恢复、延迟打开分页和窗口缩放。该检查已加入 macOS 构建前离线门禁。既有双浏览器专项补充了原生滚动条移除和内容几何检查。

本轮验证：原生 WKWebView 回归通过；Chromium/WebKit 各通过 36 组导航与滚动条专项、672 组七页布局及 84 组关于页检查，覆盖六种主题配色、中英文和宽窄窗口。完整离线发布门禁 232/232 通过，包含新增原生检查。
