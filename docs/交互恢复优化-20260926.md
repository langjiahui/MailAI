# 交互恢复优化（2026-09-26）

本轮不涉及付费认证、OAuth、真实邮件发送或 COS 付费调用。

- 搜索框显示当前范围；无结果可清除搜索和附加筛选，或扩大到当前账号全部邮件。搜索错误就地展示并可重试，过期响应不会覆盖新搜索。
- AI 填入后可撤销最近一次主题/正文修改；只恢复本次改动的字段及新增落款，后续手动编辑不会被覆盖。重生成失败保留上一份完整结果，失败的部分流式内容不能应用。
- 普通成功提示自动消失；错误提示保留关闭入口，位于顶部，不拦截底部操作。AI 和搜索失败提供对应位置的重试入口。
- 大附件展示等待、传输、云端保存、完成和失败状态；显示链接有效期，失败可单文件重试或移除。失败项未处理前阻止发送，避免漏附件；上传过程保持草稿/账号隔离。

上传百分比代表浏览器向本地服务的传输，100% 后明确显示“正在保存至云端”，不冒充云端上传完成。上传卡片及重试文件仅保留在当前写信会话中；成功链接及有效期随正文保存。离开后重新打开草稿，不恢复失败文件的二进制数据。

验证：离线发布检查 162/162 通过；新增隔离浏览器测试覆盖搜索恢复、AI 撤销与手动编辑保护、重生成失败恢复、大附件失败重试及避免重复链接。所有浏览器场景使用测试邮箱和模拟 AI/COS 响应，不操作真实邮件。

后续边界修复：失败大附件未重试或移除前，阻止保存关闭及切换发件账号，避免静默丢失文件；切换账号成功后清理旧上传卡片。关闭写信窗口立即取消 AI 生成请求。新增浏览器断言验证失败附件不会随关闭动作静默消失。

以上上传任务仅保留在当前会话的限制，已由后续“任务恢复与搜索反馈-20260926.md”中的本地持久化机制取代：完整保存到本机后可关闭草稿并恢复。
