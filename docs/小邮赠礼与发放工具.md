# 小邮赠礼与发放工具

普通客户端只提供「养成手账 → 领取礼物」，没有发放菜单、发放接口或私钥。发放工具独立运行在维护者的电脑上，不进入 Windows、macOS、Linux 普通安装包。

## 用户领取

1. 打开「小邮 → 养成手账 → 领取礼物」。专属赠礼时，展开「我的领取编号」，点击「复制编号」，把客户端领取编号发给维护者。
2. 粘贴收到的完整 `XYG1.…` 领取券，或导入 `.mailaigift` / `.txt` 文件。
3. 粘贴后点击「验证并预览」（也支持 Ctrl/Cmd + Enter）；导入文件后会自动验证。完整领取券收起，显示礼物、适用范围和期限；装扮卡片右上角的小图标可预览动效。确认后点击「免费领取礼物」。
4. 领取成功后可以在礼物卡片中直接穿戴或应用主题，也可以前往装扮商店定位到赠送的装扮。关闭后仍可从「领取记录 → 查看装扮」找回对应装扮，无需重新导入原券。赠礼不扣邮票积分，不要求成长等级，也不会自动替换正在穿戴的装扮或主题；同类配饰或特效一次只穿戴一件。

页签在滚动时保持可见，窄窗口显示简短名称；领取记录的日期按当前语言和本机时区显示。中英文、明暗配色、默认与积分主题和应用字号放大均有适配。

客户端领取编号由现有 128 位客户端 ID 编码生成，不包含邮箱或硬件信息。切换邮箱、升级和保留用户数据的重装不会改变编号。完整养成备份恢复到空白客户端时保留原编号；合并到已有进度的客户端时保留目标客户端编号，已领取的礼物和领取记录随备份合并。彻底清空资料后会产生新编号，复制完整资料也可能复制编号。

相同礼券重复领取不会重复发放。领取响应丢失时，原券暂存在本机用于核对；重新启动后点击「核对上次领取」即可查询已有记录。待核对时允许预览其他券，领取按钮暂时禁用，以免覆盖原券；核对成功或明确被拒绝后解除。已成功领取的礼物永久保留，即使后来超过领取期限也不会收回。

## 维护者发放

当前维护者的发放密钥已经初始化。macOS 上双击项目中的 **`scripts/小邮礼物发放.command`**，会打开独立的本机发放界面。关闭启动它的终端即可停止工具。普通用户不需要该脚本。

发放工具可选择：

- **专属赠礼**：填写用户的客户端领取编号，只能由对应资料领取。
- **活动礼包**：可以发给多人，每个客户端领取一次。
- 一次选择 1 至 8 件已有永久装扮或主题；成长莓等消耗品不支持赠送。
- 设置领取期限或不限期，生成后复制兑换码或下载兑换券文件，再自行发给用户。

发放页面展示选中的礼物和领取范围，满 8 件后禁止继续选择。领取券默认收起，以「复制领取券」「导出文件」完成交付。最近 20 条发放记录可以找回原券，不重新生成，并同时显示礼包中的装扮，便于区分同名礼包。找回的券会标注「已找回原领取券」，与待发放的表单区分。

独立发放页面按浏览器语言初始显示中文或英文，也可手动切换；明暗配色跟随系统。日期、错误、复制反馈和历史记录同步翻译，用户填写的礼包名称和签名领取券原文不变。复制被浏览器阻止时会展开并选中完整领取券，供手动复制。

发放记录保存在发放目录的 `issued.sqlite3`，仅记录签名所需的礼物元数据；私钥仍独立加密保存。生成结果写入记录后才返回。响应丢失或超时会保留原请求编号，重试与刷新后重试均返回同一张券；关闭服务后重新打开可从历史找回原券。旧版 `issued.jsonl` 元数据会自动迁移。

这版赠礼适用于已内置的装扮与主题。新增艺术资源仍需随客户端更新；兑换券不会执行或下载任意代码。

### 私钥与公钥

采用 [Ed25519 数字签名](https://cryptography.io/en/46.0.3/hazmat/primitives/asymmetric/ed25519/)。当前私钥加密保存在维护者用户目录下的 `~/.mailai-gift-issuer/issuer.pem`，目录权限为 `700`，私钥文件为 `600`；解锁凭据保存在系统安全凭据库的 `MailAI Gift Issuer` 服务中，不写入仓库、安装包、兑换券或发放日志。

客户端仅包含 `app/companion_gift_keys.py` 中的公钥。发放工具从未进入应用导入链，也不提供普通客户端可调用的签发接口。独立发放服务只监听本机回环地址，使用随机会话地址并检查请求来源；关闭终端后服务停止。

请通过加密系统备份保存发放目录和对应钥匙串。仅备份加密私钥而丢失解锁凭据，会无法继续签发。不要重新初始化覆盖原私钥；后续轮换密钥时保留旧公钥，以便核对已发出的礼券。

### 命令行用法

```sh
# 发放工具依赖；不改变普通客户端的密钥配置
.venv-build/bin/python -m pip install -r scripts/requirements-gift-issuer.txt

# 打开发放界面
.venv-build/bin/python scripts/companion_gift_issuer.py gui

# 指定客户端的专属券
.venv-build/bin/python scripts/companion_gift_issuer.py issue \
  --recipient '用户复制的完整 XY-… 编号' \
  --items wings orbit theme_baowu --title '小邮见面礼' \
  --days 30 --output "$HOME/Desktop/小邮见面礼.mailaigift"

# 活动礼包；不限制领取期限
.venv-build/bin/python scripts/companion_gift_issuer.py issue \
  --campaign --items scarf sparkles --title '小邮陪伴礼包' \
  --output "$HOME/Desktop/小邮陪伴礼包.mailaigift"
```

仅首次建立新的发放体系才使用 `init --keychain --public-output app/companion_gift_keys.py`。非钥匙串模式会交互要求设置至少 12 位密码；密码不通过命令行参数传递。工具拒绝把私钥初始化在项目目录内，也不会覆盖已有私钥。维护者若使用不同的发放密钥，必须先将相应公钥加入客户端并发布，才能让用户领取其签发的券。

## 离线方案的边界

可以防止没有私钥的人伪造有效领取券。专属券绑定客户端资料，活动券按客户端去重；本机时间用于判断领取期限。离线方案不提供全网总领取次数限制、即时撤销、抵抗修改本机时间或强制阻止客户端程序/资料被修改。这些能力需要后续接入服务端。
