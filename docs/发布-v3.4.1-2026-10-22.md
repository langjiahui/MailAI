# MailAI v3.4.1 发布记录

- 基准版本：最近 Web／桌面正式版 v3.4.0（2026-10-22T08:28:11Z 已公开），提交 86df0237d8e6ffde51af9345f20e4bdc3b3b697a；核对本次全部变更后定级。
- 变更类型：PATCH。修复已有国内自动更新检查在静态入口返回 403 时失败的缺陷，兼容旧数据与配置。
- 目标版本：v3.4.1，不触发编号上限进位。
- 判断依据：恢复既有更新功能的可用性，增加同仓库文件读取容错，不新增独立用户能力或改变兼容性。
- 各端独立：Android 1.4.0 与 iOS 1.0.0 测试版本不改号。

## 修复与验证

- 国内静态 raw 路由返回“暂不支持预览”403，而同仓库文件 API 和发行版附件实际可用。网络／HTTP 失败时，使用固定仓库 updates 分支的匿名文件 API；原静态入口仍优先，以避开共享匿名 API 限流。
- 发布后的公开通道验证复用客户端读取和内置公钥验签；无效 JSON／签名不触发备用读取。保留版本单调递增、同版本字节不可变、非强制推送、完整包大小和 SHA-256 校验。
- 添加访问拒绝、超时、截断、备用入口失效、篡改签名、非法文件路径及 Android 独立清单的回归。执行完整离线发布门禁和云端质量门禁。
- 屏蔽 GitHub 的受控网络环境中，直接运行客户端检查和下载代码，匿名读到 v3.4.0，完整下载 Windows、macOS、Linux 安装包并核对签名清单中的大小和 SHA-256；当前版不误报更新。安装操作不在此验证中执行。发布 v3.4.1 后再次验证最新通道与安装包。
- 老客户端若同时无法连接 GitHub、国内 raw 又返回 403，需先从国内发布页手动覆盖安装本修复版。历史标签和安装包不覆盖。

- 发布门禁中，表格列宽恢复测试改为等待 ResizeObserver 与动画帧重排后的实际几何条件，保留主题列最大及完整布局矩阵断言，避免固定等待两帧造成时序误报。
