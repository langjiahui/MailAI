# 邮件上下文、逐次撤销与窄列表优化

本轮落实重新审视后选定的第一批三项改进。保留现有整体视觉风格、安全结果和助手布局；多账号入口汇总、中等窗口助手布局留待后续。

## 已完成

- **小邮上下文**：邮件内的“问小邮／总结邮件／识别邮件图片”统一绑定这封邮件及当前账号，立即更新范围标签。主动进入另一封邮件时清理旧会话上下文并阻止迟到历史恢复；重复进入同一封保留对话。单纯浏览另一封邮件不会抢走正在进行的对话范围。手动选择当前邮件后，首次提问固定引用，后续追问继续使用它。范围菜单同步显示账号、固定邮件数量和单次分析上限；工作简报打开时，邮件入口会切回对话。
- **逐次撤销**：一次点击只撤销一组用户操作，之后仍可撤销上一组。一次大批量操作跨多个请求时收集为同一组，保留各记录原始有效期；失败只重试本组剩余记录。旧提示不能作用于后来操作，并发点击不会重复执行。撤销完成但列表刷新失败不会重放操作。提示显示邮箱、动作、数量和剩余有效时间。
- **窄列表与紧凑模式**：列表宽度不超过 430 像素时，域名标签让出空间，完整地址仍可通过发件人提示和阅读页查看；保留安全状态、分数和时间。缩小方向图标，移除空状态图标占位。紧凑模式采用独立最小行高，隐藏没有可见内容的标签行，保留账号、附件及风险标签。
