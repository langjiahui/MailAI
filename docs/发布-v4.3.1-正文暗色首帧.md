# v4.3.1：正文暗色首帧

- 基准版本：v4.3.0（最近已发布的 Web／桌面正式版本）
- 变更类型：PATCH
- 目标版本：v4.3.1
- 判断依据：修复现有 HTML 邮件正文主题适配的执行时机并优化加载体验，属于兼容修复；未增加独立能力或破坏兼容性。修订号加一，未达到编号上限；Android、iOS 独立版本不变。

## 用户可见变化

- 修复暗色主题下阅读 HTML 邮件时先白底、等图片加载后才变暗的问题。正文解析完成后立即适配背景和文字，再显示内容，不等待外部图片。
- 收件阅读、来源邮件抽屉、已发送与草稿共用处理。图片继续独立加载并保持原色，保留明暗主题切换及浅色下原始配色恢复。
- 切换邮件时清理尚未完成的初始化、事件监听与尺寸观察；外部图片完成加载不会重复安装正文功能。
- 升级保留已有邮箱、邮件、会话、草稿、成长、装扮及偏好。

## 发布验证

候选定稿后运行完整离线门禁及凭据扫描；Chromium／WebKit 回归测试固定外部图片请求为等待状态，验证正文在 iframe load 前已显示并完成暗色适配、没有可见白色采样帧、明暗切换可恢复原始配色，加载完成不重复初始化，快速切换邮件可清理旧实例。沿用完整浏览器矩阵、原生平台检查、三平台签名构建和同树发布校验。

使用 scripts/release_desktop.py --execute --head 固定候选，私有候选包与原始 full 并行，全部通过后才合并、核对同树产物、创建新标签、发布及验证国内镜像；不覆盖历史标签或安装包。
