# MailAI Android 1.3.0

- 基准版本：Android 独立正式版 android-v1.2.0（versionCode 2100104）。
- 变更类型：MINOR（兼容的新功能）。
- 目标版本：1.3.0；versionCode 2100108；标签 android-v1.3.0。
- 判断依据：新增手机独立连接模型的小邮、邮件要点与回复草稿、正文／选中文字润色，以及通讯录备注编辑；既有账号、邮件、附件和草稿兼容保留，数据库 v3 自动迁移至 v4。Android 与 Web／桌面各自维护版本，按 Android 自身基准升级次版本。安装序号高于已交付验收包 2100107。

## 小邮与模型设置

- 阅读邮件可提炼要点、起草回复；写信可润色正文或选中文字。候选先预览再采用，润色保护后来输入并可在本次编辑撤回，邮件发送仍需确认。
- 沿用原版小邮形象与有限表情过渡，入口融入现有工具栏，不新增常驻浮球或品牌行。模型配置统一位于“账号与设置 → 小邮与模型服务”。
- DeepSeek、Kimi、Kimi Code、自部署和通用 API 提供预设及模型选择，常用配置只需填写 API Key。基础地址自动补齐对话路径；Kimi Code 对齐 Web 的接口、输出预算和流式参数。
- 可取消的测试连接只发送测试文字，不发送邮件或改写已保存配置；区分登录、模型权限、额度和超时等失败，不回显服务端原文或密钥。服务配置与 API Key 通过 Android Keystore 加密保存。
- 模型仅由用户主动触发，重复结果可复用缓存；真实退后台／锁屏取消生成并保留未完成文字，旋转不重复请求。不自动发送邮件或上传附件，不新增小邮后台心跳与定时任务。

## 通知与静默收信

- 补齐 Android 13+ 首次进入可用收件箱后的通知授权。拒绝不妨碍邮箱使用，也不会反复请求，可在设置中再开启。
- 通知设置采用适配窄屏、大字号及深浅色的滚动底部面板；提供真实邮件通知类别的测试通知、后台检查记录、手动检查和取消。
- 小米／Redmi／POCO 提供后台自启动与应用省电设置入口，系统页面不可用则回退应用信息。不把进入设置或 Android 电池优化状态当作小米自启动权限已放行。
- 前台刷新与后台检查分开记录，进程中断不伪报成功；点测试通知前先保存正在编辑的草稿。真实邮件继续按 UID 去重，提醒队列保存后才确认，通知定位对应邮件。
- 每个账号共用同步锁，后台任务在锁内检查最近同步时间，合并重复连接。失败冷却并指数退避，检查结束关闭连接；只检查邮件列表元数据，不自动下载正文或附件。

## 通讯录与连续性

- 初始化时从本设备各文件夹缓存和草稿补齐联系人，不受旧有 500 封扫描上限或通讯录非空影响；只执行一次，后续收信、写信和发送增量更新，不联网下载整箱正文。
- 解码邮件姓名并按地址去重，优先保留有效中文姓名，较旧邮件刷新不覆盖更新的姓名。可编辑联系人备注，手工备注及主动清空姓名优先。
- 数据库 v3 → v4 自动迁移，保留邮件、附件、草稿、通知游标和原有有效联系人名称。失败事务可重试，不使用清库回退。

## 验证与实际边界

发布前执行离线门禁、Android 单元／IMAP／SMTP／模型协议测试、Debug／Release lint 和设备交互回归；使用合成账号和本地服务，不向真实联系人发送测试邮件。固定签名覆盖升级验证邮件、草稿、附件和账号保留，公开后回读 APK 与更新清单并校验大小、SHA-256、包名、版本及签名。

当前仍为手机独立的 15／30／60 分钟定期收信，并非系统级即时推送。Doze、澎湃 OS、自启动、极限省电和后台联网限制可能推迟通知；强行停止需重新打开。小米实体机长期锁屏、通知延迟和耗电仍需现场验证，模拟器结果不能代表实体机续航。

不包含 OAuth、IMAP IDLE、服务端草稿同步、服务器已发送文件夹 APPEND、企业组织目录或小邮后台自动全箱分析。桌面版本继续为独立的 v2.10.1。
