# Android 2.10.0-beta.7 发布记录

- 日期：2026-10-19
- 基准版本：GitHub 最近正式版本 v2.9.4；最近 Android 预发布 2.10.0-beta.6。
- 变更类型：相对 beta.6 为 PATCH 类原有界面与配置填写体验改进；从正式 v2.9.4 起的 Android 整体为 MINOR。
- 目标版本：Android 2.10.0-beta.7；versionCode 2100007；标签 android-v2.10.0-beta.7。
- 判断依据：完善已有登录页、品牌图标与服务器默认值，不改变账号数据和通信协议；目标正式版本仍为 2.10.0，递增测试序号。根 VERSION 与桌面 Latest 保持 2.9.4，历史标签与安装包不变。

## 本轮修改

- 邮箱地址、密码与服务器字段改为紧凑圆角框，独立小标签、柔和浅底、清楚的聚焦边框；移除原下划线，调整标题与留白，连接时展示等待指示。
- 沿用原版玻璃折叠 M，统一桌面、Android 自适应图标、启动画面和添加页；通知与系统主题图标使用同源几何的单色 M。
- 企业或其他有效域名自动填入 `imap.<域名>` 和 `smtp.<域名>`，同时显示域名生成提示和修改入口；常见服务商继续按精确域名匹配。切换域名清除旧参数，不保留错误的 QQ/163 服务器。
- 自动填入仅是可编辑地址建议，不是 DNS 自动发现或连接成功。用户点击“连接邮箱”才开始通信，保持公网地址与 TLS 校验，不自动提交密码。
- 不将个人企业配置或真实凭据写入公共 APK。

## 验证

JVM 42 项，Android 15 AOSP ARM64 设备回归 15 项；添加页另验 320dp × 568dp、200% 字号、深色外观、真实键盘焦点和可滚动的连接按钮。检查原品牌图标在系统桌面和应用页面的实际显示，核对固定签名覆盖升级、debug/release lint 和 244 项项目发布检查。最终执行结果和 GitHub 构建见 verification.json。

所有邮件测试使用合成数据，不向外部收件人发送测试邮件。

## 使用边界

Android 10+。部分企业服务器不遵循标准域名格式，需在“修改”中填写服务商给出的实际地址；默认 TLS 993/465，专用端口、STARTTLS 或登录名在高级设置中调整。OAuth 尚未支持。后台为系统周期调度，深度省电可延迟执行；实体手机和真实邮箱兼容性仍需验收。beta.6 可直接覆盖升级。
