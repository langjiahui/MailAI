# MailAI Android 1.0.2

- 日期：2026-10-19
- 基准版本：Android 独立正式版 android-v1.0.1（versionCode 2100102）。
- 变更类型：PATCH；简化已有邮件阅读界面，完善正文选择复制，不改变邮件协议或数据格式。
- 目标版本：Android 1.0.2；versionCode 2100103；标签 android-v1.0.2。
- 判断依据：移除不必要的文本/原版模式切换，默认直接显示收到的邮件；正文及失败回退都支持常规选字复制。已有原版 HTML、纯文本兼容、附件、草稿和联系人功能保持。Android 与 Web/桌面独立编号，根 VERSION 与 Latest 保持 v2.9.4。

## 本轮修改

- 顶部去掉“文本/原版”切换，保留返回与详情。HTML 邮件直接显示原排版、图片、表格和颜色；只有纯文本的邮件正常显示纯文本，不要求用户选择模式。
- 使用系统正文选择菜单支持长按选字、复制等常规操作。移除原邮件样式中禁止选择文字的声明，保留原有外观；不启用 JavaScript 或开放文件访问。
- 原邮件渲染失败时自动保留可选中复制的文本正文，提供重新显示原邮件；正常阅读不显示模式切换。
- 邮件链接仍由用户点按后确认打开，取消后停留在原邮件。底部详情面板、阅读位置、附件、草稿及收信通知沿用现有行为。

## 安装与更新

1.0.1、1.0.0 或历史 2.10.0 可应用内更新或下载 APK 覆盖安装，不卸载。包名 `com.mailai.mobile`、固定签名及数据库 v3 不变，内部安装序号 2100103 递增；历史标签与附件不改写。旧 beta 客户端首次进入正式通道仍需手动覆盖安装。

更新清单附件名为 `mailai-android-update.json`，继续核对包名、版本、内部序号、SHA-256、大小及相同签名。

## 验证

合成邮件设备验收直接长按 HTML 和纯文本正文、点击系统复制并核对实际剪贴板内容、点邮件链接及取消返回；检查顶部无模式切换。回归原版布局、详情面板、离线内嵌图、渲染失败回退与重试、草稿和通知；执行 JVM 测试、debug/release lint、原有发布门禁、固定签名覆盖安装与 16KB zipalign。最终数量、CI 源码与限制见随包 verification.json。

没有使用真实密码进行认证，没有向外部联系人发送邮件。模拟器结果不代表所有厂商实体机与长期后台均已覆盖。
