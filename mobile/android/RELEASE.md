# Android 2.10.0-beta.8 发布记录

- 日期：2026-10-19
- 基准版本：GitHub 最近正式版本 v2.9.4；最近 Android 预发布 2.10.0-beta.7。
- 变更类型：相对 beta.7 为 PATCH 类界面与交互优化；从正式 v2.9.4 起的 Android 整体为 MINOR。
- 目标版本：Android 2.10.0-beta.8；versionCode 2100008；标签 android-v2.10.0-beta.8。
- 判断依据：按确认的七页设计优化现有功能、触控和导航，没有新增独立用户能力、数据库或协议变更；目标正式版本仍为 2.10.0，递增测试序号。根 VERSION 和桌面 Latest 保持 2.9.4，历史标签和安装包不变。

## 本轮修改

- 邮箱总览改为分组卡片；收件箱用紧凑列表和柔和筛选条；阅读页突出正文、联系人和附件；写信使用圆角输入区及固定发送操作；草稿记录清楚区分草稿、失败与结果待确认；通知与更新沿用同一套间距和卡片。
- 收件箱、阅读、写信和草稿内容页不再为品牌 Logo 独占一行；连接与邮箱总览保留原玻璃折叠 M。
- 进入/返回用相应方向的短位移和淡入，写信从下方进入；缩短旧页淡出以减少文字重叠。各页固定容器，状态反馈平滑展开，尊重系统动画设置。
- 返回保留列表位置，切换不同邮件/草稿时重置各自阅读位置；完整缓存的已读邮件直接打开，避免短促的加载闪动；回到当前邮箱先保留内容再刷新。
- 连续导航不重复创建草稿；草稿离开确认、自动保存、失败重试和待确认时锁定重发继续保留。服务器地址仍是可修改建议，不宣称自动验证成功。

## 验证

JVM 42 项；Android 15 AOSP ARM64 设备回归 17 项，新增七页原生截图、过渡中间帧、返回滚动位置与连续写信回归。另检查 320dp 窄屏、200% 字号、真实键盘避让及深色外观。固定签名覆盖升级、debug/release lint、16KB zipalign 与现有 244 项发布门禁。具体结果、源码提交和 GitHub 构建见 verification.json。

测试使用合成的本地邮件与账号，不向外部收件人发送测试邮件。模拟器截图用于布局与状态验收，实体手机上的帧率、触感和实际服务商登录仍需测试。

## 安装

Android 10+，beta.7 可直接覆盖安装，保留邮箱和草稿。后台收信仍受系统周期调度和省电限制；更新安装仍需系统确认。OAuth 暂未支持。
