# MailAI Android 1.3.0

状态：本地开发与验收目标，尚未创建正式发布标签。

- 基准版本：Android 独立正式版 android-v1.2.0（versionCode 2100104）。
- 变更类型：MINOR（兼容的新功能）。
- 目标版本：1.3.0；versionCode 2100105；正式发布时使用标签 android-v1.3.0。
- 判断依据：新增手机独立连接模型的小邮、当前邮件摘要与回复草稿、正文／选中文字润色、候选预览与撤回，按 Android 自身版本线升级次版本。既有邮件数据库 v3、账号、固定签名和草稿继续兼容；Web／桌面独立。

## 小邮

收件箱和阅读工具栏复用原版小邮形象，不新增悬浮球或占一行；写信工具条增加“润色”。底部面板按当前邮件或草稿呈现操作，补充要求按需展开。模型配置统一收进“账号与设置 → 小邮与模型服务”，小邮面板不常驻设置按钮；首次未配置时可前往设置，返回原邮件位置。初期提供提炼要点、起草回复和润色，均由用户主动发起；无语音、养成商店、跨设备同步或自动全箱分析。

手机直接使用用户配置的 HTTPS Chat Completions 兼容接口，API Key 使用 Android Keystore 加密后原子保存。第一次保存配置说明发送范围与服务费用可能性；更改接口地址不能默认沿用旧 Key。默认仅公网，用户明确配置的企业内网服务可使用 VPN／公司 Wi-Fi；证书和域名验证继续生效。不跟随跳转、不自动重试、请求与响应有大小和时间上限。

流式结果可复制；完成前不允许采用。回复先预览，采用后保存本地草稿，仍需原发信确认。润色检查原正文与格式版本，不能覆盖后来输入；选区之外文字、收件人和附件保留，当前编辑会话可撤回润色。失败不改原稿，取消保留部分结果并标注未完成；换邮件或账号关闭旧面板，迟到结果隔离。

## 轻量与能耗

静态待机；处理中侧头、完成微笑，只有有限状态过渡，无循环呼吸、粒子、GIF 或额外 WebView。遵循系统动画与省电设置。小邮不添加后台服务、心跳、Worker、精确闹钟或 WakeLock，不改变收信频率。锁屏／真实退后台取消模型请求并保存部分结果，旋转不重复请求；返回不自动重发。完成结果按账号、正文版本、操作和服务配置缓存，重复使用不调用模型。

流式文字合并更新，不逐字符播放；结果缓存最多 40 项，单项 32000 字以内。原邮件、附件和其他账号不会自动发送给模型。长文本超过处理上限会提示缩小范围，不静默截断后宣称已分析全篇。

## 验收边界

使用合成账号、候选数据和本地 HTTPS／SSE 服务验证，不调用真实付费模型或真实邮箱。实际第三方服务、实体机触感、温控、移动网络功耗与锁屏 8 小时能耗对照需后续实机验收，不能以模拟器证明续航收益。Android Doze 或厂商省电对邮件通知的延迟限制继续存在。
