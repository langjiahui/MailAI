# MailAI Android 1.3.3

- 基准版本：Android 独立正式版 android-v1.3.2（versionCode 2100110）。
- 变更类型：PATCH。
- 目标版本：1.3.3；versionCode 2100111；标签 android-v1.3.3。
- 判断依据：修复已有姓名、主题、附件名及正文解码和历史联系人学习的编码兼容问题，不增加独立业务能力，不改变账号、邮件、草稿、附件或数据库结构。Android 与 Web／桌面独立维护版本。

## 中文编码与联系人

- 修复实际使用 GBK／GB18030、却声明为 UTF-8 等错误编码时的中文乱码；未知编码逐级尝试严格解码，避免直接出现乱码或暴露整段 MIME 编码串。兼容有效的繁体中文及其他语言编码。
- 从原始邮件头解码姓名和主题，先解析地址结构再显示姓名；姓名中的逗号、引号等标点不再影响收件人拆分。列表同步和服务器搜索批量读取原始主题头，不为每封邮件增加单独的主题请求。
- 正文与附件名使用相同的严格解码兼容方式；正文大小限制及附件路径清理继续生效。
- 一次性重新学习已有缓存邮件和草稿中的联系人，优先使用完整姓名，不让新的乱码覆盖完整历史姓名。保留人工维护的姓名和有意清空的姓名。
- 已丢失字符且没有完整缓存来源的自动姓名显示邮箱，后续同步有可靠姓名时继续补齐，不根据拼音或邮箱猜姓名。不改写原始邮件、草稿、通知游标或手工备注。

## 验证与升级

使用合成 MIME 邮件及本地模拟 IMAP／SMTP 服务器覆盖 B／Q 编码、错误编码声明、未知编码、混合中文、标点姓名、主题和正文读取，以及旧联系人恢复和手工备注保护。执行完整 JVM 测试、Android 设备编码验证、Release lint 和正式签名构建，再校验 APK 元数据、SHA-256、固定签名及公开更新清单。

发布源码已通过 120 项 JVM 测试（含模拟 IMAP 收信至正文读取）、Android 15 设备编码验证、Release lint 和 249 项离线门禁。正式构建再次执行 JVM 测试及 Release lint，验证固定签名、安装序号、APK 元数据和公开更新清单。

使用原固定签名和递增安装序号覆盖升级，保留账号、邮件、草稿及附件；不新增后台定时任务、不提高收信频率。Web／桌面版本独立发布。
