# Android 2.10.0-beta.4 发布记录

- 日期：2026-10-18
- 基准版本：GitHub 最近正式版本 v2.9.4；最近 Android 预发布 2.10.0-beta.3。
- 变更类型：本轮相对 beta.3 为 PATCH 类兼容性修复；从正式 v2.9.4 起的 Android 整体为 MINOR。
- 目标版本：Android 2.10.0-beta.4；versionCode 2100004；标签 android-v2.10.0-beta.4。
- 判断依据：补齐既有收发邮件、草稿和后台恢复的异常处理，没有新增独立产品能力。Android 目标正式版本仍为 2.10.0，递增测试序号；根 VERSION 与桌面 Latest 保持 2.9.4。已发布标签及安装包不变。

## 本轮修复

- 离线提示与本地使用：缓存正文、已下载附件和草稿仍可用；无网络时及时结束连接等待，联网后由用户重试，不自动发送。
- 弱网反馈：等待超过 8 秒提示仍在处理；区分超时、断网、本地存储失败；保留原始错误详情和重试入口。
- 发送防重：同一事务保存内容与开始发送状态；禁止并发发送和旧编辑快照覆盖发送记录。失败后界面重新核对数据库状态；确认不明确时锁定重发。
- 后台恢复：切后台补存当前草稿；返回原任务时通过 Android 保存的导航 ID 从数据库恢复草稿。任务状态不放邮件正文、附件内容或授权码。
- 保存失败：编辑器保留新内容并显示失败，不误称已保存；可明确重试。

## 验证

- JVM 33 项；Android 15 AOSP ARM64 设备测试 13 项；既有发布门禁 244 项。
- 本地 TLS 邮件服务器模拟 IMAP 回复中途断流、附件传输中断、SMTP 连接前中断、延迟确认和确认丢失；核对接收端提交次数和缓存、草稿、附件内容。
- 系统 Wi-Fi/移动数据关闭再开启、前后台切换、200% 大字号窄屏；独立终止测试应用进程，再从原任务恢复。
- 固定签名覆盖升级、GitHub 构建与分发校验结果见 verification.json。

## 使用边界

Android 10+。后台收信受系统周期调度及省电策略影响；发送结果待确认时请先核查邮箱，不提供直接重发。所有邮件测试使用本地合成数据，没有发送外部测试邮件。真实手机、厂商省电策略和真实邮箱长时兼容性仍需验收。

安装包、更新清单、SHA-256、发布说明与验收记录发布到 GitHub 预发布通道，不包含凭据和真实邮件。beta.3 可覆盖升级到本版。
