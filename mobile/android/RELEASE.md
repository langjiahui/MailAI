# MailAI Android 1.3.1

- 基准版本：Android 独立正式版 android-v1.3.0（versionCode 2100108）。
- 变更类型：PATCH（兼容的界面与交互修复）。
- 目标版本：1.3.1；versionCode 2100109；标签 android-v1.3.1。
- 判断依据：统一已有底部面板的视觉、手势与过渡，修正重复顶部留白和内容加载后操作区被挤出屏幕的问题；未增加独立业务能力，不改变账号、邮件、草稿、附件格式及数据库结构。Android 与 Web／桌面独立维护版本。

## 更紧凑的底部面板

- 应用更新、后台收信、邮件详情、附件和小邮共用紧凑标题栏，补齐拖动横杠。
- 去掉面板内部重复的状态栏留白，横杠距面板顶边约 8dp；系统状态栏、导航栏与键盘安全区域分别处理。
- 支持上拉展开、下拉收起或关闭，保留“完成／关闭”按钮；长面板的系统返回先收起，再次返回关闭。
- 正文和联系人列表滚动与面板拖动衔接，滚动查看较早内容不会误关面板，标题与退出按钮保持可见。

## 小邮与内容连续性

- 短结果按内容收紧，不以大块空白撑满屏幕。
- 加载或生成结果改变面板高度时，保持已展开的阅读状态，避免采用回复等底部操作落到屏幕之外。
- 关闭过程遇到内容完成不重新展开面板；关闭动作采用收起动画，取消动画后仍可继续操作。

## 验证与升级

- 使用合成邮件验证实际上下拖动、滚动防误关、按钮关闭、内容缩短和关闭过程中加载结束；覆盖普通屏幕、窄屏 200% 字号和深色窄屏。
- 回归邮件详情长主题、多人收件人、抄送、返回阅读，以及小邮预览和采用后草稿持久保存。
- 执行发布门禁、Android JVM 测试和 Release lint；固定签名、包名、安装序号、SHA-256 与更新清单一致性均在发布流程核验。
- 直接覆盖安装，保留已有账号、缓存邮件、草稿和附件，无需卸载。

本轮未改变后台收信频率、网络路由、模型调用方式或更新下载协议，不新增常驻服务或周期任务；实体机长时间锁屏通知与耗电仍需现场验证。Web／桌面版本继续独立维护。
