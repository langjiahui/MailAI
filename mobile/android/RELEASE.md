# Android 2.10.0-beta.9 发布记录

- 日期：2026-10-19
- 基准版本：GitHub 最近正式版本 v2.9.4；最近 Android 预发布 2.10.0-beta.8。
- 变更类型：相对 beta.8 为 PATCH 类现有操作路径与反馈优化；从正式 v2.9.4 起的 Android 整体为 MINOR。
- 目标版本：Android 2.10.0-beta.9；versionCode 2100009；标签 android-v2.10.0-beta.9。
- 判断依据：完善现有回复、草稿、搜索和状态反馈，没有增加独立能力或不兼容变更。目标正式版本仍为 2.10.0，递增测试序号；根 VERSION 与桌面 Latest 保持 2.9.4，已发布标签与安装包不变。

## 优化

- 回复保存或放弃后回到原邮件；编辑旧草稿后回到草稿记录。恢复编辑状态保留来源页面标识；原邮件不在缓存时回到收件箱，避免空白阅读页。
- 搜索框可直接清除；无匹配邮件与无未读邮件给出各自说明和“查看全部邮件”入口。改变搜索或筛选后回到列表开头，普通阅读返回继续保留位置。
- 同步完成、草稿保存/移除、附件添加等普通成功提示在 4 秒后自动收起；错误、取消、待确认发送及附件打开/分享提示持续保留。
- 保持 beta.8 的七页样式与过渡。保留离开草稿确认、发送前确认、保存失败重试及发送结果不确定时锁定重发，不自动重发。

## 验证

JVM 42 项，Android 15 AOSP ARM64 设备回归 22 项；新增回复返回、草稿保存/放弃返回、搜索清除与未读空状态恢复、普通提示消失但错误保留、重建编辑状态与来源邮件缺失回退。另以 320dp 窄屏、200% 字号与深色外观复验日常交互。核对固定签名覆盖升级、debug/release lint、16KB zipalign 和既有 244 项发布门禁；最终执行记录及 GitHub CI 见 verification.json。

所有邮件测试使用合成本地数据，没有向外部收件人发送邮件；真实手机帧率、触感、实际邮箱登录和厂商后台策略仍需验收。

## 安装

Android 10+，beta.8 可覆盖安装，保留邮箱和草稿。后台为系统周期调度，省电可能延后；更新安装需系统确认。服务器域名建议仍需核实，OAuth 尚未支持。
