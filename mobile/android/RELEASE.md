# MailAI Android 1.0.1

- 日期：2026-10-19
- 基准版本：Android 独立正式版 android-v1.0.0（versionCode 2100101）。
- 变更类型：PATCH；优化已有邮件详情的布局、信息层级与操作反馈，不新增独立业务能力。
- 目标版本：Android 1.0.1；versionCode 2100102；标签 android-v1.0.1。
- 判断依据：现有详情由居中弹窗改为底部面板，联系人既有查看/复制/保存操作整理为原地展开；邮件协议、发送、数据库与账户格式未变化。Android 与 Web/桌面各自编号，根 VERSION 与 Latest 保持 v2.9.4。

## 修改内容

- 点“详情”后从底部展开宽面板，保留上方阅读背景，明确所处位置。完成按钮固定，主题、完整日期时间和名单在面板内滚动。
- 主题与联系人分区，姓名/邮箱区分字号和颜色；发件人、收件人、抄送分别标明人数。长主题、长邮箱允许换行，不显示 MIME 编码。
- 不再在名单中逐条显示“存入通讯录”按钮；点具体联系人原地展开复制/保存操作，再点收起。同一时间只展开一个联系人，不新开一层弹窗。
- 复制邮箱后显示短暂确认；保存中禁用重复点击，成功显示已在通讯录，失败保留原因和原操作重试入口。
- 面板支持完成、下滑、点击遮罩与系统返回关闭，返回原邮件；已有阅读位置、草稿和附件保留。

## 安装与更新

1.0.0 或历史 2.10.0 可通过应用内“通知与更新”或本页 APK 覆盖安装，不卸载。包名 `com.mailai.mobile` 与分发签名不变，安装序号 2100102 高于所有旧包。历史 beta 客户端首次进入正式通道仍需手动覆盖安装。

更新清单附件固定为 `mailai-android-update.json`，校验可见版本、安装序号、SHA-256、大小、包名及固定签名。Android 1.0.0、2.10.0 等历史标签和附件不修改。

## 验证

使用合成邮件验收：多人姓名、联系人复制的剪贴板实际内容、长主题、长邮箱、末位收件人与抄送可达、关闭回原邮件、原版 HTML 与离线图片、草稿和通知回归。检查 Android 15 AOSP ARM64 的标准字号、320dp 窄屏两倍字号及深色；执行 JVM 测试、debug/release lint、原有发布门禁、固定签名覆盖安装和 16KB zipalign。具体执行数量见随包 verification.json。

没有向真实联系人发送邮件，未使用真实邮箱密码。模拟器测试不代表所有厂商实体机与长期后台行为均已验证。
