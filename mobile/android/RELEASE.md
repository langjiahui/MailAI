# Android 2.10.0-beta.3 发布记录

- 日期：2026-10-18
- 基准版本：GitHub 最近正式版本 v2.9.4；最近 Android 预发布为 2.10.0-beta.2。
- 变更类型：本轮相对 beta.2 为 PATCH 类兼容修复；从正式 v2.9.4 起的 Android 整体为 MINOR。
- 目标版本：Android 2.10.0-beta.3；构建 versionCode 2100003；Git 标签 android-v2.10.0-beta.3。
- 判断依据：首次提供独立 Android 邮件客户端，新增后台邮件通知、应用更新能力；SQLite v1→v2 自动迁移保留草稿。当前为测试通道，不宣称正式 v2.10.0 已完成全平台发布。桌面当前正式版本及根目录 VERSION 仍为 2.9.4；Android 版本存于 mobile/android/VERSION。

## 交付范围

独立邮箱登录、收发、附件、本地草稿；后台周期收信与隐私通知；自动检查、可选 Wi-Fi 下载、完整性/包名/版本/签名匹配校验、系统确认安装；通知跳转与窄屏交互优化。

公开发布仅包含 APK、更新清单、SHA-256 校验文件和本说明；不上传私钥、凭据、真实邮件或工作区内其他未完成代码。源码在独立 Android 分支，发布标签对应完整 Android 源码。

## 已执行验证

- 既有离线门禁 244/244 通过。
- Android JVM 测试 30 项；模拟器系统与交互测试 9 项。
- Debug/Release 编译与 lint，签名/安装元数据检查；签名覆盖安装与 GitHub 下载链路另见验收附件记录。
- 使用合成邮件与本地加密 IMAP/SMTP 服务，包含错误证书、发送后确认丢失、草稿恢复等故障情况。

## 使用限制

Android 10+。后台为 15/30/60 分钟周期调度，系统可能延迟；非秒级推送。普通安装需要用户确认，不能静默升级。真实邮箱服务商、目标真机触感与长时间耗电尚待验收。

本通道包名 com.mailai.mobile，与上一版本地调试包 com.mailai.mobile.dev 独立，首次切换需重新添加邮箱。后续本通道测试版本使用固定分发签名覆盖升级。

## beta.3 修复

- 320dp 窄屏与 200% 字号：邮箱选择和导航自动换行；提示文字与操作按钮分行，长内容可展开查看；退出草稿弹窗操作竖排。
- 键盘：收件人、主题“下一步”连贯切换；长正文编辑区按可用高度伸缩并保持输入末尾可见；发送按钮留在顶部，提交后收起键盘展示进度。
- 等待与恢复：修复快速取消时界面可能一直停在“正在取消”的问题；取消不误报失败，不丢原有草稿，取消后可以重试；保存草稿失败新增明确重试入口。
- 统一深浅色系统控件的中性色，保持简洁的墨绿配色，无新增装饰图标。

相对 beta.2 没有增加独立的新能力，属于兼容性修复。从正式 v2.9.4 看，Android 整体仍为 MINOR，目标正式版本保持 2.10.0，预发布序号递增为 beta.3。已发布的 beta.1、beta.2 标签和安装包不变。

本轮使用 Android 15 AOSP 模拟器，覆盖 320dp 窄屏、200% 大字号、键盘输入与关闭、深色和默认字号。设备配置与截图保存在本次验收附件；实机触感、厂商输入法差异仍需真机验收。
