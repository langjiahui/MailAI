# MailAI Android 1.0.0 正式版

- 日期：2026-10-19
- 基准版本：最近 Android 正式版 android-v2.10.0（历史共用编号，versionCode 2100100）；Web/桌面 v2.9.4 不作为 Android 的功能版本基准。
- 变更类型：独立版本线初始化（用户明确要求），同时修正分发清单命名与发布门禁；无功能回退、接口变化或数据不兼容。
- 目标版本：Android 1.0.0；versionCode 2100101；标签 android-v1.0.0。
- 判断依据：Android 从 1.0.0 独立编号，后续按自身变更执行 MAJOR/MINOR/PATCH；安装序号独立递增以兼容旧安装。Web/桌面 VERSION 与 Latest 保持 v2.9.4，历史 2.10.0 标签及安装包不覆盖、不改号。

## 版本管理变更

产品版本保存在 `mobile/android/VERSION`，内部安装序号保存在 `mobile/android/VERSION_CODE`。根 VERSION 仅表示 Web/桌面，两端不再相互借用或强制统一版本。更新器按安装序号选择候选，再核验安装包可见版本和固定签名。应用名称仍为 MailAI。

## 延续的功能

1. **联系人与多人收件人**：正确解码 MIME 姓名、移除姓名外层引号；默认折叠为“发给我 · 共 N 人”等摘要，详情按发件人、收件人、抄送分组展示姓名与邮箱。往来联系人保存在当前邮箱的本地通讯录，支持搜索、新建、写信选择和去重；手机通讯录通过系统选取单个邮箱，不申请整本通讯录读取权限。写信多人地址默认折叠，可展开移除或编辑。
2. **原版阅读**：保存 HTML 与文本两个版本，优先显示原邮件的版式、字体颜色、表格、链接及内嵌图片，支持缩放与文本切换；内嵌图片缓存在应用私有目录，可离线阅读。外部 HTTPS 图片通过公网/TLS 验证的独立图片加载器显示，不携带邮箱密码或站点 Cookie。邮件脚本、表单和嵌入网页不执行，链接由用户确认后交给外部应用打开。
3. **浮动反馈**：普通提示不再占据顶部一行，不改变邮件或编辑器的高度；完成和错误提示短暂浮现后自动隐藏，遵循系统辅助功能超时。等待中保留取消入口；提示隐藏后仍可通过刷新/重试、保存重试等原操作恢复，发送待确认继续锁定重发。
4. **正式版**：软件名称统一为 MailAI；正式客户端只订阅正式 Android 版本，继续核验安装包、SHA-256、大小、包名、版本及固定签名。

## 安装与更新

已安装 Android 2.10.0 可使用“通知与更新”或直接下载本页 APK 覆盖安装，不卸载。内部安装序号 2100101 高于旧包 2100100，Android 与更新器均按此判断升级，显示为 1.0.0 不会安装更旧的功能。

历史 beta 用户首次进入正式通道请手动下载 APK 覆盖安装。包名 `com.mailai.mobile` 与签名不变，邮箱、邮件、联系人、附件、草稿及通知设置均保留；数据库仍为 v3，无新增迁移。

更新清单统一以客户端约定的 `mailai-android-update.json` 附件名发布，支持已安装 2.10.0 发现新的独立版本。历史发布附件不修改。

## 验证

执行 JVM 协议/解析/迁移/更新测试、Android 15 AOSP ARM64 设备回归、窄屏与大字号、深色、断网和应用恢复检查。新增解码多人收件人、HTML 实际渲染与脚本隔离、内嵌图离线、通讯录选择及气泡不改变布局测试。固定签名覆盖升级、debug/release lint、16KB zipalign 和仓库既有发布门禁以 verification.json 的最终执行结果为准。

测试全部使用合成本地邮件，没有向真实联系人发送邮件，未使用真实邮箱密码进行认证。

## 使用范围

Android 10+；HTML 使用系统 WebView，字体/版式可能因设备 WebView 与屏幕宽度而有差异。静态 HTML 与图片可显示，脚本驱动页面、表单和嵌入网页不运行。正文限 2 MB；内嵌图片自动缓存合计 8 MB、单张 3 MB，超出时可作为附件单独下载；外部图片单张限 5 MB，仅允许 HTTPS 公网地址。附件和发送总计仍限 25 MB。需要 OAuth 的邮箱暂未支持。

后台收信受系统周期调度和厂商省电策略影响；“正式版”不表示已经覆盖所有实体机、邮箱服务商和长时间后台行为，目标手机仍需实测。
