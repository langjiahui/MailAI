# MailAI Android 1.5.0

- 基准版本：Android 最近正式版 android-v1.4.0（versionCode 2100112）。
- 变更类型：MINOR。
- 目标版本：1.5.0；versionCode 2100113；标签 android-v1.5.0。
- 判断依据：新增单封邮件打印、A4 PDF 生成分享及原始 `.eml` 邮件导出能力，属于向后兼容的新用户能力；同步修复发件人与收件人头部中嵌套转义引号显示名的清洗问题。保持已有账号、邮件、草稿、签名和数据库格式兼容，Android 与 Web／桌面及 iOS 各自独立维护版本。

## 单封邮件打印与分享

- 在阅读页「邮件详情」底部面板新增「打印」与「分享」入口。
- 支持使用系统打印服务输出纯白纸面排版（禁用脚本与外部网络加载，防止泄露或阻塞），并支持生成可分享／保存的 A4 PDF 文件、纯文本摘要或按需拉取的原始 `.eml` 邮件文件。
- 通过应用私有 `FileProvider` 安全授权分享与保存，不请求额外存储权限，不上传邮件内容。

## 显示名清洗修复

- 针对部分老旧邮件服务器在 `From` / `To` / `Cc` 头部中对显示名和地址重复添加 `\"...\"` 转义引号的情况，在解码与缓存边界剥离成对转义外壳，保留真实姓名中的标点符号与多收件人解析准确性。
- 对已同步缓存及新收取邮件均生效，保持通信录手工备注与既有联系人学习规则兼容。

## 验证

- 完整离线发布门禁、Android JVM 单元测试（含 `MailOutputTest`、`MailAddressEscapingTest` 等）、Release lint 及固定签名 APK 构建校验通过。
- 发布后继续执行公开下载清单、APK 大小、SHA-256、固定证书签名及国内 AtomGit 镜像一致性回读核验。
