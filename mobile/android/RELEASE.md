# MailAI Android 1.2.0

- 日期：2026-10-19。
- 基准版本：Android 独立正式版 android-v1.1.0（versionCode 2100103）。
- 变更类型：MINOR（兼容的新功能，包含连接及 UI 修复）。
- 目标版本：1.2.0；versionCode 2100104；标签 android-v1.2.0。
- 判断依据：完整变更新增当前文件夹的服务器搜索，超出原有本地缓存筛选能力，按 Android 自身 1.1.0 升级次版本；内网连接、深色显示及弹窗为兼容修复。数据库 v3、包名、固定签名与既有邮件/草稿兼容；Web/桌面版本独立，旧标签与安装包不覆盖。

## 公司 Wi-Fi 与内网邮箱

修复客户端将用户配置的邮箱服务器当作外部公网资源，拒绝内网解析结果的问题。邮箱连接支持 IPv4 私网、运营商内网和 IPv6 ULA，仍拒绝环回、链路本地、组播和未指定地址。外部图片与更新资源继续使用独立的公网限制。

DNS 与 TCP/TLS 使用同一条网络：保留可见 VPN，否则优先已连接 Wi-Fi，避免公司 Wi-Fi 无公网时邮件误走默认移动数据。前台联网提示与后台收信调度不要求 INTERNET/VALIDATED 探测通过。每次连接重新选择网络，不绑定整个应用或改变更新下载的路由；TLS 证书链与原始服务器域名验证保持。

## 检索

本机结果即时显示；可进一步搜索服务器上的整个当前文件夹，覆盖发件人、主题、正文、收件人与抄送，能找到最近 50 封之外的匹配。分别展示服务器匹配总数与已显示数量，每批 50 封，最多显示 500 封，可缩小关键词。支持取消、重试、更多匹配，保留本机结果和返回查询。附件名称仅在本机已缓存元数据中查找。

搜索只读，不标记已读、不自动下载整箱正文、不改变发送流程。关键词交给邮件协议库编码，限制长度及控制字符。服务器不支持搜索或网络不可达时显示失败与重试；不将“本机没找到”误当作整箱不存在。

## UI 与正文显示

草稿退出弹窗改为纵向操作，主操作“保存并返回”，其次“继续编辑”，危险操作“放弃草稿”单独标色，避免多个按钮挤在一行。正文、附件与草稿保存机制保持。

深色阅读时适配 HTML 的白底、黑字及灰色中性色，WebView 背景随外观变化，保留图片、表格结构、强调色和系统选字复制。变换仅用于显示，原始邮件 HTML 不修改。设置提供“保留邮件原始配色”，便于查看复杂模板原貌。

## 验证与安装

发布附件 verification.json 记录最终单元/协议测试、Android 设备测试、门禁、签名及覆盖安装结果。网络测试使用合成数据：Android 原生私网地址 TLS 握手、证书域名拒绝、本地 IMAP 搜索与分页、无公网 Wi-Fi 和双网络切换。未连接 BAOSIGHT 实际网络，未使用真实邮箱密码；公司 DNS、防火墙、证书配置仍需现场复测。

Android 10+，正式包名 com.mailai.mobile，原固定签名。直接覆盖旧正式版本，不卸载。发布不标 Pre-release，不替换 Web/桌面的 Latest。后台收信仍可能因 Doze 或厂商省电而延后。
