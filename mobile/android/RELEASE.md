# MailAI Android 1.3.2

- 基准版本：Android 独立正式版 android-v1.3.1（versionCode 2100109）。
- 变更类型：PATCH（兼容的界面、交互与下载恢复修复）。
- 目标版本：1.3.2；versionCode 2100110；标签 android-v1.3.2。
- 判断依据：改善已有应用更新流程的排版、反馈、取消与网络恢复，不增加独立业务能力，不改变账号、邮件、草稿、附件格式或数据库。Android 与 Web／桌面独立维护版本。

## 更新操作更顺手

- 下载、重试与安装按钮固定在底部，长更新说明和展开设置不会挤走主操作。
- 默认展示关键更新条目，自动检查与 Wi-Fi 自动下载收进折叠偏好；完整说明可在 GitHub 查看。
- 区分当前版本、上次缓存的更新和最新检查结果，进入更新页时重新确认；不再把检查失败当作下载失败。
- 失败原因优先显示，检查、下载和安装包验证分别提供明确的重试入口；覆盖安装保留邮箱和草稿，无需逐级升级。

## 下载与恢复

- 检查和下载都可取消，旧任务不能覆盖新任务状态；自动与手动下载共用任务队列。
- Wi-Fi 条件变化导致系统暂停时保留请求，网络恢复后重新下载；用户主动取消后不自动重启。
- 仅在计费网络下载前确认流量；安装授权返回后继续进入系统安装页面。
- 保留大小、SHA-256、包名、版本和固定签名验证，验证完成前不可安装。
- 获取最新正式 Android 更新时避免反复读取旧版本清单，减少请求和等待。

## 验证与升级

- 已通过 114 项 JVM 测试、普通／窄屏 200% 字号／深色主题下共 9 项更新页交互检查，以及 6 项设置入口与底部面板回归。
- 已通过 248 项离线发布门禁；正式签名构建再次执行单元测试、Release lint 和发布契约验证。
- 固定签名覆盖安装，保留账号、邮件、草稿与附件。未新增周期任务，不改变后台收信频率、邮箱协议或模型调用。
