# MailAI Android 1.1.0

- 日期：2026-10-19。
- 基准版本：Android 独立正式版 android-v1.0.1（versionCode 2100102）。
- 变更类型：MINOR（兼容的新功能）。
- 目标版本：1.1.0；versionCode 2100103；标签 android-v1.1.0。
- 判断依据：本次完整变更新增抄送/密送、富文本发送、分类搜索、星标、回复全部、转发与阅读偏好，超出界面修复范围，按 Android 自身 1.0.1 基准升级次版本。数据库 v3、包名与固定签名兼容；Web/桌面版本独立，历史版本不覆盖。

## UI 与操作

统一收件箱、写信、阅读、搜索、收件人、文件夹和设置：浅色白卡、深色分组、绿色主操作，内容页不为 Logo 占一行。图标等比绘制，圆形和胶囊按钮保持比例；大字号、窄屏、横屏和键盘出现时保留可达操作。修复应用深浅色与系统不同、页面重建后导航栏对比不足的问题。

收件人默认折叠，整页选择并固定确认数量；抄送和密送分别更新，不改动其他字段。往来联系人来自真实缓存，缺少企业目录、容量、智能分类数据时不展示示例数量。文件夹和筛选显示真实缓存范围，星标在此设备持久保存，跨列表和阅读页一致。

邮件直接显示原 HTML、表格、颜色及内嵌图片，支持系统选字复制；收件人和附件按需展开。底部提供回复、回复全部、转发。搜索提供分类、数量、关键词高亮与正文匹配摘要，返回保留查询。签名、外观和正文字号连接实际行为，清理图片缓存不会删除邮件、附件与草稿。

## 邮件连续性

写信支持抄送/密送、加粗、斜体、下划线、字号、颜色、HTTPS 链接与撤销/重做。草稿保存正文和格式，旧草稿兼容读取；发送同时提供纯文本和 HTML，密送只参与 SMTP 信封，收件人头不泄露密送地址。

修复切换邮箱的缓存读取与同步间隙、快速编辑的旧字段覆盖，以及键盘收起时重复滚动请求造成的异常。加载、取消、失败重试使用浮动反馈，不挤动内容。星标迁入同一存储源，正文和已读状态写回不覆盖星标。

保留发送确认、结果待确认保护、草稿与附件持久化；恢复网络不自动重发。回复全部排除本人并去重；转发保留原文和已下载附件，缺失或超过 25 MB 会提示处理。后台通知去重、通知定位与应用内安全更新继续使用原有机制。

## 验收与安装

发布附件 verification.json 记录最终测试、屏幕配置、签名、哈希及覆盖安装检查。测试使用合成数据和本地协议服务，没有使用真实密码或向外部联系人发信。

正式包名 com.mailai.mobile，使用原固定签名，可直接覆盖 1.0.0、1.0.1 和历史正式 2.10.0，不卸载；beta 用户首次进入正式通道需手动覆盖。Android 10+。发布不标 Pre-release，不替换 Web/桌面的 Latest。

模拟器覆盖不能替代厂商实体机的指尖触感和长期省电验收。后台定时收信可能受 Doze、锁屏和厂商省电影响而延后；系统强行停止后需重新打开。OAuth、服务端草稿同步、IMAP IDLE、服务器星标同步和邮件移动/删除尚未提供。
