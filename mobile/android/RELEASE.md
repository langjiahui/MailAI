# MailAI Android 1.4.0

- 基准版本：Android 最近正式版 android-v1.3.3（versionCode 2100111）。
- 变更类型：MINOR。
- 目标版本：1.4.0；versionCode 2100112；标签 android-v1.4.0。
- 判断依据：新增可独立工作的国内签名更新通道与官方 APK 镜像，属于向后兼容的新能力；同时补齐已有自部署模型的 HTTP 内网、流式解析及推理额度兼容问题。保持已有配置、邮件和数据库格式兼容，Android 与 Web／桌面独立维护版本。

## 国内更新

- 国内与 GitHub 发布完全相同的 APK，固定签名覆盖升级。Android 使用独立签名静态清单，不依赖共享匿名平台 API，不覆盖桌面更新指针。
- GitHub 发布列表或清单不可达时检查国内清单；下载线路可回退。固定公钥验签，并继续核对 APK 大小、SHA-256、包名、安装序号、可见版本和原签名；异常文件不能安装。
- 保留取消、失败重试、Wi-Fi 自动下载与系统安装确认。旧 Android 安装包首次使用国内更新能力，请从国内发布页手动覆盖安装本版，不卸载。

## 小邮模型兼容

- 企业内网自部署 Chat Completions 支持 HTTP 基础地址及完整接口地址；须明确开启内网选项，校验并固定内网目标地址，禁止重定向；HTTPS 继续验证证书。
- 保留模型 ID 大小写。Qwen 的 tool_calls 空值或空数组不再被误判为工具请求；实际工具调用仍拒绝。
- 仅为自部署 Kimi K2 系列预留 4096 token 输出额度，不发送不兼容的厂商参数。流式总接收上限为 4 MiB，可见结果仍限制 32000 字符，输入限 24000 字符，单次调用限 90 秒；中断或截断不作为完整候选。
- 摘要提示限制原文要点，减少额外推断。其他预设 API 参数、收发邮件、草稿、附件、联系人和后台收信流程保持兼容。

## 验证与发布

使用合成邮件完成两种内网模型的摘要、回复、润色、24000 字符长文、JSON 等实际接口验证及真实响应解析回放；API Key、企业地址和响应样本不进入发布源码。执行现有离线门禁、完整 JVM 测试、Release lint、设备协议／设置验证和固定签名构建。发布后回读 GitHub 与国内附件、签名清单和文件哈希，既有发布版本保持不变。

发布前本地验收：250 项离线发布门禁、132 项 JVM 单测、19 项 Android 15 设备测试全部通过；Release lint 与原固定签名构建通过。设备测试覆盖 HTTP／HTTPS 传输、流式结果、模型配置、国内签名验证、中文编码及更新面板。
