# MailAI Android

当前 Android 正式版本：**1.3.2**（versionCode **2100110**），Android 10+。

[下载 APK](https://github.com/langjiahui/MailAI/releases/download/android-v1.3.2/MailAI-Android-1.3.2.apk) · [发布说明](https://github.com/langjiahui/MailAI/releases/tag/android-v1.3.2)

Kotlin + Jetpack Compose 原生邮件客户端，软件名称为 **MailAI**。手机通过 IMAP/SMTP 独立收发，电脑关机也能工作，不依赖桌面服务或 Google Play 服务。

## 1.3.2 更新体验修复

下载、重试与安装按钮固定在面板底部；更新内容默认显示关键条目，自动检查与 Wi-Fi 下载设置折叠收纳。区分当前安装版本、缓存的更新信息及最新检查结果；失败原因优先显示，检查、下载、验证失败分别提供对应重试操作。

支持取消检查与下载，旧任务不能覆盖新任务状态。Wi-Fi 条件变化导致系统暂停时保留任务，网络恢复后重新下载；主动取消后不自动重启。使用计费网络下载前确认流量，授权安装后继续进入系统安装页面。保留安装包大小、SHA-256、包名、版本及固定签名验证，覆盖安装保留邮件和草稿。

验证普通屏幕、窄屏 200% 字号、深色主题、长说明和设置展开后的底部按钮可见性。不新增周期任务，不改变邮箱协议、数据库或 Web/桌面版本。

## 1.3.1 底部面板与交互修复

应用更新、后台收信、邮件详情、附件和小邮统一紧凑标题栏与拖动横杠。去掉重复的状态栏留白，横杠距面板顶边约 8dp；长面板支持上拉展开、下拉收起／关闭，系统返回先收起再关闭，按钮可直接关闭。正文滚动不误关面板，窄屏、大字号和深浅色保持清楚可读。

小邮短结果按内容收紧；加载结果改变高度时保留展开状态，底部采用操作可见。关闭过程中加载结束不会重新打开面板，关闭和取消动画仍可连续操作。本轮不修改数据结构或后台任务，覆盖升级保留账号、邮件、附件与草稿。

## 1.3.0 小邮与后台收信

本次新增按需小邮：阅读页提炼要点、预览并起草回复，写信页润色正文或选中文字。使用自己的 HTTPS Chat Completions 兼容模型服务，手机独立连接；配置与 API Key 加密保存，不内置服务凭据。

模型配置统一在“账号与设置 → 小邮与模型服务”，面板不常驻设置入口。小邮面板沿用原角色，静态待机，只有处理中／完成时的有限表情过渡。无小邮后台心跳、定时自动分析或常驻服务；锁屏或退后台停止生成，旋转不重复请求，已有文字保留为未完成结果。缓存相同结果，按账号与正文版本隔离。采用后才保存草稿，润色保护新输入并可在本次编辑中撤回；邮件发送仍需确认。

小邮候选结果保存在应用私有 SQLite，按账号与正文版本隔离，不宣称结果库额外加密；可在模型设置清理，邮件和草稿保留。服务配置属于此设备，不自动与桌面同步。

此阶段尚不包含自然语言整箱检索、语音、提醒、养成商店或跨端同步。模型真实服务和实体机能耗需现场验收；本地协议／设备验证与截图另行记录。详见 [小邮融合与能耗方案](../../docs/Android小邮融合与能耗方案-2026-10-19.md)。

## 邮件与通讯录

1.3.0 在账号初始化时从本地各文件夹缓存和草稿补齐往来联系人，之后增量学习，无需整箱下载或反复扫描。姓名解码、有效中文姓名与新旧优先级一致，支持编辑备注且自动学习不覆盖人工备注；数据库 v3 自动迁移至 v4，保留原邮件、草稿、附件及通知游标。

- 多邮箱、公网与内网 IMAP/SMTP、TLS / 强制 STARTTLS；QQ/Foxmail、163、126 按完整域名匹配，其他域名生成待确认的可修改建议。验证成功后才保存凭据；不自动提交输入的密码。
- 收件箱、真实文件夹、未读筛选、本地搜索、分批加载、已读同步、中文发送和回复。多人收件人默认折叠；详情分别展示解码后的发件人、收件人、抄送姓名与邮箱。
- 原邮件 HTML 版式、颜色、表格与内嵌图片，支持缩放、长按选字与复制，原邮件只有纯文本时正常显示纯文本。旧文本缓存保留，联网时可补读原版。普通附件下载、打开与分享，发送附件保存私有副本。
- 当前邮箱的往来通讯录支持搜索、新建与写信选择。手机联系人通过系统选取单个邮箱，不要求读取整个手机通讯录。写信地址默认折叠、可展开编辑/移除，去重后单封最多 50 位收件人。
- 写信支持抄送、密送、受控富文本（加粗、斜体、下划线、字号、颜色和 HTTPS 链接）、撤销/重做和系统复制粘贴；TO/CC/BCC 跨字段去重，密送不出现在收件方邮件头。纯文本和 HTML 同时发送，旧草稿兼容读取。
- 本地草稿和附件自动保存、离开确认、发送前确认、保存失败重试。SMTP 提交后确认丢失时保留结果待确认，禁止直接重发，网络恢复不自动重发。

## 1.2.0：公司网络、完整文件夹检索与深色正文

- 修复邮件地址复用公网资源校验而拒绝私网服务器的问题。用户配置的邮箱支持 IPv4 私网、运营商内网和 IPv6 ULA；仍拒绝环回、链路本地、组播和未指定地址。邮件远程图片及更新资源继续只允许公网。
- 邮件连接使用同一网络解析 DNS 和建立 TCP/TLS。保留可见 VPN；没有 VPN 时优先已连接 Wi-Fi，避免公司 Wi-Fi 无公网时误走移动数据的公网 DNS。前台和后台邮件不再要求 INTERNET/VALIDATED 能力，断网仍保留缓存和草稿；不更改整个应用的网络路由，不降低证书或域名验证。
- 检索先显示当前缓存，可搜索服务器上整个当前文件夹的发件人、主题、正文、收件人和抄送，不受最近 50 封窗口限制。服务器匹配总数与已显示数量分开，分批显示 50 封，最多显示 500 封，更多结果可缩小关键词；搜索不把邮件标为已读。附件名称仍在已缓存元数据中搜索。服务器不支持检索时给出失败/重试，保留本机结果，不下载整箱正文。
- 深色下适配 HTML 正文的白底、黑字和灰色中性色，保留图片、表格结构及强调色；显示变换不改写邮件源。设置可打开“保留邮件原始配色”。复杂模板如有配色差异可使用此选项。
- 草稿退出弹窗使用纵向主次操作：保存并返回、继续编辑、放弃草稿。宽度、字号和触控区域自适应。

## 已有：整体 UI 与交互统一

- 收件箱与写信页同步统一：搜索、筛选、头像、星标与附件状态互通；抄送/密送通讯录只更新对应字段。
- 浅底白卡、深绿主操作、统一线性图标与彩色姓名头像，内容页不占一行展示品牌。
- 阅读页发件人、收件人摘要、主题与正文分层；底部固定回复/回复全部/转发，附件用底部面板。直接显示原邮件，支持系统选字复制。
- 独立本地搜索页，按发件人、主题、附件筛选并高亮匹配。显示真实数量，正文摘要围绕关键词；返回保留当前查询与结果。
- 整页收件人多选，顶部固定确认与数量；搜索和键盘不挡确认。取消不修改草稿，已有地址不可重复选取。

- 回复全部排除自己的邮箱并去重；转发包含原文和已下载附件，附件缺失或超限时提示处理，不静默遗漏。所有发送仍需原有发送前确认。

没有接入企业组织目录、服务端容量或智能分类的数据时，不显示设计图中的示意组织、容量与分类数量。签名等新选项均连接实际行为，不添加无效按钮。

## 界面与反馈

七页设计延续纸白、森林绿和原版玻璃 M；内容页不为 Logo 独占一行。短位移过渡保留列表和阅读位置，回复返回原邮件、旧草稿返回记录；原邮件不在缓存则回到收件箱。

状态提示使用浮动气泡，不占顶部一行，不挤动页面；短暂显示后隐藏，等待可取消，恢复入口保留在原操作中。大字号允许换行、滚动和键盘避让，图标等比绘制，圆形与胶囊按钮保持比例；系统动画与辅助功能超时设置继续生效。应用外观与系统深浅色不同时，导航按钮仍保持可读。

切换邮箱先读取本地缓存再同步，加载过程立即反馈；编辑只更新当前草稿对应字段。星标写入数据库后更新各页面，正文加载和已读状态写回不会覆盖星标。旧星标偏好在首次读取时兼容迁入数据库。

## 通知与更新

本轮补齐首次进入收件箱后的 Android 13+ 通知授权（仅请求一次，拒绝后可在设置开启）。通知与后台收信改为可滚动底部面板，提供同类别测试通知、后台检查独立记录、立即检查与取消。前台刷新成功不会冒充后台检查成功；过程被杀或取消也不会写成成功。测试通知不确认真实邮件提醒队列，点击测试通知先保留草稿，再打开收信设置。

识别小米／Redmi／POCO，提供后台自启动入口、应用省电设置与操作说明；系统页面不存在或不允许跳转时回退应用信息。小米自启动权限不可公开读取，不根据跳转或 Android 电池优化状态假称其已放行。后台运行受限、省电模式、通知类别关闭分别展示。

每个账号的前台刷新和后台任务共用锁；后台任务拿到锁后再次检查新鲜度，避免多个任务重复连接。失败至少间隔 1 分钟再尝试并继续采用系统指数退避。收信只取列表元数据，结束关闭连接，不取正文／附件，不运行小邮、不增加常驻服务或高频闹钟。当前仍为 15/30/60 分钟定期检查，不是系统级即时推送；Doze／澎湃 OS 可能推迟，实体机锁屏耗电和通知延迟需现场验收。

后台 WorkManager 定期检查，15/30/60 分钟可选；返回应用与网络恢复时补查，失败退避。首轮同步及 UIDVALIDITY 改变建立基准，后续按 UID 去重。通知默认隐藏姓名/主题，遵循锁屏隐私设置；点通知打开对应邮件，跳转前保存当前草稿。

正式客户端每日检查 GitHub 正式 Android 通道，可自动在不限流量网络下载；手动下载确认当前流量，支持进度、取消与重试。下载后核验 SHA-256、大小、包名、版本和相同签名，再交给系统安装器。

**已安装 1.0.0、1.0.1、1.1.0、1.2.0、1.3.0 或历史 2.10.0 的用户可通过应用内更新或下载本页 APK 覆盖安装，不卸载。** 安卓版使用独立的版本线，内部安装序号继续递增（本版 2100109），功能与数据不回退。beta 用户首次进入正式通道需手动覆盖安装。 旧 beta 客户端只认识 beta 清单，无法识别正式清单；后续正式版本可使用应用内更新。

## 数据与边界

- 分发包名 `com.mailai.mobile`，固定签名覆盖升级；调试包 `com.mailai.mobile.dev` 独立，不自动迁移数据。签名私钥在仓库之外，不提交或作为附件分发。
- 凭据使用 Android Keystore AES-GCM；邮件、通讯录、草稿位于各账号 SQLite 和应用私有目录，依赖系统沙箱及设备加密，不宣称全库应用层加密。禁用自动备份/设备迁移，避免凭据密钥错配。
- HTML 在禁用脚本、文件和 Content URI 访问的 WebView 中显示，不运行邮件表单、脚本或内嵌网页；点击外部链接先确认。内嵌图片在私有目录，外部图片仅经 HTTPS 公网/TLS 验证加载，不附带邮箱凭据、站点 Cookie 或 Referer，缓存可由系统清理。
- 正文 2 MB；内嵌图自动缓存单张 3 MB/合计 8 MB，超出时仍可单独下载附件；外部图单张 5 MB、缓存约 64 MB；附件及发送合计 25 MB。原邮件样式保留，但设备字体、WebView 与窄屏可能影响具体排版。
- 后台不是秒级推送，锁屏、Doze、厂商省电可延后；系统强行停止后需重新打开。Android 13+ 通知需用户授权。当前通知 INBOX 新到未读邮件，最新同步窗口外历史邮件不保证逐封提醒。
- SMTP 成功代表发件服务器接受，本机保留发送记录，尚不主动 APPEND 到服务器已发送文件夹。OAuth、服务端草稿同步、IMAP IDLE、归档/移动/删除及账号移除未实现。真实邮箱、实体机触感和长期后台仍需验收。

## 版本与构建

Android 与 Web/桌面完全独立，Android 从 **1.0.0** 起步，只按安卓版自己的变更升级。本目录 `VERSION` 记录可见产品版本，`VERSION_CODE` 记录持续递增的安装序号；历史共用编号 2.10.0 与 beta 发布保留，不重写。正式使用 `android-v<版本>`、不标 Pre-release，保留桌面 Latest；根 VERSION 继续表示桌面版本。分级与发布规则见 [CONTRIBUTING](../../CONTRIBUTING.md#版本号与发布规则)，本次判断与验收见 [RELEASE.md](RELEASE.md)。数据 v1/v2/v3→v4 自动兼容迁移，不删除缓存或草稿。

JDK 17、Gradle 8.11.1、AGP 8.9.2、Kotlin 2.1.20、Compose BOM 2025.04.01、compile/target SDK 35。

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
./gradlew :app:connectedDebugAndroidTest
python3 scripts/build_distribution.py
```

源码分为 data、mail、ui、background、update；JVM 测试检查协议、MIME、联系人、HTML、存储迁移和更新策略；设备测试覆盖实际 HTML 渲染、联系人选择、气泡布局、草稿、网络、通知、升级和键盘。测试仅使用合成数据，最终数量与结果见发布附件 verification.json。

小邮模型设置提供 DeepSeek、Kimi、Kimi Code、自部署、通用 API 预设和模型选择；默认地址／模型自动填好。测试连接仅由用户点击触发，支持取消，不带邮件正文，不自动替换已保存配置；保存本身不代表连接已通过。Kimi Code 与 Web 使用同样的接口路径、输出预算和流式参数；两种 Kimi 服务的 Key 不通用。
