# MailAI Android

当前 Android 正式版本：**1.0.1**（versionCode **2100102**），Android 10+。

[下载 APK](https://github.com/langjiahui/MailAI/releases/download/android-v1.0.1/MailAI-Android-1.0.1.apk) · [发布说明](https://github.com/langjiahui/MailAI/releases/tag/android-v1.0.1)

Kotlin + Jetpack Compose 原生邮件客户端，软件名称为 **MailAI**。手机通过 IMAP/SMTP 独立收发，电脑关机也能工作，不依赖桌面服务或 Google Play 服务。

## 邮件与通讯录

- 多邮箱、公网 IMAP/SMTP、TLS / 强制 STARTTLS；QQ/Foxmail、163、126 按完整域名匹配，其他域名生成待确认的可修改建议。验证成功后才保存凭据；不自动提交输入的密码。
- 收件箱、真实文件夹、未读筛选、本地搜索、分批加载、已读同步、中文发送和回复。多人收件人默认折叠；详情分别展示解码后的发件人、收件人、抄送姓名与邮箱。
- 原邮件 HTML 版式、颜色、表格与内嵌图片，支持缩放与文本切换。旧文本缓存保留，联网时可补读原版。普通附件下载、打开与分享，发送附件保存私有副本。
- 当前邮箱的往来通讯录支持搜索、新建与写信选择。手机联系人通过系统选取单个邮箱，不要求读取整个手机通讯录。写信地址默认折叠、可展开编辑/移除，去重后单封最多 50 位收件人。
- 本地草稿和附件自动保存、离开确认、发送前确认、保存失败重试。SMTP 提交后确认丢失时保留结果待确认，禁止直接重发，网络恢复不自动重发。

## 本次更新：邮件详情

点“详情”从底部展开宽面板，主题与完整时间独立展示，发件人、收件人和抄送分组排列；姓名、邮箱分出层次。联系人操作默认收起，点某一位在原地展开复制/保存，复制后就地反馈。多人名单可滚动，长主题和长邮箱自然换行，完成、下滑或系统返回可关闭，回到原邮件阅读位置。

## 界面与反馈

七页设计延续纸白、森林绿和原版玻璃 M；内容页不为 Logo 独占一行。短位移过渡保留列表和阅读位置，回复返回原邮件、旧草稿返回记录；原邮件不在缓存则回到收件箱。

状态提示使用浮动气泡，不占顶部一行，不挤动页面；短暂显示后隐藏，等待可取消，恢复入口保留在原操作中。大字号允许换行、滚动和键盘避让，系统动画与辅助功能超时设置继续生效。

## 通知与更新

后台 WorkManager 定期检查，15/30/60 分钟可选；返回应用与网络恢复时补查，失败退避。首轮同步及 UIDVALIDITY 改变建立基准，后续按 UID 去重。通知默认隐藏姓名/主题，遵循锁屏隐私设置；点通知打开对应邮件，跳转前保存当前草稿。

正式客户端每日检查 GitHub 正式 Android 通道，可自动在不限流量网络下载；手动下载确认当前流量，支持进度、取消与重试。下载后核验 SHA-256、大小、包名、版本和相同签名，再交给系统安装器。

**已安装 1.0.0 或历史 2.10.0 的用户可通过应用内更新或下载本页 APK 覆盖安装，不卸载。** 安卓版使用独立的 1.0.x 版本，内部安装序号继续递增（本版 2100102），功能与数据不回退。beta 用户首次进入正式通道需手动覆盖安装。 旧 beta 客户端只认识 beta 清单，无法识别正式清单；后续正式版本可使用应用内更新。

## 数据与边界

- 分发包名 `com.mailai.mobile`，固定签名覆盖升级；调试包 `com.mailai.mobile.dev` 独立，不自动迁移数据。签名私钥在仓库之外，不提交或作为附件分发。
- 凭据使用 Android Keystore AES-GCM；邮件、通讯录、草稿位于各账号 SQLite 和应用私有目录，依赖系统沙箱及设备加密，不宣称全库应用层加密。禁用自动备份/设备迁移，避免凭据密钥错配。
- HTML 在禁用脚本、文件和 Content URI 访问的 WebView 中显示，不运行邮件表单、脚本或内嵌网页；点击外部链接先确认。内嵌图片在私有目录，外部图片仅经 HTTPS 公网/TLS 验证加载，不附带邮箱凭据、站点 Cookie 或 Referer，缓存可由系统清理。
- 正文 2 MB；内嵌图自动缓存单张 3 MB/合计 8 MB，超出时仍可单独下载附件；外部图单张 5 MB、缓存约 64 MB；附件及发送合计 25 MB。原邮件样式保留，但设备字体、WebView 与窄屏可能影响具体排版。
- 后台不是秒级推送，锁屏、Doze、厂商省电可延后；系统强行停止后需重新打开。Android 13+ 通知需用户授权。当前通知 INBOX 新到未读邮件，最新同步窗口外历史邮件不保证逐封提醒。
- SMTP 成功代表发件服务器接受，本机保留发送记录，尚不主动 APPEND 到服务器已发送文件夹。OAuth、服务端草稿同步、IMAP IDLE、AI、归档/移动/删除及账号移除未实现。真实邮箱、实体机触感和长期后台仍需验收。

## 版本与构建

Android 与 Web/桌面完全独立，Android 从 **1.0.0** 起步，只按安卓版自己的变更升级。本目录 `VERSION` 记录可见产品版本，`VERSION_CODE` 记录持续递增的安装序号；历史共用编号 2.10.0 与 beta 发布保留，不重写。正式使用 `android-v<版本>`、不标 Pre-release，保留桌面 Latest；根 VERSION 继续表示桌面版本。分级与发布规则见 [CONTRIBUTING](../../CONTRIBUTING.md#版本号与发布规则)，本次判断与验收见 [RELEASE.md](RELEASE.md)。数据 v1/v2→v3 自动兼容迁移，不删除缓存或草稿。

JDK 17、Gradle 8.11.1、AGP 8.9.2、Kotlin 2.1.20、Compose BOM 2025.04.01、compile/target SDK 35。

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
./gradlew :app:connectedDebugAndroidTest
python3 scripts/build_distribution.py
```

源码分为 data、mail、ui、background、update；JVM 测试检查协议、MIME、联系人、HTML、存储迁移和更新策略；设备测试覆盖实际 HTML 渲染、联系人选择、气泡布局、草稿、网络、通知、升级和键盘。测试仅使用合成数据，最终数量与结果见发布附件 verification.json。
