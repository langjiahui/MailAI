# Android 1.1.0 整体交互验收

原收件箱/写信与阅读/搜索/设置两组改动已整合在 `codex/android-unified-release`，统一使用应用主题，完成跨页联系人、星标、草稿与搜索连接检查。本次按用户最新指示统一发布，版本范围和验收以 [RELEASE.md](RELEASE.md) 与发布附件 verification.json 为准。下方保留此前独立分支的实现与检查记录，其中“未发布”描述的是当时状态。

本变更在独立分支 `codex/android-compose-inbox-finish` 完成，基于 Android 1.0.1 提交 `4b1adb3`，整合原写信与收件箱工作区的未完成界面。未修改原工作区、主线程阅读页分支、Web/桌面代码或历史发布。

## 实现内容

- 视觉按用户反馈进一步减线：写信去掉正文外框、主题上下分隔线、底栏线与收件人输入描边，使用淡底色和留白；收件箱取消逐封横线，降低搜索阴影。
- 收件箱：顶部搜索、全部/未读下拉及本地缓存计数、发件人头像、未读标识、附件提示、此设备的星标、悬浮写信、同步取消/重试和原有空态。搜索使用解码的姓名、地址、主题和已缓存正文。
- 搜索键盘出现时隐藏写信悬浮按钮；列表底部按按钮实际高度留空，按钮测量结果随页面保存，避免大字号下遮挡尾部和阅读返回时跳动。头像首字为装饰，字号单独限制，发件人和邮件文字仍遵循系统字号。
- 写信：紧凑顶栏，联系人选择、多人默认折叠及编辑/移除，按需展开抄送/密送，正文独立滚动、主题键盘 Next、图片/附件导入、原有保存失败重试和发送前确认。
- 正文编辑：原生选择/复制/粘贴，加粗、斜体、下划线、字号、三种文字颜色、HTTPS 链接、清除格式、撤销/重做；支持选区及光标后的输入。工具条可横向滚动。深色预览提高文字颜色对比，邮件发出的颜色值不变。
- 草稿将纯文本和受控格式范围一起保存，已有 JSON 草稿缺失新字段时仍正常读取，不改变数据库版本；抄送、密送、格式和附件沿用既有保存/发送状态机。
- SMTP 同时发送纯文本和 HTML alternative；正文经转义后生成 HTML。TO/CC/BCC 合计上限 50、跨字段去重、校验换行注入；密送只参与信封投递，不出现在接收方邮件头。提交状态及重复发送保护继续生效。

仅提供已实现的入口。参考图中的云文件、表格编辑、签名库和模板库不属于本次已有能力，未加入空按钮。星标为此设备功能，尚不与邮箱服务器 FLAGGED 同步。

## 验证与构建

合成数据和本地模拟 IMAP/SMTP；不登录真实邮箱、不发送外部邮件。JVM 测试覆盖存储恢复、历史兼容、范围编辑、HTML 转义、MIME alternative、附件、密送隐私和星标的 UIDVALIDITY 隔离。设备检查包括正常屏幕、320dp/200% 字号和深色模式，验证键盘、撤销/重做、字体颜色、链接/取消、重建、草稿恢复、筛选搜索、尾行无遮挡和阅读返回位置。

实测截图与最终日志、开发 APK 在此工作区 `output/two-pages/`；首次交付 62 项 JVM 测试、33 项独立设备用例（常规 33、窄屏 7、深色 7，共 47 次执行）和 lint 通过，仓库离线门禁 244/244；完整结果见 `verification.json`。调试包名 `com.mailai.mobile.dev`，与正式应用分开，不迁移正式应用的账号或数据。

这份交付未发布 GitHub 正式版本。基准版本是此开发分支的 Android 1.0.1；变更包含富文本发送、抄送/密送与本地星标，属于兼容的新能力（MINOR），候选目标为 1.1.0。正式整合发布时必须重新核对届时最新 Android 正式版本及完整变更，再同步 VERSION、VERSION_CODE、README、RELEASE 和标签；不得覆盖已有 APK 或沿用 Web 版本。当前正式版本文件保持原值，开发 APK 不是正式更新通道的产物。

## 2026-10-19：比例与按钮自适应

写信悬浮按钮保持 1:1 圆形，按文字高度和宽度一起放大直径；发送按钮保留横向胶囊形。图标用同一缩放系数居中绘制，不随容器宽高分别拉伸。格式工具的 B/I/U 与撤销箭头按图标尺寸显示，工具项垂直居中；邮件正文仍遵循系统字号。

窄屏/大字号隐藏顶栏重复的附件图标，底栏保留图片/附件，移除容易折行的容量说明（限制仍由附件操作的无障碍描述说明）。收件人和主题标签共用宽度；窄屏收件人姓名与人数上下排，不互相挤占。正文编辑高度按可用页面比例调整，继续保留独立滚动和键盘避让。收件箱展开搜索键盘时临时收起大标题，使横屏的搜索输入框也保持可见。

新增界面约束检查：圆形按钮宽高一致、发送按钮在视口内且保持横向、标题和发送不重叠、底部操作不重叠、触控范围至少 48dp（允许像素换算误差）。本轮覆盖常规、320dp/200% 字号、深色和横屏收件箱，共 22 次设备用例；62 项 JVM 测试、lint 和仓库 244 项门禁通过。横屏测试先滚动目标邮件到可点击区域，再点该邮件的星标，避免点击被悬浮按钮遮住的屏幕位置。

这轮是兼容的界面修正，不单独发布正式版本；与首次交付的新能力整合时，仍按完整变更中的最高级别判断版本。
