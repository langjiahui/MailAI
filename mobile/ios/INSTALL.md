# MailAI iOS 测试安装

本包适用于 iOS 18+ 的 iPhone / iPad。`unsigned.ipa` 尚未签名，需要用目标设备的有效证书签名后安装，不能直接点击安装；本测试包未在 App Store 或 TestFlight 上架。

1. 在**准备安装 MailAI 的那台 iPhone**上，使用 Safari 打开证书卖家提供的兑换页面。按页面教程完成 UDID 绑定，核对绑定设备后再兑换。商家说明证书只绑定该设备，绑定后不能更换到其他设备。
2. 保存兑换得到的 `.p12` 证书与 `.mobileprovision` 描述文件；保管卡密和证书密码，不放进 GitHub Issue、发布附件或源码仓库。
3. 按商家教程安装签名工具，将证书与描述文件导入工具，再导入 `MailAI-iOS-1.0.0-unsigned.ipa`，选择该设备证书签名并安装。包标识为 `com.mailai.ios`；若描述文件不允许这个标识，需由服务商提供匹配描述文件或按工具支持的方式使用允许的标识。
4. 如果系统提示，按设备设置开启开发者模式并按要求重启、信任开发者。具体安装授权以 iPhone 的系统提示为准。
5. 首次启动添加邮箱，核对服务器与端口后点击“验证并保存”。使用合成测试邮箱先验收收信、阅读、回复、中文发送、离线缓存与重启后的草稿；确认正常后再添加日常邮箱。

同一证书是否允许签其他 App、有效期、设备变更、撤销后的补发与售后范围，以所购买服务的实际条款为准。证书与设备绑定不代表可以公开分发给所有用户安装。

如果希望由电脑签好包，需要向构建端提供上述两个签名文件及其密码；当前发布产物不会包含私钥或个人 UDID。不要以“服务器已发送文件夹没有副本”为依据直接重发，本版不自动保存该副本。
