# iOS 设计稿实施（2026-10-28）

用户已批准本地 `ios-design-review-2026-10-28` 的 16 张设计板、61 项页面与弹窗覆盖。视觉基准为宝武蓝 #005EAA、浅色 #F6F8FA / #FFFFFF、深色 #101923 / #172330，文字随系统动态字号。

本轮范围：紧凑邮箱导航、搜索与筛选、批量整理；白底阅读、详情与附件；正文优先的写信页、收件人标签与多选、折叠原邮件和格式工具；草稿／发送记录分栏；联系人详情；设置分层、外观预览、隐私与许可；小邮调用范围确认、原文对照、模型配置清除确认。

数据与收发约束：保留钥匙串、缓存、旧草稿兼容性、TLS 与 HTML CSP；不自动上传邮件；不自动重发发送结果未知的邮件；已发送副本重试仅做 IMAP 存档。模型服务配置可在授权关闭时保存，真实邮件调用仍要求授权和本次范围确认。测试连接只发送固定合成文字。

验收：核心测试覆盖移除非当前邮箱的数据隔离、转发清空所有原收件人；UI 回归保留添加邮箱取消后重复进入、域名默认配置、阅读／回复全部、深色、大字号，并增加联系人多选确认与草稿持久化。最终以 CI 模拟器结果、截图与 arm64 构建为准；本机只有 CommandLineTools，不能替代 iOS SDK 构建。

此轮为本地更新候选，不创建正式发布、覆盖标签或修改其他端版本。

模拟器验收固定使用 iPhone 15 Pro（393×852 逻辑点），在当前可用 iOS 运行时创建独立设备。避免仅以更宽的默认模拟器截图作为目标机型验收。页面状态与深色／大字号巡检均保留，不缩减既有协议或核心测试。

扩展到全页面／异常状态和三组主题字号巡检后，iOS作业上限由60分钟增加到90分钟。没有缩减测试、改变断言或跳过失败；完整门禁继续绑定最终提交。

## 2026-10-29 真机反馈调整

用户在5801真机版上要求继续精简收件箱：写信改为44点图标按钮，账号头像去掉iOS26自动玻璃外框；邮件列表隐藏连续分割线与导航箭头，明确行内边距，并把附件和星标并入元数据行。无正文预览的邮件不再为状态图标单独占行，大字号继续分行显示时间。

通讯录自动积累改为保留结构化姓名，并解码邮件头姓名；从缓存补齐旧的空姓名，保留手工编辑，区分From与Reply-To，按账号隔离。只有邮箱或拼音的邮件不猜测中文姓名。

模型设置沿用Web云端预设：默认DeepSeek，选择Kimi或Kimi Code后自动填充地址和默认模型，普通入口只需填写Key；自定义地址和模型位于高级设置，旧配置继续读取。切换服务商清空Key与授权状态，保存与测试保持用户主动触发；兼容的思考模式参数与Web保持一致。iOS继续要求HTTPS，不把手机localhost当作Mac上的Ollama服务。
