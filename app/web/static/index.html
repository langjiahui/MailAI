运行与隐私

电脑须开机联网，MailAI 须在后台运行。微信正常退出与断线恢复时会尝试通知；突然断网、休眠或关机无法保证即时提示。只处理本人单聊，不支持群聊。微信可按序号获取附件，钉钉附件尚未接入。手机切换邮箱不会改变电脑当前邮箱。

功能指南

点击主题查看步骤，一次专注一个功能。

邮箱账号与同步
连接多个邮箱，按账号查看邮件和同步状态。

入口 · 设置 → 邮箱账号；顶部同步按钮

  1. 使用客户端授权码连接邮箱；Google、Microsoft 也可从官方登录入口授权。连接前核对收发服务器与账号。
  2. 日常从邮件列表左侧切换邮箱；在全部收件箱中，先核对邮件所属账号再回复或操作。
  3. 顶部同步按钮获取新邮件；补历史邮件时使用拉取更多或拉取全部。未完成、暂停和失败状态可在同步进度中查看。
搜索与邮件整理
组合条件、保存搜索，快速定位已同步的邮件。

入口 · 顶部搜索框 → 右侧筛选图标；邮件列表 → 筛选

  1. 输入主题、发件人、正文或姓名拼音；高级搜索可组合收发件人、日期、附件名、未读及分类等条件。
  2. 高级搜索中可以选择账号范围并保存本次条件，下次从已保存的搜索恢复。结果只覆盖已同步到本机的内容。
  3. 列表筛选可查看重点邮件和已有处理标记；从侧栏查看 AI 分类、服务器文件夹与我的收藏。
阅读与往来邮件
看正文、展开引用，按对方查找历史收发记录。

入口 · 打开邮件 → 阅读区；联系人 → 往来次数

  1. 邮件逐封阅读；历史引用和签名折叠时，点击展开原文即可查看完整内容。摘要需要可用的 AI 服务。
  2. 阅读区的往来入口可查找当前邮箱与对方的已同步收发记录；联系人列表中的往来次数也可打开记录。
  3. 点击记录跳转阅读；勾选后可批量移入垃圾箱。我的收藏是本机标记，与服务器星标分别管理。
联系人与标签
导入资料、核对更新，用标签和部门筛选联系人。

入口 · 顶部 → 联系人

  1. 搜索姓名、拼音、邮箱、公司或标签；按个人标签、导入标签、公司和部门组合筛选，多个标签可选匹配任一或全部。
  2. 导入通讯录先预览。已有联系人有资料变化时，先核对再选择更新；支持 CSV、vCard，以及导入界面提供的资料格式。
  3. 批量标记可为多位联系人添加个人标签。写信时从收件人、抄送或密送的通讯录入口选择人员，并核对去重后的地址。
附件查找与核对
按文件内容查找，比较同名附件的文字差异。

入口 · 顶部 → 附件

  1. 按文件名和类型筛选，切换列表或卡片展示；从来源邮件核对文件的发件人和日期，再预览或下载。
  2. 查找文件内容可搜索当前邮箱附件或指定一份文件，显示匹配片段、读取范围和无法读取的文件；搜索在本机进行。
  3. 文件旁的操作入口可比较其他邮件中的同名附件；先确认属于同一材料，再查看文字差异。扫描件不支持文字搜索，Excel 不重算公式。
写信、签名与大附件
使用模板和短语，预览 AI 建议后再应用。

入口 · 顶部 → 写邮件；写信工具栏

  1. 在模板和短语入口保存常用内容；签名可按账号管理。使用模板不会自动复制收件人、附件或签名。
  2. 小邮帮写可参考选定邮件；选中文字后可局部润色，先预览再应用，并可撤销。发送前核对收件人、日期、金额和附件。
  3. 超出普通附件限额的文件可在配置腾讯云 COS 后转为分享链接；附件中心的已分享文件可查看到期时间并重新生成链接。
定时发送与发信跟进
查看发送阶段，调整尚未开始的定时任务。

入口 · 写信底部 → 发送安排；顶部 → 发件箱

  1. 发送安排可设置发送时间及未回复提醒，安排随草稿保存；点击发送后才会加入发件队列。
  2. 发件箱中可核对任务状态，对尚未开始的定时任务编辑邮件、调整时间或取消。编辑后需重新确认发送。
  3. 定时发送依赖电脑开机、联网和 MailAI 运行。发送结果需要核对时，先查看已发送邮件或网页邮箱，不要直接重复发送。
待办、提醒与日历
按期限处理任务，核对来源邮件和会议时间。

入口 · 顶部 → 待办；待办 → 日历文件

  1. 按今天、已逾期、以后或未安排筛选待办；编辑标题，在安排入口设置截止、跟进与提醒，并从来源邮件核对内容。
  2. 完成任务后停止提醒并保留记录。批量操作只影响当前视图中的选择；系统通知权限与提醒时间需要分别配置。
  3. 日历文件可读取邮件中的 ICS 邀请或导入 ICS 预览，核对时区与时间后导出。接受或拒绝会准备回复草稿，仍需确认发送。
日报与工作简报
汇总已同步信息，再核对今天的任务与重点。

入口 · 顶部 → 今日日报；小邮 → 工作简报

  1. 今日日报汇总当前邮箱的邮件与待办；需要生成内容时先确认 AI 服务可用。结果以本机已同步信息为范围。
  2. 小邮的工作简报可按执行或决策视角查看今天先做、等待反馈和待你确认的线索，不覆盖聊天记录。
  3. 从简报回到原邮件核对，再添加或调整待办。未同步邮件、自动识别的线索或未记录的回复不能代表实际进展。
AI 服务与小邮助手
配置模型，选择邮件或附件作为本次参考。

入口 · 设置 → AI 服务；右下角 → 小邮

  1. AI 服务中选择服务商、填写 API 地址、模型名称和 API Key，先测试连接再保存；页头可查看本机记录的模型用量。
  2. 在小邮中选择参考邮件，提问总结重点、整理待办或准备回复。可选择附件先预览再分析，读取范围与不支持格式会有提示。
  3. 支持的表格、文档或表单可请求填写并准备回复；先核对字段与生成文件。小邮准备的草稿仍需人工检查并确认发送。
手机聊天控制邮件
连接本人微信或钉钉，先预览回复再确认。

入口 · 设置 → 手机控制

  1. 微信通过二维码连接；钉钉使用应用机器人配置。选择允许控制的邮箱并保存，显示已连接后在本人单聊中发送帮助。
  2. 可询问最新邮件、未读邮件和今天待办，按序号查看，再回复当前邮件。回复先生成预览，需使用有效的一次性编号确认发送。
  3. 电脑须开机联网，MailAI 须保持运行。手机切换邮箱不改变电脑当前邮箱；邮件内容会经过所选聊天平台。
安全检测与处置
查看风险依据，用反馈修正误报与漏报。

入口 · 顶部 → 安全 → 处置策略／安全看板／规则中心

  1. 首次使用建议选择仅观察，核对检测结果后使用人工确认，再按需要启用自动处置；不同模式会影响高风险邮件的处理方式。
  2. 阅读邮件时展开风险提示核对身份、链接和附件证据，使用反馈标记误报、漏报或确认结果。
  3. 安全看板查看趋势与处置记录；规则中心调整启停、权重和阈值。白名单会减少常规误报，但严重风险仍可能提醒。
导入 Foxmail 旧邮件
扫描去重后导入，历史邮件保留在本地归档。

入口 · 设置 → 数据与维护 → 从 Foxmail 导入

  1. 先在原客户端导出完整 EML、MBOX 或邮件目录，再核对 MailAI 中的目标邮箱并选择文件。
  2. 先扫描并去重，查看新增、重复和问题文件，再点击导入缺少的邮件；不会覆盖原客户端邮件，也不会上传服务器。
  3. 完成后从目标邮箱的本地归档阅读。暂停、重启或失败后，可从最近导入记录继续；问题文件可重新导出并重试。
备份、换机与服务器清理
区分本机恢复、设备迁移和服务器空间释放。

入口 · 设置 → 数据与维护

  1. 本机备份用于当前设备恢复，可在备份记录中另存为或恢复；恢复前会保留安全副本。
  2. 换电脑使用导出到新设备和从旧设备导入，可限定导出日期并设置迁移密码。新设备需重新配置邮箱授权码和模型密钥。
  3. 清理服务器邮件时，先选择范围并预览，再核对列表和邮箱地址。执行前会备份，本机邮件保留；网页版和其他设备可能不再显示，恢复本地备份不会重新上传。

常见问题

小邮没有回答或模型连接失败？

在 AI 服务中核对服务商、API 地址、模型名称和 Key，再点击测试连接；仍失败时到数据与维护运行诊断，按失败项查看建议。模型故障不影响阅读已同步邮件。

为什么搜不到邮件或附件？

先检查搜索的账号、文件夹、日期和筛选条件，再核对同步状态。邮件搜索只覆盖已同步内容；Foxmail 历史需先导入。附件内容搜索不包含扫描图片，较长文件可能只读取部分文字。

发送失败，能直接重新发送吗？

先在任务与发件箱核对阶段。若提示结果需要核对，请先查看已发送邮件或网页邮箱，确认是否送达再操作，避免重复发信；尚未开始的定时任务可调整或取消。

邮件和附件会发送到哪里？

邮件与界面偏好保存在本机。启用云端 AI 后，自动分析及小邮功能会按任务发送所需内容到所选模型服务；大附件分享和手机控制分别经过存储服务与聊天平台。可在关于与隐私查看说明，并按需要使用本地模型。

关于你的数据

本地保存，不代表所有处理都离线。这里说明数据保存在哪里，以及什么时候会联网。

01 · 本机存储

邮件数据保存在本机

MailAI 的邮件数据库与下载的邮件原文保存在本机数据目录。邮箱服务器仍保留其自身数据；本地保存不等于磁盘加密，请妥善保护设备和备份。

02 · 邮箱连接

收发与同步需要联网

连接邮箱、同步和发送邮件会与配置的邮箱服务器通信。邮件中的远程图片或外部链接，也可能访问第三方网站。

03 · AI 处理

模型服务由你配置

服务连接

每个服务商的配置分别保存在本机，选择已保存的服务商即可直接切换使用。首次配置请填写地址、模型名称和 API Key 并保存。其他厂商支持 OpenAI Chat Completions 兼容 API。

支持基础地址（如 /v1）或完整 /chat/completions 地址。模型 ID 须与服务商控制台一致。

模型与能力

测试连接会发送简短文本请求；启用图片识别时还会发送一张不含业务信息的极小测试图，可能产生少量 API 费用。测试成功后再保存即可生效。

扩展请求参数

通常无需填写。可按厂商文档设置参数，例如 {"enable_thinking":false}；值为 null 可省略对应参数。切换厂商后会清空。
